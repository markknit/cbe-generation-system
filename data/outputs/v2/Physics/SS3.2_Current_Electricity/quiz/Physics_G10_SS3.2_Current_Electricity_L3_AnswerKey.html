Q1. Three identical bulbs are connected one after another to a 9 V battery. You want to measure the current in this series loop. How should the ammeter be connected?
  1. Across the battery, joined to both of its terminals
  2. Beside the circuit, with only one end joined to the loop
  3. Across one bulb, joined to both of its terminals
  4. In the loop, as one of the wires in the circuit, so the current passes through it
Correct answer: D
An ammeter measures the charge flowing past a point, so the current must pass through it. It is connected in series, in the loop. Across a bulb or the battery is a parallel connection and is wrong.
Use after: Predict phase — Predict: Wanjiru's idea that 'bulbs use up some current' and the class vote
Q2. Wanjiru says: 'Bulbs use up some current, so less current comes out at the end of the loop.' Three identical bulbs are in series with a battery. The ammeter reads 0.10 A before the first bulb. What will an ammeter read after the third bulb?
  1. 0.07 A, because some current is used up in the bulbs
  2. 0 A, because the bulbs use up all the current
  3. 0.03 A, because each bulb uses up one third
  4. 0.10 A, the same as before the first bulb
Correct answer: D
In a single series loop the charge has nowhere to go, so the same current passes every point. Bulbs transfer energy but do not use up current.
Use after: Observe phase — Part A, series: unscrewing one bulb and noting the ammeter drops to 0 A
Q3. In a series circuit with three identical bulbs, all bulbs are lit and the ammeter reads about 0.10 A. A learner unscrews one bulb. What happens, and why?
  1. The ammeter reads 0.20 A because the current moves to the other bulbs
  2. The ammeter reads 0 A and all bulbs go out, because the loop is broken
  3. The ammeter reads 0 A, but the other two bulbs stay lit
  4. The ammeter still reads 0.10 A and the other two bulbs stay lit
Correct answer: B
Removing a bulb opens the only path round the loop, so no charge flows anywhere. The current is 0 A and all bulbs go out. This matches the closed-loop idea from Lesson 2.
Use after: Observe phase — Part B, parallel: recording 0.30 A in each branch and 0.90 A at the battery
Q4. Three identical bulbs are connected in PARALLEL to the same 9 V battery. The ammeter is used to measure each branch and the battery lead. Which set of readings was recorded, and how did the bulbs look compared with the series circuit?
  1. 0.10 A in each branch and 0.10 A at the battery; the bulbs were the same brightness
  2. 0.30 A in each branch and 0.90 A at the battery; the bulbs were brighter
  3. 0.30 A in each branch and 0.30 A at the battery; the bulbs were dimmer
  4. 0.90 A in each branch and 0.30 A at the battery; the bulbs were brighter
Correct answer: B
The parallel measurements gave 0.30 A in each branch and 0.90 A at the battery, with brighter bulbs than in series. These were recorded only; the explanation comes in later lessons.
Use after: Explain phase — Explain: calculating Q = It for t = 60 s with the series current of 0.10 A
Q5. In a series circuit the current is 0.10 A. How much charge passes any point in the loop in 60 seconds? (Use Q = I × t.)
  1. 0.6 C
  2. 6 C
  3. 600 C
  4. 6 A
Correct answer: B
Q = I × t = 0.10 A × 60 s = 6 C. Charge is measured in coulombs, not amperes.
Use after: Explain phase — Explain: introducing I = Q/t (0.10 A moves 0.10 C every second)
Q6. A student says: 'A current of 0.10 A means 0.10 C of charge passes each point in the wire every second.' Which statement about current is correct?
  1. Current is the total charge in the wire, and it gets used up as it passes a bulb
  2. Current is the energy stored in a battery, measured in coulombs
  3. Current is the push of the battery, measured in amperes
  4. Current is the rate of flow of charge, I = Q/t, and 1 A means 1 C passes each second
Correct answer: D
Current is the rate of flow of charge, I = Q/t, so 1 A = 1 C/s. It is not stored energy, total charge or the push of the battery.
Use after: Explain phase — Explain: clarifying conventional current versus electron movement on the diagram
Q7. In a circuit diagram, conventional current is drawn leaving the + terminal of the battery. In the metal wires, which way do the electrons actually move?
  1. From the + terminal towards the - terminal, the same as the conventional current
  2. They do not move; only the bulb filament has moving charges
  3. From the - terminal towards the + terminal, opposite to the conventional current
  4. Both ways at once, so they cancel out
Correct answer: C
Conventional current is drawn from + to -, but electrons are negatively charged and move from - to + in the wires, opposite to the arrows on the diagram.
