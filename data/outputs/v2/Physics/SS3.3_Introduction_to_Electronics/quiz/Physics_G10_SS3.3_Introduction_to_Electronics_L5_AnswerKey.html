Q1. In the class band model, four materials have these energy gaps: copper 0 eV, germanium 0.67 eV, silicon 1.1 eV and glass above about 5 eV. Which list puts them in order from the smallest gap to the largest gap?
  1. Copper, silicon, germanium, glass
  2. Glass, silicon, germanium, copper
  3. Copper, germanium, silicon, glass
  4. Germanium, copper, silicon, glass
Correct answer: C
Copper has overlapping bands (0 eV), then germanium (0.67 eV), then silicon (1.1 eV), then glass (above about 5 eV). Germanium's gap is smaller than silicon's.
Use after: Observe phase — Observe, Investigation 1 (gap): setting the gap for a metal, germanium, silicon and an insulator
Q2. In the simulation, a learner sets the energy gap to a value above about 5 eV, like glass, and keeps the temperature the same. What should the simulated current reading show?
  1. High current, the same as copper
  2. The same current as silicon at room temperature
  3. Almost none, because very few electrons can cross the large gap
  4. Exactly zero, because no electron can ever move
Correct answer: C
A very large gap means almost no electrons reach the upper band, so the current is almost none. It is not exactly zero, which is a common misconception.
Use after: Observe phase — Observe, Investigation 2 (temperature): raising the temperature of silicon in 3 steps
Q3. A group selects silicon in the simulation and raises the temperature in three steps. What do they expect to record in their table?
  1. The number of free electrons and holes increases
  2. The number of free electrons and holes stays the same
  3. The number of free electrons and holes decreases
  4. Free electrons increase but there are no holes
Correct answer: A
Higher temperature gives more electrons enough energy to cross the 1.1 eV gap. Each electron that crosses leaves a hole, so free electrons and holes both increase.
Use after: Observe phase — Observe, Investigation 3 (doping): adding phosphorus (n-type) and then boron (p-type) to silicon
Q4. A group adds boron, which has 3 valence electrons, to silicon in the simulation. What type of semiconductor do they record, and what are the majority carriers?
  1. n-type, with electrons as the majority carriers
  2. p-type, with holes as the majority carriers
  3. n-type, with holes as the majority carriers
  4. p-type, with electrons as the majority carriers
Correct answer: B
Boron has 3 valence electrons, so it leaves gaps (holes) in the silicon bonds. This gives p-type silicon, where holes are the majority carriers.
Use after: Explain phase — Explain: challenge question "If we add phosphorus to silicon, is the silicon now negatively charged? Use evidence."
Q5. Phosphorus is added to a piece of silicon, giving it many extra free electrons. Is the doped silicon negatively charged overall?
  1. No, it is still electrically neutral overall, because each phosphorus atom is also neutral
  2. No, it is positively charged because it has lost holes
  3. Yes, because it now has extra electrons
  4. Yes, because phosphorus atoms carry a negative charge
Correct answer: A
Each phosphorus atom has equal numbers of protons and electrons. The extra free electron comes from a neutral atom, so the doped silicon stays neutral overall.
Use after: Explain phase — Explain: CER frame for why copper lit the bulb while glass, wood and plastic did not
Q6. Mr Otieno in Nairobi safely holds a PVC-covered copper cable that carries current. Which explanation best uses the band model?
  1. PVC has an energy gap of 0 eV, so electrons are stopped by overlapping bands
  2. PVC has a very large energy gap (above about 5 eV), so almost no electrons can move through it
  3. PVC has no electrons, so there is nothing to carry current
  4. PVC has a smaller gap than copper, so it blocks the electrons
Correct answer: B
The large gap in PVC means almost no electrons can reach the upper band, so almost no current flows through it. Copper's 0 eV gap lets electrons move easily.
Use after: Observe phase — Observe: the checker confirms that only one variable was changed at a time
Q7. A group wants to test how temperature affects the number of free electrons in the simulation. Which plan is a fair test?
  1. Raise the temperature and add phosphorus at the same time
  2. Change the gap size at each step and keep a guess of the temperature
  3. Raise the temperature and change from silicon to germanium at the same time
  4. Keep the same material and doping, and change only the temperature in steps
Correct answer: D
A fair test changes one variable at a time. Changing only the temperature lets any change in free electrons be linked to temperature alone.
