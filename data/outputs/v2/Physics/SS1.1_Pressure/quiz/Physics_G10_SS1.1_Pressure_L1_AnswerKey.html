Q1. In a Kisumu kitchen, Mama Wanjiru pushes with a force of 40 N on a sharp knife (edge 0.1 mm thick) and then on a blunt knife (edge 1 mm thick). The two knives are the same size and shape and she cuts the same kind of tomato. Which of these was the SAME for both knives?
  1. How sharp the knife was
  2. The thickness of the knife edge
  3. The force of the push, 40 N
  4. The result on the tomato
Correct answer: C
The force meter read 40 N each time, the person, the food and the knife size were also the same. The edge thickness and the result were what differed.
Use after: Observe phase — Observe: table 'What I see for the sharp knife / What I see for the blunt knife'
Q2. Mama Wanjiru cut a tomato with a sharp knife and with a blunt knife. Learners were asked to write down only what they could SEE, not the reason. Which sentence is an observation?
  1. The blunt knife pressed the tomato flat and the skin did not break.
  2. The sharp knife cuts because it is made of stronger metal.
  3. The sharp knife is heavier than the blunt knife.
  4. The sharp knife is pushed harder than the blunt knife.
Correct answer: A
An observation says what can be seen. Pressing the tomato flat without breaking the skin was seen. The other statements are untested reasons or claims about the knives.
Use after: Observe phase — Observe: teacher asks 'Was the push the same? How do you know?'
Q3. A learner says, 'The sharp knife cut the tomato because Mama Wanjiru pushed harder on it.' The force meter showed 40 N for the sharp knife and 40 N for the blunt knife. What is the best reply?
  1. We cannot say anything because forces cannot be measured.
  2. The claim is not supported by the evidence, because the force meter showed the same push each time.
  3. The claim is correct because the sharp knife is heavier.
  4. The claim is correct because sharp knives always need a bigger push.
Correct answer: B
Using evidence from the force meter, the push was the same (40 N) for both knives, so 'pushed harder' does not match what was observed.
Use after: Explain phase — Explain: group poster and sentence 'I think the sharp knife cuts better because ... but I am still wondering ...'
Q4. By the end of the first lesson, the class knows that the force is the same (40 N) and that only the knife edge is different (0.1 mm and 1 mm), yet one knife cuts and the other squashes. Which statement is the best thing to say about why this happens?
  1. Mama Wanjiru unknowingly pushes harder on the sharp knife.
  2. The sharp knife is made of a stronger metal, so it always wins.
  3. We have not explained it yet, so we will keep our ideas as questions and test them in the coming lessons.
  4. The sharp knife is heavier, so it cuts.
Correct answer: C
This is the opening lesson and the cause is deliberately left unexplained. Learners have only observed that force is the same and the edges differ. Honest 'I am not sure yet' thinking is the aim.
Use after: DQB phase — Driving Question Board: learners write 2 questions on sticky notes
Q5. The class Driving Question is: 'Why does a sharp knife cut better than a blunt knife when using the same force?' Which learner question is the best one to add to the Driving Question Board because it can be investigated?
  1. Why?
  2. How much does a knife cost in Kisumu market?
  3. Is Mama Wanjiru's kitchen big?
  4. Does the thickness of the knife edge change whether the tomato is cut?
Correct answer: D
A good DQB question has a clear subject and can be tested with evidence. The edge-thickness question links to what was observed. The others are vague or not related to the phenomenon.
Use after: Model Building phase — Model Building: initial model drawing of the sharp and blunt knives
Q6. You are drawing an initial model of the two knives pressing on a tomato, using only what the class observed. Which drawing matches the evidence?
  1. The same edge thickness on both knives but a longer force arrow on the blunt knife
  2. Force arrows drawn only on the blunt knife
  3. The same force arrow on both knives, a thinner edge on the sharp knife and a thicker edge on the blunt knife
  4. A longer force arrow on the sharp knife and a shorter arrow on the blunt knife
Correct answer: C
The force was the same (40 N) for both knives and only the edge thickness differed (0.1 mm and 1 mm). A model that fits the evidence shows equal force arrows and different edges.
Use after: End of lesson — Model Building: shared class model statement marked 'Version 1 - to be tested'
Q7. At the end of the lesson, the class writes a first model statement on chart paper and labels it 'Version 1 - to be tested'. What does this label mean?
  1. It is the final correct answer and cannot be changed.
  2. It is a starting idea that the class will test and change when evidence shows it should be changed.
  3. It is a wrong idea that will be thrown away tomorrow.
  4. It is the teacher's answer, so learners should copy it.
Correct answer: B
Version 1 is the class's starting model. Later lessons will test it and revise it with evidence, which is how scientific models improve.
