Q1. A matatu mirror reflects point P(2, 1) to the image P′(6, 5). The mirror has been removed. Which point must lie on the mirror line?
  1. (4, 4)
  2. (8, 6)
  3. (4, 3)
  4. (6, 5)
Correct answer: C
The mirror line passes through the midpoint of P and P′ because the object and image are equal distances from it. Midpoint = ((2+6)/2, (1+5)/2) = (4, 3).
Use after: Observe phase — Observe: Task 2, working out the gradient of PP′ and the perpendicular mirror line
Q2. Point B(1, 2) is reflected to B′(5, 4). What is the gradient of the mirror line?
  1. −2
  2. 2
  3. −1/2
  4. 1/2
Correct answer: A
Gradient of BB′ = (4−2)/(5−1) = 1/2. The mirror line is perpendicular to BB′, so its gradient is the negative reciprocal: −1 ÷ (1/2) = −2.
Use after: Observe phase — Observe: Task 3, verifying that M is equidistant from P and P′ and the angle at M is 90°
Q3. An object point P and its image P′ are given on a Cartesian plane. Which statement correctly describes the mirror line?
  1. It passes through P′ and is parallel to PP′
  2. It always passes through the origin and the midpoint of PP′
  3. It is the perpendicular bisector of the segment PP′
  4. It is the angle bisector of the angle at P
Correct answer: C
The mirror line cuts PP′ in half at its midpoint and meets it at 90°, so it is the perpendicular bisector. It does not have to pass through P′ or the origin.
Use after: Explain phase — Explain: second worked example, A(−1, 4) reflected to A′(3, 0)
Q4. A lorry at A(−1, 4) has its image at A′(3, 0) in a mirror. Which equation gives the mirror line?
  1. y = x + 5
  2. y = x − 1
  3. y = x + 1
  4. y = −x + 3
Correct answer: C
Midpoint = (1, 2). Gradient of AA′ = (0−4)/(3−(−1)) = −1, so the mirror gradient is 1. Then y − 2 = 1(x − 1), which gives y = x + 1.
Use after: Explain phase — Explain: special cases when the object–image segment is horizontal or vertical
Q5. Point (1, 2) is reflected to the image (7, 2). What is the equation of the mirror line?
  1. y = 2
  2. x = 2
  3. y = 4
  4. x = 4
Correct answer: D
The segment joining the points is horizontal, so its gradient is 0 and it has no negative reciprocal. The mirror line is therefore vertical, passing through the midpoint (4, 2), so x = 4.
Use after: DQB phase — Driving Question Board: checking 'NOW WE KNOW' cards for the 'passes through the origin' misconception
Q6. A learner writes on the Driving Question Board: 'The mirror line always passes through the origin.' Which object–image pair shows that this claim is wrong?
  1. (3, 0) and its image (−3, 0)
  2. (1, 2) and its image (2, 1)
  3. (2, 1) and its image (6, 5)
  4. (2, −1) and its image (−2, 1)
Correct answer: C
For (2, 1) and (6, 5) the midpoint is (4, 3) and the mirror line is y = −x + 7, which does not pass through the origin. In each of the other pairs the midpoint is (0, 0), so the mirror line passes through the origin.
Use after: Model Building phase — Model Building: applying the three-step Mirror Line Algorithm to an invented example
Q7. Q(−2, 3) is reflected to Q′(6, −1). Using the Mirror Line Algorithm, which equation gives the mirror line?
  1. y = 2x − 3
  2. y = −2x + 5
  3. y = ½x
  4. y = −½x + 2
Correct answer: A
Midpoint = (2, 1). Gradient of QQ′ = (−1−3)/(6−(−2)) = −1/2, so the mirror gradient is 2. Then y − 1 = 2(x − 2), which gives y = 2x − 3.
