Q1. A point P(3, 2) is marked on a Cartesian grid. The mirror line is the y-axis (x = 0). What are the coordinates of the image P′?
  1. (2, 3)
  2. (−3, −2)
  3. (−3, 2)
  4. (3, −2)
Correct answer: C
P is 3 squares to the right of the y-axis, so P′ is 3 squares to the left at the same height. This gives (−3, 2): only the x-coordinate changes sign.
Use after: Observe phase — Observe: Reflection Investigation Worksheet, drawing perpendiculars with a ruler and set-square
Q2. When reflecting a vertex in a mirror line on the Cartesian grid, you draw a line from the vertex to the mirror line using a set-square. At what angle should this line meet the mirror line?
  1. It can be any angle, as long as the counts of squares are equal
  2. 45°
  3. 90°
  4. 60°
Correct answer: C
The line from an object point to the mirror line must be perpendicular (90°). The image point is then found by counting the same distance along that perpendicular on the other side.
Use after: Observe phase — Observe: grid (i), reflecting quadrilateral ABCD in the y-axis (x = 0)
Q3. A lorry-shaped quadrilateral ABCD has vertices A(1, 1), B(4, 1), C(4, 3) and D(1, 3). It is reflected in the y-axis (x = 0). What are the coordinates of C′?
  1. (−4, 3)
  2. (3, 4)
  3. (−4, −3)
  4. (4, −3)
Correct answer: A
C is 4 squares to the right of the y-axis, so C′ is 4 squares to the left at the same height. The rule (a, b) → (−a, b) gives C′(−4, 3).
Use after: Observe phase — Observe: grid (iv), reflecting vertices A and C in y = −x, and completing the Coordinate Rule Table
Q4. The point C(4, 3) is reflected in the line y = −x. What are the coordinates of C′?
  1. (3, 4)
  2. (−4, −3)
  3. (−3, 4)
  4. (−3, −4)
Correct answer: D
The rule for reflection in y = −x is (a, b) → (−b, −a). So (4, 3) → (−3, −4).
Use after: Explain phase — Explain: Reflection Rules Reference Card, consolidation question Q1
Q5. A point K(−2, 5) is reflected in the line y = x. What are the coordinates of K′?
  1. (−5, 2)
  2. (−2, −5)
  3. (5, −2)
  4. (2, −5)
Correct answer: C
Reflection in y = x swaps the coordinates: (a, b) → (b, a). So (−2, 5) → (5, −2). Writing (−b, −a) is the common mix-up with y = −x.
Use after: Explain phase — Explain: Reflection Rules Reference Card, consolidation question Q2
Q6. After reflection in the x-axis (y = 0), the image of a point M is M′(4, −3). What are the coordinates of the original point M?
  1. (−4, −3)
  2. (−4, 3)
  3. (4, 3)
  4. (3, −4)
Correct answer: C
Reflecting M′ back in the same mirror line returns the original point. The rule (a, b) → (a, −b) gives M(4, 3).
Use after: Explain phase — Explain: whole-class discussion on why the lorry image in the matatu mirror is the same size as the real lorry
Q7. Side CD of the lorry quadrilateral has C(4, 3) and D(1, 3), so its length is 3 units. After reflection in the y-axis, the image points are C′(−4, 3) and D′(−1, 3). What is the length of C′D′?
  1. 3 units
  2. 1 unit
  3. 4 units
  4. 5 units
Correct answer: A
C′ and D′ are on the same horizontal line, so the distance is |−4 − (−1)| = 3 units. The reflection rule preserves distances, which is why the lorry's image in the matatu mirror is the same size as the lorry.
Use after: Model Building phase — Model: Cartesian overlay on the cumulative model, modelling a flat rear-view mirror as a vertical line x = k
Q8. A flat rear-view mirror is modelled as the vertical line x = 3 on a grid. A point on the lorry is at (5, 2). What are the coordinates of its image?
  1. (−1, 2)
  2. (5, −2)
  3. (−5, 2)
  4. (1, 2)
Correct answer: D
The point is 5 − 3 = 2 squares to the right of the mirror line, so the image is 2 squares to the left of it, at x = 1. The height stays the same, so the image is (1, 2), from (a, b) → (2k − a, b) = (6 − 5, 2).
