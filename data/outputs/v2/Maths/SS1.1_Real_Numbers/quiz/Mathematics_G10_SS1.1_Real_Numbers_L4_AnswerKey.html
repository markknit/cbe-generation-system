Q1. In the lesson, groups use a calculator to find π − 3 to 4 decimal places before pegging it on the number line. Using π ≈ 3.14159265, which value is π − 3 to 4 decimal places?
  1. 0.1416
  2. 0.5000
  3. 3.1416
  4. 6.1416
Correct answer: A
π − 3 ≈ 3.14159265 − 3 = 0.14159265, which is 0.1416 to 4 decimal places. It lies between 0 and 1, close to 0, not at 0.5 or at 3.14.

Q2. Which list shows the numbers −√3, −1.5, 0, 2/3 and √2 in order from smallest to largest on the number line?
  1. −√3, −1.5, 0, 2/3, √2
  2. −√3, −1.5, 0, √2, 2/3
  3. −1.5, −√3, 0, 2/3, √2
  4. 0, 2/3, √2, −1.5, −√3
Correct answer: A
−√3 ≈ −1.732 is to the left of −1.5. Then come 0, 2/3 ≈ 0.667 and √2 ≈ 1.414, so the order is −√3, −1.5, 0, 2/3, √2.

Q3. A group is classifying the Kericho temperature 19.333…°C, where the 3s repeat forever. One learner says it is irrational because the decimal never stops. Which statement is correct?
  1. It is irrational, because it has digits after the decimal point.
  2. It is neither rational nor irrational, because it has no exact position on the number line.
  3. It is irrational, because any decimal that never stops is irrational.
  4. It is rational, because a repeating decimal can be written as a fraction (58/3).
Correct answer: D
A repeating decimal is rational because it equals a ratio of two integers, here 19.333… = 58/3. Only decimals that neither end nor repeat are irrational.

Q4. The Kericho temperature one day was (16 + √5)°C. Using √5 ≈ 2.236, what is this temperature to 2 decimal places, and is it rational or irrational?
  1. 18.50°C, rational
  2. 18.24°C, irrational
  3. 21.00°C, rational
  4. 18.24°C, rational
Correct answer: B
16 + √5 ≈ 16 + 2.236 = 18.236, which is 18.24 to 2 decimal places. Since √5 is irrational, adding 16 gives an irrational number.

Q5. In the Mathematical Court, a learner is asked: 'You cannot write √2 exactly, so how do you know it has a place on the number line?' Which answer is the best?
  1. It sits at the nearest whole number, which is 1.
  2. It has no exact place, because its decimal never ends, so we can only guess a spot near 1.4.
  3. It has one exact position. We cannot write it completely, but decimal approximations such as 1.4142 show that it lies between 1.414 and 1.415.
  4. It is not on the line, but only in the gaps between the rational numbers.
Correct answer: C
Every real number, rational or irrational, corresponds to exactly one point on the number line. Better and better approximations locate that point precisely, even though the number cannot be written exactly.
Use after: Explain phase — Explain: revisiting the sufuria phenomenon ('is 88 exactly at 28π?')
Q6. A sufuria has diameter 28 cm, so its circumference is exactly 28π cm, which is about 87.9646 cm. The daughter cut her string at 88 cm. On a number line of lengths, where is 88 compared with 28π?
  1. 88 is exactly at 28π, because rounding gives the exact value.
  2. 88 and 28π cannot be compared, because 28π has no position on the number line.
  3. 88 is slightly to the left of 28π.
  4. 88 is slightly to the right of 28π, so the string is a tiny bit too long.
Correct answer: D
28π ≈ 87.9646, which is less than 88, so 88 lies slightly to the right of 28π. The tiny gap is the approximation error, because 28π has an exact position but cannot be written exactly.
Use after: Model Building phase — Model: 'Kenyan Connections' box in the cumulative Real Number System Model
Q7. For the 'Kenyan Connections' box in the model, a learner must pick the irrational quantity. Which one is irrational?
  1. The circumference of a sufuria of diameter 28 cm, 28π cm
  2. A temperature of 18.75°C (= 75/4)
  3. The distance from Nairobi to Nakuru, 160 km (= 160/1)
  4. The price of unga, Ksh 60.50 (= 121/2)
Correct answer: A
28π is irrational because π is irrational, so it cannot be written as a ratio of two integers. The other three can each be written as a fraction. Whether a number is rational does not depend on how big or small it is.
