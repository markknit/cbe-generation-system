Q1. In the Ugali Pot Problem, the sufuria has a diameter of exactly 28 cm. What makes the problem puzzling?
  1. 28 is too large a number to multiply by π.
  2. The diameter 28 cm is a whole number, but 28 × π gives digits that never end or repeat.
  3. The calculator was faulty because it showed too many digits.
  4. The sufuria is not a perfect circle, so it has no exact circumference.
Correct answer: B
The puzzle is the contrast between a neat whole-number diameter and a product whose decimal digits go on forever without repeating. The lesson only raises this puzzle and does not explain it.
Use after: Predict phase — Number Sort Card: sorting into Column A ('I can write this number down completely and exactly') and Column B ('I cannot')
Q2. On the Number Sort Card, which of these Kenyan numbers can be written down completely and exactly, with its digits stopping?
  1. 87.96459430… (calculator result of 28 × π)
  2. π (the number used in the sufuria problem)
  3. 34.5 (temperature in Kisumu, °C)
  4. 0.333… (calculator form of 1/3)
Correct answer: C
34.5 has digits that stop after one decimal place, so it can be written completely. The other three go on and cannot be written out in full.
Use after: Observe phase — Calculator investigation: computation (B) 28 × 0.5
Q3. A learner uses a calculator to find the circumference of a circle with a diameter of 28 cm, using 28 × 0.5 as a first practice step. What does the calculator show for 28 × 0.5?
  1. 14
  2. 1.4
  3. 56
  4. 140
Correct answer: A
28 × 0.5 is half of 28, which is 14. The decimal stops, so it can be written exactly.
Use after: Observe phase — Calculator investigation: 'What I Observed' for computations (A), (B) and (C)
Q4. A learner calculates 28 × 3, 28 × 0.5 and 28 × π on a calculator. Which statement best describes what the learner observes?
  1. 28 × 3 and 28 × π both stop, but 28 × 0.5 goes on forever.
  2. 28 × π repeats a short block of digits such as 87.96 87.96 87.96.
  3. 28 × 3 and 28 × 0.5 stop, but 28 × π shows digits that keep going with no repeating pattern.
  4. All three answers stop after a few digits.
Correct answer: C
28 × 3 = 84 and 28 × 0.5 = 14 both stop. 28 × π = 87.96459430… keeps going with no repeating pattern.
Use after: Observe phase — Calculator investigation: computation (C) 28 × π and the daughter's string of 88 cm
Q5. The calculator shows the circumference of the sufuria as 87.96459430… cm. The daughter cuts the string to 88 cm. To 2 decimal places, how many centimetres longer is the string than 87.9645943 cm?
  1. 0.4 cm
  2. 0.96 cm
  3. 0.04 cm
  4. 0.004 cm
Correct answer: C
88 − 87.9645943 = 0.0354057, which is 0.04 cm to 2 decimal places. The 88 cm string is a rounded value, so a tiny gap or overlap remains.
Use after: Explain phase — Group sorting on the A3 sheet: teacher asks 'Is 22/7 × 7 exactly 22? What does that tell you?'
Q6. Some learners say that 22/7 and π are the same number. To test the idea, a group first works out 22/7 × 7. What is the answer?
  1. 22
  2. 154
  3. 3.14
  4. 7
Correct answer: A
22/7 × 7 = 22, because multiplying by 7 cancels the division by 7. This arithmetic does not settle whether 22/7 equals π, which the class investigates later.
Use after: End of lesson — End of lesson: after the Driving Question Board and 'My Number Landscape: Unit Model (Start)'
Q7. At the end of the first lesson, which statement about 28 × π = 87.96459430… is true of what the class has done so far?
  1. The class has learned that calculators are not accurate enough to show it.
  2. The class has found that it is exactly 28 × 22/7.
  3. The class has shown that it is exactly 88 cm.
  4. The class has seen that its digits never end or repeat, but has not yet explained why.
Correct answer: D
Learners have observed the endless, non-repeating digits and written a first hypothesis. The explanation is left for later lessons and is on the Driving Question Board.
