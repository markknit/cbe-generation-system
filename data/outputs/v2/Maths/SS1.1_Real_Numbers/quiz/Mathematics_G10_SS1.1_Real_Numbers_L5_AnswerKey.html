Q1. Four friends share a 1 kg bag of unga equally, so each gets 1/4 kg. What must you multiply 4 by to get exactly 1?
  1. 1/4
  2. −4
  3. 3
  4. 4
Correct answer: A
4 × 1/4 = 1, so 1/4 is the number that multiplies 4 to give exactly 1. Subtracting 3 would give 1 but that is not multiplication.
Use after: Observe phase — Observe: Reciprocal Table (1 ÷ 1.6 = 0.625)
Q2. In the Reciprocal Table a pair divides 1 by 1.6. What is the reciprocal of 1.6?
  1. 0.16
  2. 1.625
  3. 0.625
  4. 6.25
Correct answer: C
The reciprocal is 1 ÷ 1.6 = 0.625. Multiplying back, 1.6 × 0.625 = 1.
Use after: Observe phase — Observe: Reciprocal Table (the number −8)
Q3. Wanjiru finds the reciprocal of −8 by dividing 1 by −8. Which answer is correct?
  1. −8
  2. 8
  3. −0.125
  4. 0.125
Correct answer: C
1 ÷ (−8) = −0.125, so the sign stays negative. Check: (−8) × (−0.125) = 1.
Use after: Observe phase — Observe: Reciprocal Table (3/4) and the pattern-finding for 2/3 and 3/4
Q4. What is the reciprocal of the fraction 3/4?
  1. 3/4
  2. 1/4
  3. −3/4
  4. 4/3
Correct answer: D
1 ÷ 3/4 = 4/3, so a fraction is flipped upside down. Check: 3/4 × 4/3 = 1.
Use after: Observe phase — Observe: Reciprocal Table (1 ÷ √2 ≈ 0.7071)
Q5. Using a calculator, 1 ÷ √2 is worked out and rounded to 4 decimal places. Which value is correct?
  1. 0.5
  2. 1.4142
  3. 0.7071
  4. 0.7017
Correct answer: C
1 ÷ √2 = 1 ÷ 1.41421… = 0.70710…, which is 0.7071 to 4 decimal places. 1.4142 is √2 itself.
Use after: Explain phase — Explain: 'Why can nothing be the reciprocal of 0?'
Q6. Why does the number 0 have no reciprocal?
  1. No number multiplied by 0 gives 1, and 1 ÷ 0 is not defined
  2. 1 ÷ 0 = 0, which is not equal to 1
  3. 0 is not a real number
  4. The reciprocal of 0 is negative, so it cannot be written
Correct answer: A
A reciprocal of x must satisfy x × (1/x) = 1. Anything multiplied by 0 is 0, so no number works, and division by zero is not defined.
Use after: Explain phase — Explain: 'Is 1/π rational or irrational? How do you know?'
Q7. Is 1/π rational or irrational?
  1. Rational: the reciprocal of any number is always rational
  2. Rational: it is written as 1 over a number, so it is a fraction
  3. Irrational: it is less than 1
  4. Irrational: if 1/π were a fraction p/q, then π would be q/p, a fraction, but π is irrational
Correct answer: D
If 1/π = p/q then π = q/p would be rational, which contradicts π being irrational. So the reciprocal of an irrational number is irrational.
