Q1. Mama Wanjiru's garden is a rectangle whose length is always 3 m more than its width. If the garden is 5 m wide, what is its area?
  1. 40 m²
  2. 13 m²
  3. 25 m²
  4. 15 m²
Correct answer: A
Length = 5 + 3 = 8 m, so area = 5 × 8 = 40 m². Adding 5 + 8 gives 13 and 5 × 3 gives 15, which are common slips.
Use after: Observe phase — Observe: grid-paper rectangles and class table of widths, lengths and areas
Q2. Chebet and Kiprop drew gardens whose length is 3 m more than the width. A garden 8 m wide has area 88 m², one 9 m wide has area 108 m², and one 10 m wide has area 130 m². What pattern do these areas show?
  1. The area grows as the width grows, but it grows by less each time.
  2. The area grows by the same amount each time the width increases by 1 m.
  3. The area stays the same because the length is always 3 m more than the width.
  4. The area grows as the width grows, and it grows by more each time.
Correct answer: D
The area goes up by 20 m² (88 to 108) and then by 22 m² (108 to 130), so it grows by more each time.
Use after: Explain phase — Explain: letting width = x, length = x + 3 and area = x(x + 3)
Q3. Mama Wanjiru's garden has width x metres, and its length is 3 m more than its width. Which expression gives the area of the garden in m²?
  1. x² + 3
  2. 2x + 3
  3. x + 3
  4. x(x + 3)
Correct answer: D
The length is x + 3, so area = width × length = x(x + 3). The expression x + 3 is only the length.
Use after: Explain phase — Explain: expanding x(x + 3) using the grid
Q4. Expand x(x + 3).
  1. x + 3x
  2. x² + 3
  3. 3x²
  4. x² + 3x
Correct answer: D
Multiply x by each term in the bracket: x × x = x² and x × 3 = 3x, so x(x + 3) = x² + 3x. Testing x = 8 gives 64 + 24 = 88, which matches the table.
Use after: Explain phase — Explain: tile model of (x + 3)(x + 5)
Q5. Using area tiles, a rectangle has sides (x + 3) and (x + 5). The four parts have areas x², 5x, 3x and 15. What is the expanded expression for the total area?
  1. x² + 5x + 15
  2. x² + 8x + 15
  3. x² + 15
  4. x² + 8x + 8
Correct answer: B
Add the four parts: x² + 5x + 3x + 15. The like terms 5x and 3x combine to 8x, giving x² + 8x + 15.
Use after: Explain phase — Explain: classifying quadratic and non-quadratic expressions (thumbs up or down)
Q6. A quadratic expression is an expression whose highest power of x is 2. Which of these is a quadratic expression?
  1. x² + 8x + 15
  2. 2x + 9
  3. 3x + 7
  4. x³ + 2
Correct answer: A
x² + 8x + 15 has highest power 2. 3x + 7 and 2x + 9 have highest power 1, and x³ + 2 has highest power 3.
Use after: DQB phase — DQB Creation: questions about finding the width for a target area
Q7. At the end of the lesson, the class wrote the garden's area as x² + 3x. They found that a width of 9 m gives exactly 108 m², but only by trying widths one after another. What is the correct statement about what the class has done so far?
  1. They have explained completely why the area grows faster as the width grows.
  2. They have written the area as an expression, but they still wonder how to find the width for a target area without trial and error.
  3. They have proved that 9 m is the only possible width for any garden.
  4. They have shown how to solve for x to find the width for any target area.
Correct answer: B
The lesson only formed the area expression. Solving for the width without trial and error is a question left on the DQB for later lessons.
