Q1. Point P(3, −2) is rotated 90° anticlockwise about the origin. Using the rule (x, y) → (−y, x), what is the image P′?
  1. (−2, −3)
  2. (−2, 3)
  3. (2, 3)
  4. (−3, 2)
Correct answer: C
Substitute x = 3 and y = −2 into (−y, x): −y = 2 and x = 3, so P′ = (2, 3). (−2, −3) comes from the clockwise rule, and (−3, 2) is the 180° image.
Use after: Observe phase — Observe: pairs record the 90° CW Image column of the pre-drawn table
Q2. A triangle has a vertex at A(4, 1). It is rotated 90° clockwise about the origin. What are the coordinates of A′?
  1. (1, −4)
  2. (−4, −1)
  3. (4, −1)
  4. (−1, 4)
Correct answer: A
The 90° clockwise rule is (x, y) → (y, −x). With x = 4 and y = 1, A′ = (1, −4). (−1, 4) is the anticlockwise image, (−4, −1) is the 180° image, and (4, −1) is a reflection in the x-axis, not a rotation.
Use after: Explain phase — Explain: Kasarani application – football mark Q(2, 5) rotated 90° clockwise then 180°
Q3. A mark on a football is at Q(2, 5), with the axle of the ball as the origin. The ball turns 90° clockwise, then a further 180°, both about the axle. (The forward motion of the ball is ignored.) Where does the mark end up?
  1. (−5, −2)
  2. (−5, 2)
  3. (5, −2)
  4. (−2, −5)
Correct answer: B
Step 1: 90° clockwise (x, y) → (y, −x) gives Q′ = (5, −2). Step 2: 180° (x, y) → (−x, −y) applied to Q′ gives Q″ = (−5, 2).
Use after: Explain phase — Explain: 'Notice that 270° anticlockwise gives the same image as 90° clockwise' discussion
Q4. Which coordinate rule gives a rotation of 270° anticlockwise about the origin?
  1. (x, y) → (−x, y)
  2. (x, y) → (y, −x)
  3. (x, y) → (−x, −y)
  4. (x, y) → (−y, x)
Correct answer: B
A 270° anticlockwise turn ends in the same position as a 90° clockwise turn, so the rule is (x, y) → (y, −x). (−y, x) is 90° anticlockwise, and (−x, −y) is 180°.
Use after: Explain phase — Explain: translate-apply-translate-back for R(5, 3) about C(2, 1)
Q5. Point R(5, 3) is rotated 90° anticlockwise about the centre C(2, 1), which is not the origin. What is the image R′?
  1. (4, −2)
  2. (−2, 3)
  3. (0, 4)
  4. (−3, 5)
Correct answer: C
Translate so C is the origin: (5 − 2, 3 − 1) = (3, 2). Apply (x, y) → (−y, x) to get (−2, 3). Translate back: (−2 + 2, 3 + 1) = (0, 4). (−3, 5) comes from applying the rule directly to R, and (−2, 3) comes from forgetting to translate back.
Use after: Model Building phase — Model: final insight that (x, y) → (−y, x) preserves √(x² + y²)
Q6. Point (6, 8) is rotated 90° anticlockwise about the origin using (x, y) → (−y, x). How far is the image from the origin?
  1. 14 units
  2. 8 units
  3. 10 units
  4. 6 units
Correct answer: C
The image is (−8, 6). Its distance from the origin is √((−8)² + 6²) = √100 = 10, the same as the original point's distance √(6² + 8²) = 10, because rotation preserves distance from the centre.
Use after: End of lesson — Model: extension task – rotate the minute-hand tip (0, 5) through multiples of 90°
Q7. On a clock face grid with the centre at the origin, the tip of the minute hand is at (0, 5) at 12:00. At 12:15 the hand has turned 90° clockwise about the centre. Which point is the tip now at?
  1. (0, 5)
  2. (0, −5)
  3. (5, 0)
  4. (−5, 0)
Correct answer: C
Use the 90° clockwise rule (x, y) → (y, −x): (0, 5) → (5, −0) = (5, 0). The tip points to the right, as the minute hand does at 3 on the clock.
