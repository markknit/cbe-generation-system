Use after: Predict phase — Predict prompt (1): exponent increased by 1, from 2³ to 2⁴
Q1. On Chai Bora Estate in Kericho, one tea plant produces 2³ = 8 grams of processed tea per harvest cycle. If the exponent increased by 1, so that the output became 2⁴ grams, how many grams would one plant produce?
  1. 12 grams
  2. 24 grams
  3. 9 grams
  4. 16 grams
Correct answer: D
2⁴ = 2 × 2 × 2 × 2 = 16 grams. Learners who predict 9 or 12 are thinking of adding a fixed amount instead of multiplying.
Use after: Observe phase — Part A: Powers of 2 Table and Part B: Reading the Table (what happens when n decreases by 1)
Q2. In a powers-of-2 table built by repeated doubling, the value of 2⁸ is 256. What is the value of 2⁷?
  1. 128
  2. 255
  3. 248
  4. 512
Correct answer: A
Decreasing the exponent by 1 halves the value: 256 ÷ 2 = 128.
Use after: Observe phase — Part B: Reading the Table (estate total using 2¹⁰ from the table)
Q3. One tea plant produces 2³ = 8 grams per harvest cycle and the estate has 2¹⁰ = 1 024 plants. Using the powers-of-2 table, how many grams does the whole estate produce per cycle?
  1. 1 032 grams
  2. 8 192 grams
  3. 3 072 grams
  4. 8 000 grams
Correct answer: B
Total = 8 × 1 024 = 8 192 grams, which is about 8 kg. Adding (8 + 1 024 = 1 032) is a common slip.
Use after: Explain phase — Step 1: Index Notation (base and exponent in 2¹⁰)
Q4. In the expression 2¹⁰, which statement correctly names the parts?
  1. The base is 10 and the exponent is 2.
  2. The base is 2 and the exponent is 20.
  3. The base is 2 and the exponent is 10.
  4. The base and the exponent are both 2 × 10.
Correct answer: C
In 2¹⁰ the base (2) is the number being multiplied and the exponent (10) tells how many times it is used as a factor.
Use after: Explain phase — Step 1: Index Notation (write 3⁴ in expanded form and evaluate it)
Q5. What is the value of 3⁴?
  1. 12
  2. 64
  3. 7
  4. 81
Correct answer: D
3⁴ = 3 × 3 × 3 × 3 = 81. The answer 12 comes from multiplying 3 × 4, and 7 from adding.
Use after: Explain phase — Step 1: Index Notation (write 5 × 5 × 5 in index form)
Q6. Which of these is 5 × 5 × 5 written in index form?
  1. 3⁵
  2. 15
  3. 5 × 3
  4. 5³
Correct answer: D
The number 5 is used as a factor 3 times, so the base is 5 and the exponent is 3: 5³. 3⁵ swaps the base and the exponent.
Use after: DQB phase — Driving Question Board: Kamau's question about adding numbers in a log table
Q7. A student writes this question on the Driving Question Board: 'Why does adding two small numbers from a logarithm table give the same answer as multiplying two huge numbers?' Where does the class stand on this question at the end of Lesson 1?
  1. It is not answered yet; it is the central puzzle that the class will investigate in later lessons.
  2. It is already answered: adding the exponents is the same as doubling the plant.
  3. It is already answered: the logarithm table simply makes the numbers smaller.
  4. It cannot be answered, because logarithm tables do not give correct results.
Correct answer: A
Lesson 1 only introduces the puzzle, index notation and the doubling pattern. The question about why logarithms turn multiplication into addition is left open on the Driving Question Board for later lessons.
