Q1. If 10ⁿ = 1 000, what is the value of n?
  1. 1 000
  2. 4
  3. 3
  4. 2
Correct answer: C
1 000 = 10 × 10 × 10 = 10³, so n = 3. This is the exponent idea from index notation, which the definition of a logarithm builds on.
Use after: Observe phase — Supporting Phenomenon: pH Scale of Kenyan Foods, Observation Table
Q2. Lemon juice has a hydrogen ion concentration [H⁺] of 0.01 mol/L. How is 0.01 written as a power of 10?
  1. 10⁻¹
  2. 10²
  3. 10⁻²
  4. 10⁻¹⁰
Correct answer: C
0.01 = 1/100 = 1/10² = 10⁻². The number is less than 1, so the exponent must be negative.
Use after: Explain phase — Part A: Formal Definition (worked examples and four-item rapid conversion table)
Q3. What is the value of log₁₀ 0.001?
  1. −2
  2. −3
  3. 3
  4. 0.003
Correct answer: B
log₁₀ 0.001 = n means 10ⁿ = 0.001. Since 0.001 = 1/10³ = 10⁻³, n = −3.
Use after: Explain phase — Part B: Characteristic and Mantissa (five-item characteristic identification)
Q4. Without using tables, what is the characteristic of log₁₀ 45 200?
  1. 5
  2. 0.2
  3. 3
  4. 4
Correct answer: D
45 200 has 5 digits before the decimal point. The characteristic is one less than that, so 5 − 1 = 4. This is because 10⁴ ≤ 45 200 < 10⁵.
Use after: Explain phase — Part B: Characteristic and Mantissa (worked example log₁₀ 3,500 ≈ 3.5441)
Q5. log₁₀ 3 500 = 3.5441. What is the mantissa of this logarithm?
  1. 3.5441
  2. 3
  3. 0.3544
  4. 0.5441
Correct answer: D
The mantissa is the decimal part of the logarithm, which is 3.5441 − 3 = 0.5441. The characteristic is the whole-number part, 3.
Use after: Explain phase — Part C: Reading Four-Figure Tables (teacher models log₁₀ 3,142 using the mean-difference column)
Q6. A student uses a four-figure logarithm table to find log₁₀ 3 142. Row 31, column 4 gives 0.4969. The mean difference for the fourth digit 2 is 3 (that is, 0.0003). What is log₁₀ 3 142?
  1. 3.4972
  2. 3.4969
  3. 2.4972
  4. 3.4999
Correct answer: A
3 142 has 4 digits, so the characteristic is 3. The mantissa is 0.4969 + 0.0003 = 0.4972, so log₁₀ 3 142 = 3.4972.
Use after: Explain phase — Part C: Table-Reading Record (pairs look up log₁₀ 0.064)
Q7. From a four-figure table, log₁₀ 0.064 = 2̄.8062, which means −2 + 0.8062. What is this as a single decimal number?
  1. −2.1938
  2. −2.8062
  3. 1.1938
  4. −1.1938
Correct answer: D
The characteristic is −2 and the mantissa stays positive at 0.8062. So −2 + 0.8062 = −1.1938.
Use after: Model Building phase — Model Building: Concept Map 'LOGARITHM SIDE' bridge statement
Q8. Which statement best describes what a common logarithm is?
  1. It is the number divided by 10.
  2. It is the exponent (power) to which 10 must be raised to give the number.
  3. It is the number of digits in the number.
  4. It is the answer you get when you multiply a number by 10.
Correct answer: B
log₁₀ x = n means 10ⁿ = x, so a logarithm is the exponent rewritten on the other side of the equation. Number of digits relates only to the characteristic, not the whole logarithm.
