Q1. Kamau must evaluate (2.374 × 0.8163³) ÷ √54.72 using four-figure tables. Which line correctly shows the logarithm of this whole expression?
  1. log 2.374 × 3 log 0.8163 ÷ ½ log 54.72
  2. log 2.374 + 3 log 0.8163 − 2 log 54.72
  3. log 2.374 + 3 log 0.8163 − ½ log 54.72
  4. log 2.374 + (log 0.8163)³ − √(log 54.72)
Correct answer: C
Multiplication becomes addition (product law), division becomes subtraction (quotient law), the cube becomes 3 × the log (power law) and the square root becomes ½ × the log (root law).
Use after: Observe phase — Observe Phase: 3-minute bar-number demonstration (cubing log 0.8163)
Q2. log 0.8163 = 1̄.9119, which means −1 + 0.9119. What is the value of 3 × 1̄.9119 written as an ordinary decimal?
  1. 2.7357
  2. −5.7357
  3. −0.2643
  4. −2.7357
Correct answer: C
3 × (−1 + 0.9119) = −3 + 2.7357 = −0.2643, which is written as the bar number 1̄.7357. Reading 1̄.9119 as −1.9119 would wrongly give −5.7357.
Use after: Observe phase — Observe Phase: 3-minute bar-number demonstration (halving a bar number)
Q3. log 0.6731 = 1̄.8281. Which of these is half of 1̄.8281, that is, the logarithm of √0.6731?
  1. 0.4141
  2. 2̄.9140
  3. 1̄.9140
  4. 1̄.4141
Correct answer: C
First rewrite 1̄.8281 as 2̄ + 1.8281 so the negative part divides evenly. Half of this is 1̄ + 0.9140 = 1̄.9140. Halving only the decimal part gives the wrong answer 1̄.4141.
Use after: Observe phase — Observe Phase: groups complete the log-table template for Problem A
Q4. In Problem A, log 2.374 = 0.3755 and log (0.8163³) = −0.2643 (that is, 1̄.7357). What is the logarithm of the numerator 2.374 × 0.8163³?
  1. −0.0993
  2. 1.1265
  3. 0.6398
  4. 0.1112
Correct answer: D
By the product law, log of a product is the sum of the logs: 0.3755 + (−0.2643) = 0.1112. Multiplying the logs, or ignoring the negative sign, are common errors.
Use after: Explain phase — Explain Phase: class builds the Problem A solution step by step, naming the antilog step
Q5. In Problem A the logarithm of the final answer is 1̄.242 (that is, −1 + 0.242). From the antilogarithm table, the antilog of 0.242 is 1.746. What is the value of the answer?
  1. 17.46
  2. 1.746
  3. 0.01746
  4. 0.1746
Correct answer: D
The bar 1̄ means the answer is 1.746 × 10⁻¹, so the answer is 1.746 ÷ 10 = 0.1746.
Use after: Explain phase — Explain Phase: discussion on why changing the exponent from 2³ to 2⁴ doubles the harvest
Q6. A tea plant yields 2³ grams per harvest and the estate has 2¹⁰ plants, so the total is 2¹³ = 8 192 grams. If each plant's yield rises to 2⁴ grams and there are still 2¹⁰ plants, what is the new total in grams?
  1. 16 384
  2. 8 193
  3. 32 768
  4. 12 288
Correct answer: A
2⁴ × 2¹⁰ = 2¹⁴ = 16 384. Increasing the index by 1 doubles the value, so the total doubles from 8 192 to 16 384, not 'adds 1'.
Use after: DQB phase — DQB Phase: Final Explanation of how logarithms convert multiplication to addition
Q7. Logarithms turn multiplication into addition: log (a × b) = log a + log b. Which index law is this product law of logarithms based on?
  1. aᵐ ÷ aⁿ = aᵐ⁻ⁿ
  2. a⁰ = 1
  3. (aᵐ)ⁿ = aᵐⁿ
  4. aᵐ × aⁿ = aᵐ⁺ⁿ
Correct answer: D
A logarithm is an index. Multiplying numbers with the same base adds their indices (aᵐ × aⁿ = aᵐ⁺ⁿ), so the logs of the numbers add when the numbers are multiplied.
