Q1. Kamau the boda-boda rider travels vector d = (2, 1) km from Kencom (2 km east, 1 km north). He makes the SAME trip 3 times in a row from the same start. Which single vector describes his total journey?
  1. (5, 4)
  2. (6, 3)
  3. (6, 1)
  4. (2, 3)
Correct answer: B
Making the trip 3 times is 3d, so each component is multiplied by 3: (3×2, 3×1) = (6, 3). Adding 3 to each component, or multiplying only one component, are common errors.
Use after: Observe phase — Observe: construction (D) Draw −2d on the Nairobi-style grid
Q2. On a grid where each square is 1 km, vector d = (2, 1) means 2 km east and 1 km north. Which column vector is −2d?
  1. (−4, −2)
  2. (−2, −1)
  3. (−4, −1)
  4. (4, 2)
Correct answer: A
−2d = −2 × (2, 1) = (−4, −2), which is 4 km west and 2 km south. The negative sign reverses the direction and the 2 doubles the size.
Use after: Observe phase — Observe: observation table (direction and line of action columns) and one-sentence summary
Q3. Vector d is 2 km east and 1 km north from Kencom. Compared with d, the vector −2d:
  1. is twice as long, points in the same direction as d, and lies on the same line as d
  2. is twice as long, points in the opposite direction, and lies on the same line as d
  3. is twice as long, points in the opposite direction, and lies on a different line from d
  4. is the same length as d, points in the opposite direction, and lies on a different line
Correct answer: B
The magnitude is |−2| × |d| = 2|d|, so it is twice as long. The negative scalar reverses the direction, but the vector stays on the same line of action as d.
Use after: Explain phase — Explain: Akinyi's Kisumu application problem (write 2r, −r, ½r in column form)
Q4. Akinyi's matatu covers vector r = (3, −4) km from Kisumu Bus Park to Dunga Beach. What is ½r?
  1. (−1.5, 2)
  2. (1.5, 2)
  3. (6, −8)
  4. (1.5, −2)
Correct answer: D
Multiply each component by ½: (½×3, ½×(−4)) = (1.5, −2). The direction is unchanged because ½ is positive.
Use after: Explain phase — Explain: Akinyi's Kisumu application problem (calculate the magnitude of each)
Q5. Akinyi's matatu covers vector r = (3, −4) km from Kisumu Bus Park to Dunga Beach. What is the magnitude of 2r?
  1. 10 km
  2. 5 km
  3. 25 km
  4. 14 km
Correct answer: A
2r = (6, −8), so the magnitude = √(6² + (−8)²) = √100 = 10 km. This is also 2 × |r| = 2 × 5.
Use after: Explain phase — Explain: vector subtraction practice with a = (5, 2) and b = (3, 6)
Q6. Given a = (5, 2) and b = (3, 6), what is a − b?
  1. (8, 8)
  2. (2, −4)
  3. (2, 4)
  4. (−2, 4)
Correct answer: B
a − b = a + (−b) = (5, 2) + (−3, −6) = (2, −4). Getting (−2, 4) means b − a was worked out by mistake.
Use after: Explain phase — Explain: connecting subtraction to the phenomenon (journey from Westlands to South B)
Q7. Vector w is the journey from Kencom to Westlands. Vector s is the journey from Kencom to South B. Which expression describes the journey from Westlands to South B?
  1. w + s
  2. s + (−w)
  3. −w − s
  4. w − s
Correct answer: B
To go from Westlands to South B, first reverse the trip to Kencom (−w), then go on to South B (s). This gives s + (−w), which is s − w.
Use after: End of lesson — Model: exit-ticket question on v = (4, −3), write −2v and state its magnitude
Q8. A vector v = (4, −3). Without a calculator, what is the magnitude of −2v?
  1. −10
  2. 10
  3. 7
  4. 5
Correct answer: B
−2v = (−8, 6), so the magnitude = √(64 + 36) = √100 = 10. Magnitude is never negative, because the negative sign only reverses the direction.
