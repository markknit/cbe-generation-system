Q1. On a Nakuru map, a matatu leg goes from Westside Mall to the ASK Showground: 5 km East and 2 km South. Taking East as positive x and North as positive y, which column vector describes this leg?
  1. (-5; 2)
  2. (5; -2)
  3. (2; -5)
  4. (5; 2)
Correct answer: B
East is positive x, so 5 km East gives +5. South is negative y, so 2 km South gives -2. The vector is (5; -2).
Use after: Explain phase — Explain: Task 2 – add the three column vectors to find the resultant displacement
Q2. A three-leg journey in Nakuru has leg vectors (3; 4), (5; -2) and (-2; 6), each in km. What is the resultant displacement vector?
  1. (8; 6)
  2. (0; 0)
  3. (6; 8)
  4. (10; 12)
Correct answer: C
Add the matching components: x = 3 + 5 + (-2) = 6 and y = 4 + (-2) + 6 = 8. The resultant is (6; 8).
Use after: Explain phase — Explain: Task 3 – find the magnitude of the resultant displacement vector
Q3. The resultant displacement of a journey from Nakuru CBD Terminus to Lake Nakuru Viewpoint is (6; 8) km. What is the magnitude of this vector, that is, the straight-line distance from start to finish?
  1. 100 km
  2. 7 km
  3. 14 km
  4. 10 km
Correct answer: D
Use Pythagoras' theorem: magnitude = sqrt(6² + 8²) = sqrt(36 + 64) = sqrt(100) = 10 km.
Use after: Explain phase — Explain: Task 4 – find the position vector of the endpoint and the midpoint of the journey
Q4. A journey starts at point S with position vector (2; 1) and ends at point F with position vector (8; 9), relative to origin O. What is the position vector of the midpoint of the journey from S to F?
  1. (6; 8)
  2. (5; 5)
  3. (4; 4)
  4. (10; 10)
Correct answer: B
The midpoint is half the sum of the position vectors: ½[(2; 1) + (8; 9)] = ½(10; 10) = (5; 5). (6; 8) is the displacement from S to F, not the midpoint.
Use after: Explain phase — Observe/Explain: comparing total path distance with the straight-line distance from Nakuru CBD Terminus to Lake Nakuru Viewpoint
Q5. A matatu journey has three legs of lengths 5 km, about 5.4 km and about 6.3 km, so the total path is about 16.7 km. The resultant displacement from start to finish has magnitude 10 km. Why is the 10 km smaller than the 16.7 km?
  1. Displacement is always exactly half of the total path distance
  2. Vectors cannot be added, so the 10 km is only an estimate
  3. The displacement is the straight-line distance from start to finish, while the path distance follows every change of direction
  4. Some of the leg distances were measured wrongly
Correct answer: C
The path distance adds the lengths of all legs, which turn in different directions. The displacement is the single straight-line vector from start to end, so it is shorter.
Use after: DQB phase — DQB: writing the Final DQB Answer on the Kencom to Westlands vs Kencom to South B phenomenon
Q6. Two matatus leave Kencom Bus Stop in Nairobi and each travels exactly 8 km. One ends at Westlands and the other ends at South B. What best explains why they end at different places?
  1. Distance is a vector, so equal distances should give equal destinations
  2. They have the same distance (a scalar) but different directions, so their displacement vectors are different
  3. They have the same displacement vector but different speeds
  4. The matatus travelled different distances
Correct answer: B
Distance is a scalar and gives only magnitude. A displacement vector also needs direction. Equal magnitudes with different directions give different end points.
Use after: Model Building phase — Model: Final Model – the translation vector mapping start to end, and Explain Task 5
Q7. The translation vector that maps the start point of a journey to its end point is (6; 8), in km. A boda-boda rider is told this vector. What does it tell the rider?
  1. Move 14 km in any direction
  2. Move 10 km, and the direction does not matter
  3. Move 6 km East and 8 km North from the start point
  4. Move 6 km North and then 8 km East
Correct answer: C
The top component is the x (East) movement and the bottom component is the y (North) movement. So (6; 8) means 6 km East and 8 km North. This is a vector, so it gives both magnitude (10 km) and direction.
