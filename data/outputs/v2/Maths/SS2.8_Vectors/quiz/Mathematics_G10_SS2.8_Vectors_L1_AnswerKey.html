Q1. Two matatus leave Kencom Bus Stop in Nairobi's CBD. Each is labelled '8 km'. One ends at Westlands and the other at South B. What information does the label '8 km' give?
  1. How far the matatu travels and which way it goes
  2. How far the matatu travels, but not which way it goes
  3. Which stage the matatu ends at
  4. How long the journey takes and which road is used
Correct answer: B
The label '8 km' only states the distance travelled. It does not say which way the matatu goes, so it cannot tell us where the journey ends. The time, the road and the final stage are not given in it.
Use after: Observe phase — Activity A: Map Analysis, observation question 1 'What is the same about Route A and Route B?'
Q2. Two matatus start at Kencom Bus Stop. Route A is 8 km towards Westlands (northwest) and Route B is 8 km towards South B (southeast). Which is something that is the SAME about the two routes?
  1. Both take exactly the same road
  2. Both start at Kencom and both are 8 km long
  3. Both end at the same place
  4. Both travel in the same direction
Correct answer: B
Both routes start at Kencom and both have a distance of 8 km. They end at different places, and they head in different directions along different roads.
Use after: Observe phase — Activity B: Live Demonstration with 8 steps north and 8 steps east
Q3. In class, one learner walks 8 steps north from a starting point. Another learner walks 8 steps east from the same starting point. What do we observe?
  1. Both take 8 steps but they end up in different places
  2. Both take 8 steps so they end up in the same place
  3. The learner walking north walks further because north is up
  4. The learner walking east takes more steps to get there
Correct answer: A
Both learners take the same number of steps (8) from the same start. They walk in different directions, so they end at different places.
Use after: Explain phase — Classification activity: eight Kenyan-context quantities, item 8 (bodaboda velocity) compared with items 1, 3 and 7
Q4. Which of these quantities is a VECTOR?
  1. The temperature in Nairobi today: 22°C
  2. The time taken to cook ugali: 20 minutes
  3. The velocity of a bodaboda travelling at 40 km/h heading south on Ngong Road
  4. The mass of a bag of maize at Wakulima Market: 90 kg
Correct answer: C
A vector needs both magnitude and direction. Only the velocity gives a size (40 km/h) and a direction (south). Temperature, mass and time have size only, so they are scalars.
Use after: Explain phase — Definition phase: 'Is 8 km a scalar or a vector?' and '8 km northwest from Kencom towards Westlands'
Q5. Compare two statements: (i) 'A matatu travels 8 km.' (ii) 'A matatu travels 8 km northwest from Kencom towards Westlands.' Which choice classifies them correctly?
  1. Both are scalars because both give 8 km
  2. Both are vectors because both describe a journey
  3. (i) is a vector because it has a distance; (ii) is a scalar because it has a place name
  4. (i) is a scalar because it has size only; (ii) is a vector because it has size and direction
Correct answer: D
A scalar is described completely by its magnitude only, which fits '8 km'. A vector needs magnitude and direction, which fits '8 km northwest'. Having a number or describing a journey does not make a quantity a vector.
Use after: Explain phase — Whole-class debrief of the classification activity: item 2 (wind speed at Kisumu Airport)
Q6. The wind speed at Kisumu Airport is 15 km/h, blowing from Lake Victoria towards the east. A learner says this is a scalar because it is only a speed. Which response is correct?
  1. It is a scalar, because any speed is a scalar
  2. It is a vector, because the direction (towards the east) is stated as well as the size (15 km/h)
  3. It is a vector, because 15 is a large number
  4. It is a scalar, because wind cannot have a direction
Correct answer: B
The quantity includes the phrase 'towards the east', so it gives magnitude and direction and is a vector. The learner read only the magnitude. '15 km/h' alone, with no direction, would be a scalar.
Use after: Model Building phase — Initial model: drawing Route A and Route B on the 4×4 grid with Kencom at the centre
Q7. A grid has Kencom Bus Stop at the centre. Which drawing correctly shows the two matatu routes from the puzzle (Route A to Westlands, Route B to South B)?
  1. One arrow from Kencom pointing northwest labelled 8 km, and another from Kencom pointing southeast labelled 8 km
  2. Two arrows from Kencom both pointing northwest, one labelled 8 km and the other labelled 4 km
  3. One arrow pointing northwest labelled 8 km and another pointing southeast labelled 3 km
  4. Two arrows from Kencom both pointing northwest, both labelled 8 km
Correct answer: A
Both routes are 8 km long but go in different directions. So the two arrows must start at Kencom, have the same distance label, and point northwest and southeast.
