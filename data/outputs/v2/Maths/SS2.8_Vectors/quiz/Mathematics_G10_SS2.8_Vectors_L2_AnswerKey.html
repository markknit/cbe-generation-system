Q1. Two straight lines are each exactly 8 cm long, but they point in different directions. They have no arrowheads and no labels. A student says, "These two lines are enough to describe two different matatu journeys." What is the best response?
  1. They are not enough: a plain line shows only length, so we need an arrowhead to show direction
  2. They are not enough, because the lines must be longer than 8 cm to show a journey
  3. They are enough, because lines of equal length always describe the same journey
  4. They are enough, because a plain line already shows both distance and direction
Correct answer: A
A plain line segment gives only length (magnitude). An arrowhead is needed to show which way the journey goes, so the journey is fully described by a directed line segment.
Use after: Observe phase — Observe: tracing the Kencom routes as arrow-headed line segments on the Nairobi grid-map worksheet
Q2. A learner draws the journey from Kencom (point K) to Westlands (point W) as a vector. Where should the arrowhead be placed?
  1. At K, the starting point, because that is where the journey begins
  2. At both K and W, so the journey can be read either way
  3. At W, the destination, because the head of the vector shows the direction of travel
  4. Nowhere; only the length of the line is needed
Correct answer: C
The tail of a vector is at the start (K) and the head, marked with the arrowhead, is at the destination (W). A common error is placing the arrowhead at the tail.
Use after: Observe phase — Observe: labelling the Westlands arrow with column vector notation
Q3. On a square grid, 1 square = 1 km, east and north are positive. A matatu journey goes 6 km west and 5 km north. Which column vector (x-component on top, y-component below) describes this journey?
  1. −6 on top, 5 below
  2. −6 on top, −5 below
  3. 6 on top, 5 below
  4. 5 on top, −6 below
Correct answer: A
The x-component comes first. Going 6 km west gives x = −6 and going 5 km north gives y = +5, so the column vector is (−6, 5).
Use after: Explain phase — Explain: Notation Translation Table (column vector to geometric arrow description)
Q4. A vector is written as the column vector (3, −4), with the x-component on top and the y-component below. Which arrow does it describe?
  1. 3 units to the left and 4 units up
  2. 3 units to the right and 4 units up
  3. 4 units to the right and 3 units down
  4. 3 units to the right and 4 units down
Correct answer: D
The x-component 3 is positive, so the arrow goes 3 units right. The y-component −4 is negative, so it goes 4 units down.
Use after: Explain phase — Explain: equivalent-vectors task (vectors P, Q and R compared with the Westlands vector)
Q5. The Westlands journey is the vector (−6, 5), drawn as an arrow starting at Kencom. A second arrow is drawn on the same grid starting at a different point. It also has column vector (−6, 5). Which statement is correct?
  1. The two arrows are equivalent, because they have the same magnitude and the same direction
  2. The two arrows are different vectors, because they start at different points
  3. The two arrows are equivalent only if they have the same length, even if the directions differ
  4. The two arrows are equivalent only if they end at the same point
Correct answer: A
Equivalent vectors have identical column vectors, meaning the same magnitude and direction. Where the arrow is drawn on the grid does not change the vector.
Use after: DQB phase — Driving Question Board: 'We now know...' sticky note about arrows and notation
Q6. Which statement about vectors is correct?
  1. A vector is an arrow whose arrowhead shows magnitude and whose length shows direction
  2. A vector is a directed line segment: its length shows magnitude and its arrowhead shows direction
  3. A vector can be written only as a bold letter, never as a column
  4. A vector is any straight line, because the length alone tells us everything about the journey
Correct answer: B
A vector is represented by a directed line segment. Its length encodes magnitude and its arrowhead encodes direction. It can be written in several forms, including bold, underline, letter-pair and column notation.
Use after: Model Building phase — Model Building: upgrading the Lesson 1 sketch-model and writing the model caption
Q7. Two matatus each travel 8 km from Kencom. One goes north-west to Westlands and the other goes south-east to South B. Which sentence correctly completes this model caption? "The two journey vectors are not equivalent because ____."
  1. they both start at Kencom
  2. they have the same magnitude but different directions
  3. they are both measured in kilometres
  4. they have different magnitudes
Correct answer: B
Both journeys are 8 km, so the magnitudes are equal. North-west and south-east are different directions, so the vectors are not equivalent. Equal magnitude alone is not enough.
