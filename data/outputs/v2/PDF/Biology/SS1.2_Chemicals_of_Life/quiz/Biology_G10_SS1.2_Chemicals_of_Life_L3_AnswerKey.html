Use after: Observe phase — Test 1: iodine test for starch
Q1. A group adds 2-3 drops of iodine solution to some maize flour mixed with water. Which result shows that starch is present?
  1. The mixture turns brick-red
  2. The mixture turns blue-black
  3. The mixture turns yellow-orange and stays clear
  4. The mixture turns green
Correct answer: B
Iodine turns blue-black when starch is present. Brick-red and green are Benedict's test colours for reducing sugar, not iodine results.
Use after: Observe phase — Test 2: Benedict's test for reducing sugars
Q2. A learner mixes 2 cm3 of mashed ripe banana solution with 2 cm3 of Benedict's solution and heats it in a hot water bath for 4 minutes. It turns orange to brick-red. What does this show?
  1. The banana contains starch
  2. The banana contains a lot of reducing sugar
  3. The banana contains protein
  4. The banana contains no carbohydrate
Correct answer: B
Benedict's solution changes from blue through green, yellow and orange to brick-red as the amount of reducing sugar increases, so orange to brick-red means a lot of reducing sugar is present.
Use after: Explain phase — Explain Step 1: group discussion on ugali being blue-black with iodine but blue with Benedict's
Q3. Ugali turns blue-black with iodine solution but stays blue when heated with Benedict's solution. What does this tell us about the carbohydrate in ugali before digestion?
  1. It contains starch but no reducing sugar such as glucose
  2. It contains no carbohydrate
  3. It contains both starch and a lot of glucose
  4. It contains glucose but no starch
Correct answer: A
Blue-black with iodine shows starch is present. Benedict's staying blue shows there is no reducing sugar (glucose) in the ugali before digestion.
Use after: Explain phase — Explain Step 2: bead or paper-chain model of starch breaking into glucose
Q4. Ugali has no reducing sugar, yet Wanjiru's blood glucose went up after she ate it. Which statement best explains this?
  1. Starch is already glucose, so it passes straight into the blood
  2. Beans turn into starch in the stomach, which raises the glucose
  3. Starch changes into protein, which then enters the blood as glucose
  4. Starch is made of many glucose units joined together, so it must be broken down into glucose before entering the blood
Correct answer: D
Starch is a large carbohydrate made of many glucose units. It must be broken down into single glucose units (monosaccharides) before glucose can enter the blood.
Use after: Explain phase — Explain Step 3: using the numbers from the graph to write the CER statement
Q5. Wanjiru's blood glucose concentration was 4.5 mmol/L before lunch and reached a peak of 8.0 mmol/L after 60 minutes. By how much did it rise, in mmol/L?
  1. 3.0
  2. 3.5
  3. 12.5
  4. 4.5
Correct answer: B
Rise = peak minus starting value = 8.0 - 4.5 = 3.5 mmol/L.
Use after: DQB phase — DQB: sorting sticky notes into answered, partly answered and still to investigate
Q6. After today's food tests, the class DQB has these four questions. Which one can the class now answer using the test results?
  1. Does the body use only carbohydrates for energy?
  2. Why did Wanjiru's blood glucose fall after 60 minutes?
  3. Which enzyme breaks starch into glucose?
  4. Do ugali and maize flour contain starch?
Correct answer: D
The blue-black iodine result for ugali and maize flour answers this directly. The other questions need further investigation in later lessons.
Use after: Model Building phase — Revising the class flow-diagram model: adding evidence to the 'Food chemicals' box
Q7. Which statement about the chain from ugali to blood glucose is supported by today's evidence and should be added to the 'food chemicals' box of the class model?
  1. Ugali contains starch, which is made of glucose units, so it can be a source of the glucose in the blood
  2. Nyama choma gives a blue-black result with iodine, so it is the main source of starch in Wanjiru's lunch
  3. Ugali gives a brick-red result with Benedict's solution, so it already contains glucose
  4. Only sweet foods contain carbohydrates, so ugali cannot be a source of glucose
Correct answer: A
Ugali is blue-black with iodine, so it contains starch, and starch is made of glucose units. Ugali stays blue with Benedict's, and nyama choma does not give a positive starch test.
