Q1. A scientist removes the brain neurosecretory cells (the cells that make Brain Hormone) from a young caterpillar. What do you predict will happen to the caterpillar's moulting?
  1. It will stop moulting because the signal that starts the process is missing
  2. It will turn into a pupa straight away
  3. It will moult more often because the brain no longer slows growth
  4. It will moult as normal because the shell splits by itself
Correct answer: A
Brain Hormone signals the prothoracic glands to release Ecdysone, which triggers moulting. Without the first signal, no Ecdysone is released and moulting stops.
Use after: Observe phase — Part A: 3-row hormone table (Brain Hormone, Ecdysone, Juvenile Hormone) using reference texts and data sheets
Q2. Which gland releases Ecdysone after it receives the signal from Brain Hormone?
  1. Prothoracic glands
  2. Corpora allata
  3. Malpighian tubules
  4. Salivary glands
Correct answer: A
Brain Hormone from the neurosecretory cells stimulates the prothoracic glands to release Ecdysone. The corpora allata make Juvenile Hormone instead.
Use after: Observe phase — Part B: Experiment 2, larva with brain removed then injected with Ecdysone (moult resumes)
Q3. In an experiment, a larva has its brain neurosecretory cells removed and it stops moulting. The same larva is then injected with Ecdysone and it starts to moult again. What does this result show?
  1. Ecdysone is made by the brain neurosecretory cells
  2. Ecdysone triggers moulting and acts after the brain signal
  3. Moulting does not need any hormones
  4. Ecdysone keeps the larva in the larval form
Correct answer: B
Moulting stopped when the brain signal was removed and resumed when Ecdysone was replaced. This shows Ecdysone is the hormone that triggers moulting and works after the brain signal.
Use after: Observe phase — Part B: Experiment 4, larva with corpora allata removed early (small, early pupa)
Q4. In an experiment, the corpora allata (which make Juvenile Hormone) are removed from a young larva. It changes early into a small pupa. What does this show about Juvenile Hormone?
  1. Juvenile Hormone is made by the prothoracic glands
  2. Juvenile Hormone is needed to trigger every moult
  3. Juvenile Hormone keeps the larval state, so low Juvenile Hormone allows pupation
  4. High Juvenile Hormone makes a larva change into a pupa early
Correct answer: C
With the corpora allata removed, Juvenile Hormone is low. The larva pupates early and stays small. So Juvenile Hormone normally keeps the insect in the larval state, and low levels allow the change to a pupa.
Use after: Explain phase — Explain: CER writing and oral probe 'What would happen if JH stayed high at the last larval moult?'
Q5. A farmer in the Rift Valley has an armyworm larva that is about to make its last larval moult. Suppose Juvenile Hormone stayed high at this moult. What would you expect to happen?
  1. It would moult straight into an adult moth
  2. It would stop moulting because Ecdysone is blocked completely
  3. It would moult into a pupa as normal
  4. It would moult into another larva instead of a pupa
Correct answer: D
High Juvenile Hormone gives a larva-to-larva moult. Pupation needs low Juvenile Hormone, so the larva would moult into a larger larva instead.
Use after: Model Building phase — Model: annotating the stepped growth curve from Lesson 3 with the hormone control layer
Q6. A student annotates a stepped growth curve for a grasshopper. Each sudden upward step in body size marks a moult. What should the student write about Ecdysone at each step?
  1. Ecdysone peaks at the step, because it triggers moulting
  2. Ecdysone is lowest at the step, because it keeps the old cuticle in place
  3. Ecdysone is only made after the insect becomes an adult
  4. Ecdysone is absent during the whole life cycle
Correct answer: A
Ecdysone triggers moulting. The upward steps in the stepped growth curve match the moults, when Ecdysone peaks. The flat parts match the period when the new cuticle hardens.
Use after: End of lesson — End of lesson: exit ticket 'Brain Hormone, Ecdysone and Juvenile Hormone work together by...'
Q7. Which sequence correctly shows how hormones control a moult in an insect?
  1. Corpora allata, then Ecdysone, then Brain Hormone, then moult
  2. Brain Hormone, then the prothoracic gland releases Ecdysone, then moult; Juvenile Hormone decides the type of moult
  3. Ecdysone, then the prothoracic gland, then Brain Hormone, then moult
  4. Juvenile Hormone, then Brain Hormone, then the prothoracic gland, then Ecdysone
Correct answer: B
Brain Hormone signals the prothoracic gland, which releases Ecdysone to trigger the moult. Juvenile Hormone from the corpora allata decides the kind of moult: larva to larva, larva to pupa or pupa to adult.
