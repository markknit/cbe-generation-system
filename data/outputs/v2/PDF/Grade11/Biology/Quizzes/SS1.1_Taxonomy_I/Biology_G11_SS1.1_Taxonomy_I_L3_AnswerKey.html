Q1. A Kenyan address goes from the biggest area to the smallest area. Scientists place organisms in groups inside groups in a similar way. Which list of address levels is in the correct order from biggest to smallest?
  1. County, Country, Ward, Sub-county, Village
  2. Country, County, Sub-county, Ward, Village
  3. Village, Ward, Sub-county, County, Country
  4. Country, Village, Ward, Sub-county, County
Correct answer: B
A country contains counties, which contain sub-counties, then wards, then villages. The address is a nested system, just like taxonomic ranks, which go from the biggest group to the smallest.
Use after: Observe phase — Card sorting investigation, Step 1: arrange the rank cards from broadest to most specific
Q2. Which list shows the seven taxonomic ranks in the correct order from the broadest group to the most specific group?
  1. Kingdom, Phylum/Division, Class, Family, Order, Genus, Species
  2. Kingdom, Class, Phylum/Division, Order, Family, Genus, Species
  3. Species, Genus, Family, Order, Class, Phylum/Division, Kingdom
  4. Kingdom, Phylum/Division, Class, Order, Family, Genus, Species
Correct answer: D
The correct order from broadest to most specific is Kingdom, Phylum/Division, Class, Order, Family, Genus, Species. One distractor reverses Order and Family, one swaps Phylum and Class, and one lists the ranks from most specific to broadest.
Use after: Observe phase — Card sorting investigation, Step 3: 'funnel' diagram counting organisms at each rank
Q3. As you move down the ranks from Kingdom to Species, what happens to the number of organisms in each group and to the features they share?
  1. There are fewer organisms in each group and they share fewer features
  2. The number of organisms and the shared features stay the same
  3. There are fewer organisms in each group and they share more features
  4. There are more organisms in each group and they share more features
Correct answer: C
Each rank is nested inside the one above it, so groups get smaller. Organisms in a smaller group are more alike, so they share more features. The funnel diagram in the activity shows this.
Use after: Observe phase — Card sorting investigation, Step 2: match organism-category cards to each rank for the maize plant
Q4. Maize is classified in this order from broadest to most specific: Plantae, Angiospermophyta, Monocotyledonae, Poales, Poaceae, Zea, Zea mays. Which taxonomic rank is Poaceae?
  1. Genus
  2. Family
  3. Class
  4. Order
Correct answer: B
The ranks run Kingdom (Plantae), Division (Angiospermophyta), Class (Monocotyledonae), Order (Poales), Family (Poaceae), Genus (Zea), Species (Zea mays). Poaceae is the fifth group, so it is the Family.
Use after: Explain phase — Claim-Evidence-Reasoning: How are the taxonomic ranks related from the largest group to the smallest?
Q5. A Kikuyu speaker, a Luo speaker and a Kiswahili speaker each use a different local name for the same animal. Why does the nested ranking system (Kingdom to Species) help them?
  1. It gives every organism one exact place in the system, so all of them can find the same organism whatever its local name
  2. It replaces all local names so that people stop using them
  3. It puts all animals with similar local names into the same group
  4. It sorts organisms by where they live, so everyone agrees on the habitat
Correct answer: A
Nesting gives each organism one unique position from Kingdom to Species, so people who use different local names can still identify the same organism. The system does not sort by habitat and does not need local names to be abandoned.
Use after: Explain phase — Class discussion after Claim-Evidence-Reasoning: clarifying Phylum and Division
Q6. Animals are placed in a Phylum. What is the name of the rank at the same level, directly below Kingdom, that is used for plants such as maize?
  1. Class
  2. Genus
  3. Division
  4. Family
Correct answer: C
The second rank is called Phylum for animals and Division for plants. Class, Family and Genus are lower ranks and are not the plant version of Phylum.
Use after: Model Building phase — Model revision: adding the 'nested ladder' section with the lion (Panthera leo) and maize (Zea mays) examples
Q7. The lion is classified as Animalia, Chordata, Mammalia, Carnivora, Felidae, Panthera, Panthera leo. Maize is classified as Plantae, Angiospermophyta, Monocotyledonae, Poales, Poaceae, Zea, Zea mays. Comparing the two lists rank by rank, in how many of the seven ranks do the lion and maize belong to the same group?
  1. 2 ranks
  2. 7 ranks
  3. 1 rank
  4. 0 ranks
Correct answer: D
The lion and maize already differ at Kingdom (Animalia and Plantae). Because each rank is nested inside the one above, they are in different groups at every rank below it too, so they share no group at any of the seven ranks.
