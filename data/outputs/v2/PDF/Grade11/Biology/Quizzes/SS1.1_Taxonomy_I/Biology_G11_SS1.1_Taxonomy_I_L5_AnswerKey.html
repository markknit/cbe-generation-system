Use after: Predict phase — Predict: individual prediction and Think-Pair-Share on problems that arise when people use only their own local names
Q1. A farmer in Kisumu and a researcher in Nairobi each use only their own local name for a mosquito species when sharing information about malaria control. What problem is most likely to happen?
  1. Local names are always wrong, so neither person can describe the mosquito
  2. The mosquito will change its behaviour depending on the name used
  3. They may not be sure they are talking about the same organism, so mistakes can happen
  4. The mosquito can only be studied by people who speak Kiswahili
Correct answer: C
Common names vary by place and language, so two people may use different names for the same organism, or the same name for different ones. This causes confusion in farming, medicine and pest control.
Use after: Observe phase — Part A: Name Comparison Table, examples where one common name refers to different organisms
Q2. In some countries the word 'corn' means maize, but in other countries it means a different cereal. What does this show about common names?
  1. A common name always tells us exactly which species an organism is
  2. Common names are only used for plants, never for animals
  3. Common names are the same everywhere in the world
  4. The same common name can refer to different organisms, which causes confusion
Correct answer: D
One common name can refer to different organisms in different places. This is one reason a universal name is needed.
Use after: Observe phase — Part C: Jigsaw, expert rule 3 (italics or underlining each part separately)
Q3. You want to handwrite the scientific name of the goat, Capra hircus, following the rules of binomial nomenclature. What should you do?
  1. Underline the genus and the species separately
  2. Write the whole name in capital letters instead of underlining
  3. Underline the whole name with one continuous line so the two words are joined
  4. Write the name in brackets so that it can be told apart from other words
Correct answer: A
Scientific names are written in italics when typed. When handwritten, the genus and the species are each underlined separately.
Use after: Explain phase — Card-sorting task: sorting 'Correct' and 'Incorrect' name cards and explaining which rule was broken
Q4. A learner writes the scientific name of the mosquito as Anopheles Gambiae. Which rule of binomial nomenclature has been broken?
  1. The species name must start with a small letter
  2. The genus must start with a small letter
  3. A scientific name must be written in Kiswahili
  4. A scientific name must have three parts
Correct answer: A
The genus begins with a capital letter and the species begins with a small letter. The correct form is Anopheles gambiae.
Use after: Explain phase — Claim-Evidence-Reasoning (CER) explanation: 'Why do scientists need a scientific name for each organism?'
Q5. A group writes the claim: 'Scientists need a scientific name for each organism even though people already have common names.' Which reasoning best supports this claim?
  1. Scientific names are longer than common names, so they are more useful
  2. Scientific names are in Latin, and Latin is the easiest language for everyone to speak
  3. Local names are wrong and should not be used by anyone
  4. Each organism has one accepted two-part name used worldwide, so scientists everywhere know which organism is meant and can share information without confusion
Correct answer: D
Good reasoning links the evidence (common names differ, but Zea mays is the same everywhere) to the idea that a universal name avoids confusion.
Use after: Explain phase — Class discussion and debate: 'Should we stop using local names now that we have scientific names?'
Q6. In a class debate, a learner says: 'Now that we have scientific names, we should stop using local names like mbuzi, mbũri and diel.' Which response is best?
  1. Disagree, because local names remain valuable in communities, while scientific names are used for communication among scientists worldwide
  2. Agree, because scientific names replace local names completely
  3. Disagree, because scientific names can only be used for plants
  4. Agree, because local names are never correct
Correct answer: A
Scientific names do not replace local names. Local names keep their cultural and community value, and scientific names give one shared name for universal scientific communication.
Use after: Model Building phase — Revising the class classification model: Naming Layer diagram labelling genus and species
Q7. Learners add a Naming Layer to the class model and label the scientific name of the goat, Capra hircus. Which labelling is correct?
  1. Genus: Capra hircus; Species: goat
  2. Genus: mbuzi; Species: Capra hircus
  3. Genus: hircus; Species: Capra
  4. Genus: Capra; Species: hircus
Correct answer: D
The first word, written with a capital letter, is the genus (Capra). The second word, written with a small letter, is the species (hircus).
