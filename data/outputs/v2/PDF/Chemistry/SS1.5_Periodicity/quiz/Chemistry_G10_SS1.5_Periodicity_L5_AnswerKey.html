Q1. A water purification officer stored sodium inside a sealed ampoule of argon gas. Which statement best explains why argon was a safe choice?
  1. Argon has one outer electron that it holds very tightly
  2. Argon has 7 outer electrons, so it only reacts with metals that are not very reactive
  3. Argon has a full outer shell of 8 electrons, so it does not need to lose, gain or share electrons
  4. Argon has no electrons, so it cannot react with anything
Correct answer: C
Argon is 2,8,8, so its outer shell is full. This stable arrangement makes it chemically inert, so it will not react with the reactive sodium.

Q2. The boiling points of the Group VIII elements are: helium −269 °C, neon −246 °C, argon −186 °C, krypton −153 °C. Which statement best explains this trend down the group?
  1. The atoms get smaller down the group, so they pack together more tightly
  2. The covalent bonds inside each atom get stronger down the group
  3. The atoms lose outer electrons more easily down the group, so they attract each other more
  4. The atoms get larger and have more electrons, so the London dispersion forces between atoms get stronger
Correct answer: D
Atomic radius and electron number increase down Group VIII, so the London dispersion forces between atoms get stronger. More energy is needed to separate the atoms, so the boiling point rises.

Q3. Across Period 3 from sodium to chlorine, atomic radius decreases. Which statement best explains this?
  1. The atoms lose electrons across the period, so they become smaller
  2. The number of protons decreases, so the nucleus pulls less on the outer electrons
  3. Each element has fewer electron shells than the one before it
  4. The nuclear charge increases while the number of shells stays the same and shielding is almost constant, so the outer electrons are pulled in more strongly
Correct answer: D
Each step across Period 3 adds one proton, but the electrons go into the same outer shell. Shielding stays nearly constant, so the stronger nuclear attraction pulls the outer electrons closer.
Use after: Observe phase — Activity B: Period 3 graph-plotting relay (Group C: melting point graph)
Q4. When the melting points of Na, Mg, Al, Si, P, S, Cl and Ar are plotted against atomic number, silicon has by far the highest melting point. Why?
  1. Silicon has a giant covalent structure, so many strong covalent bonds must be broken to melt it
  2. Silicon has the weakest London dispersion forces in Period 3
  3. Silicon has the largest atoms in Period 3, so it has the strongest forces between them
  4. Silicon is the most metallic element in Period 3
Correct answer: A
Silicon has a giant covalent structure in which every atom is joined to others by strong covalent bonds. A large amount of energy is needed to break these bonds, so the melting point peaks at silicon.

Q5. The first ionisation energy of aluminium (2,8,3) is lower than that of magnesium (2,8,2). Which statement best explains this dip?
  1. Aluminium has fewer protons than magnesium
  2. Aluminium's outer electrons are paired and repel each other
  3. Aluminium's outer electron is in a 3p sub-shell, which is slightly higher in energy than the 3s sub-shell, so it is easier to remove
  4. Aluminium has a full outer shell, so it does not hold its electrons tightly
Correct answer: C
Magnesium's two outer electrons are in the 3s sub-shell. Aluminium's third outer electron is in a higher-energy 3p sub-shell, so it is removed more easily and the ionisation energy dips.

Q6. Sulfur (2,8,6) has a lower first ionisation energy than phosphorus (2,8,5). Which statement best explains this dip?
  1. In sulfur, two electrons are paired in one 3p orbital and repel each other, so one is easier to remove
  2. Sulfur has a full 3p sub-shell, which makes it unstable
  3. Sulfur's outer electron is in the 4s sub-shell, which is further from the nucleus
  4. Sulfur has fewer protons than phosphorus
Correct answer: A
Phosphorus has one electron in each 3p orbital. Sulfur must pair two electrons in one 3p orbital, and the repulsion between them makes one easier to remove.
Use after: Explain phase — Part B: Conductivity and Physical Properties of Period 3 Metals
Q7. Mama Achieng's aluminium sufuria conducts better than a piece of sodium. Which statement best explains why the conductivity of the metals increases from Na to Mg to Al?
  1. Aluminium atoms have more electron shells than sodium atoms
  2. The number of delocalised electrons per atom increases (Na: 1, Mg: 2, Al: 3)
  3. Sodium atoms are heavier than aluminium atoms
  4. Aluminium atoms lose electrons less easily than sodium atoms, so they hold the current inside
Correct answer: B
Each Na atom gives 1 delocalised electron, each Mg atom 2 and each Al atom 3. More delocalised electrons per atom means a higher electron density and better conductivity.
Use after: Explain phase — Part B: 2-sentence answer on ionisation energy versus conductivity as a predictor of reactivity
Q8. Sodium conducts electricity less well than aluminium, yet sodium reacts far more violently with water. Which property is the better predictor of how reactive a metal is with water?
  1. Electrical conductivity, because it shows how many electrons a metal has
  2. Electrical conductivity, because a better conductor reacts faster
  3. Ionisation energy, because a low value means an electron is lost easily, so the metal is more reactive
  4. Melting point, because metals with high melting points react fastest
Correct answer: C
Metals react with water by losing electrons, so a low ionisation energy means higher reactivity. Conductivity and reactivity measure different things.
Use after: Model Building phase — Model: stability scale and the argon-versus-chlorine test question
Q9. Chlorine is right next to argon in Period 3. Why was argon, and not chlorine, used to protect the sodium?
  1. Chlorine has a higher first ionisation energy than argon, so it would react with sodium
  2. Argon has 7 outer electrons, so it gains an electron from sodium more easily than chlorine does
  3. Chlorine has a full outer shell, so it would react more strongly than argon
  4. Chlorine has 7 outer electrons and readily gains an electron, so it would react violently with sodium, while argon's full outer shell of 8 makes it inert
Correct answer: D
Chlorine is reactive because it gains one electron to complete its outer shell, so it would react with sodium. Argon already has a full outer shell of 8 electrons and reacts with nothing.
