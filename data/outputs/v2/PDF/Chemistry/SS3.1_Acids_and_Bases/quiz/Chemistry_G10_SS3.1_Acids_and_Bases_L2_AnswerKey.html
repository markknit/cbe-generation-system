Use after: Predict phase — Predict: writing a prediction and reason for each product using the Lesson 1 pH graph
Q1. A soap solution has a pH of 10.0 on the pH graph. Which prediction for the litmus test is best supported by this evidence?
  1. Red litmus will stay red, because soap looks white and clear.
  2. Neither litmus paper will change, because soap is not food.
  3. Red litmus will turn blue, because a pH above 7 suggests a base.
  4. Blue litmus will turn red, because soap feels slippery.
Correct answer: C
A pH above 7 points to a base, and bases turn red litmus blue. The other reasons rely on feel, appearance or whether it is food, none of which decide acidity.
Use after: Observe phase — Observe: testing 5 cups (lemon juice, vinegar, water, baking soda solution, soap solution) with red litmus, blue litmus and red cabbage extract
Q2. In the practical, learners test pure water as well as lemon juice, vinegar, baking soda solution and soap solution. Why is water included?
  1. It makes the acids and bases weaker so the colours are easier to see.
  2. It is expected to be a strong acid, to compare with lemon juice.
  3. It cleans the litmus strips between tests.
  4. It is a reference that shows what the indicators look like in a neutral liquid, so other results can be compared with it.
Correct answer: D
Water is neutral. Its results (litmus unchanged, cabbage extract purple) are the baseline against which colour changes in the other liquids are judged.
Use after: Observe phase — Observe: Step 3, adding about 10 drops of red cabbage extract to about 2 cm of each liquid (fair test)
Q3. A group adds 10 drops of red cabbage extract to 2 cm of vinegar, but only 3 drops to 5 cm of baking soda solution. Why is this a problem for the investigation?
  1. There is no problem, because the colour depends only on the type of substance.
  2. It is a problem only because vinegar should never be tested with red cabbage extract.
  3. It is a problem only because baking soda solution should be tested with litmus instead.
  4. It is not a fair test, because the amounts differ, so the colours cannot be compared reliably.
Correct answer: D
In a fair test only the substance being tested changes. The amount of liquid and the number of drops must be the same each time.
Use after: Explain phase — Explain: looking for patterns in the class results table and writing the claim 'Lemon juice and vinegar are ___ because ___'
Q4. A learner tests an unknown kitchen liquid. Blue litmus turns red, red litmus stays red, and purple red cabbage extract turns pink-red. How should the liquid be classified?
  1. Base
  2. It cannot be classified without tasting it
  3. Neutral
  4. Acid
Correct answer: D
Acids turn blue litmus red, leave red litmus red, and turn red cabbage extract red/pink. All three indicators agree it is an acid.
Use after: Explain phase — Explain: CER claim using evidence from at least two indicators; challenging 'colour or appearance' reasoning
Q5. Which piece of evidence best shows that vinegar is an acid?
  1. Vinegar is safe to eat.
  2. Vinegar is used to pickle kachumbari and onions.
  3. Blue litmus turns red and red cabbage extract turns pink-red in vinegar.
  4. Vinegar is clear, like water.
Correct answer: C
Classification must rest on a pattern of indicator colour changes. Appearance, use and being edible are not evidence of acidity.
Use after: Explain phase — Explain: 'Water stayed purple. Where would you place it?'
Q6. Pure water (pH 7.0) leaves both red litmus and blue litmus unchanged and keeps red cabbage extract purple. How should water be classified?
  1. Neutral, because it shows no acid or base colour change
  2. Base, because red litmus did not turn red
  3. Acid, because blue litmus did not turn blue
  4. A weak base, because the cabbage extract stayed purple instead of turning red
Correct answer: A
Acids and bases cause colour changes in the indicators. With no change and a pH of 7.0, water is neither acidic nor basic, so it is neutral.
Use after: Model Building phase — Model: labelling each box 'acid', 'base' or 'neutral' and revising any hypothesis that was not supported
Q7. In Lesson 1, a learner hypothesised that soap is an acid because it is used for cleaning. In the practical, red litmus turned blue in soap solution and red cabbage extract turned blue-green. What should the learner do?
  1. Repeat the test until red litmus stays red, so the result matches the hypothesis.
  2. Label soap neutral, because it is a cleaning product and not food.
  3. Keep the hypothesis, because the first idea should not be changed.
  4. Revise the hypothesis and label soap a base, because the evidence does not support the acid idea.
Correct answer: D
Evidence outranks an earlier hypothesis. Red litmus turning blue and blue-green cabbage extract show a base, so the model label should be corrected.
