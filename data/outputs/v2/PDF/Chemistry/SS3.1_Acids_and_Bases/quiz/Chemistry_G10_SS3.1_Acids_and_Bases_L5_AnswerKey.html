Use after: Observe phase — Station 1 - Litmus: red and blue litmus in baking soda solution, soap solution, vinegar and water
Q1. A learner dips red litmus paper into a clear solution and it turns blue. What does this result show about the solution?
  1. The solution is acidic, because it contains H+ (aq) ions
  2. The solution is basic, because it contains OH- (aq) ions
  3. The solution is a salt that cannot be basic or acidic
  4. The solution is neutral, like pure water with pH 7.0
Correct answer: B
Red litmus turns blue in basic solutions such as soap and baking soda solutions, which contain OH- (aq) ions. Acids such as vinegar turn blue litmus red.
Use after: Observe phase — Station 3 - Data card: OH- concentration of soap against the water value
Q2. Pure water has an OH- concentration of 1 x 10^-7 mol/L. Soap solution (pH 10.0) has an OH- concentration of 1 x 10^-4 mol/L. How many times more OH- does the soap solution have than pure water?
  1. 10 000 times
  2. 3 times
  3. 100 times
  4. 1000 times
Correct answer: D
Divide the concentrations: 10^-4 / 10^-7 = 10^3 = 1000. The 3 comes from subtracting the powers instead of dividing the numbers.
Use after: Observe phase — Station 3 - Data card: 'Soap is pH 10.0 and baking soda 8.3. Which has more OH- and how do you know?'
Q3. Soap solution has pH 10.0 and baking soda solution has pH 8.3. Which statement about their OH- (aq) ions is correct?
  1. Both have the same amount of OH- because both have pH above 7
  2. Baking soda solution has more OH- because it is used in food
  3. Baking soda solution has no OH- at all
  4. Soap solution has more OH- than baking soda solution
Correct answer: D
A higher pH above 7 means more OH- ions. Soap (pH 10.0) has more OH- than baking soda (pH 8.3), which is only weakly basic but still has some OH-.
Use after: Explain phase — Claim-Evidence-Reasoning: answering Wanjiru's question about slippery soap
Q4. Wanjiru asked why soap solution feels slippery. Which explanation best uses the evidence from the lesson?
  1. Vinegar makes soap slippery when the two are mixed
  2. Soap solution is slippery because it is clear and looks like water
  3. Soap solution contains many H+ ions that make the skin smooth
  4. The OH- (aq) ions in soap solution react with the oils on the skin
Correct answer: D
Soap solution contains OH- (aq) ions (pH 10.0), and these ions react with oils on the skin to give the slippery feel. Vinegar, which contains H+ ions, does not feel slippery.
Use after: Explain phase — Card sort: sodium hydroxide, calcium hydroxide, ammonia solution, magnesium hydroxide and copper(II) oxide
Q5. Copper(II) oxide is a base that does not dissolve in water. Which statement about it is correct?
  1. It is an acid, because it does not dissolve in water
  2. It is an alkali, because all bases are alkalis
  3. It is neither a base nor an alkali, because it has no OH in its formula
  4. It is a base but not an alkali, because it does not dissolve in water to give OH- (aq) ions
Correct answer: D
An alkali is a base that dissolves in water producing OH- (aq) ions. Copper(II) oxide is an insoluble base, so it is a base but not an alkali: all alkalis are bases, but not all bases are alkalis.
Use after: Explain phase — Explain phase: baking soda (pH 8.3) explained as a weak base
Q6. Mama Wanjiru adds baking soda (pH 8.3) to her mandazi mixture. Which explanation fits what the class learned about baking soda?
  1. It is a weak base that gives only a few OH- ions, so it is only slightly above neutral
  2. It is a strong alkali, so only a tiny amount can be used
  3. It is an acid, so it is safe to eat
  4. It contains no ions, so it has no effect
Correct answer: A
Baking soda solution gives only a few OH- ions, so its pH (8.3) is just above 7. It is therefore only weakly basic and safe in small amounts in mandazi.
Use after: Model Building phase — Model phase: four-box particle drawing (lemon juice, vinegar, baking soda solution, soap solution)
Q7. A learner draws a particle model with four boxes. Lemon juice has H+ of 1 x 10^-2 mol/L. Vinegar has H+ of about 1.6 x 10^-3 mol/L. Baking soda solution is pH 8.3. Soap solution is pH 10.0. Which model shows the particles correctly?
  1. Lemon juice has more H+ than vinegar, and soap solution has more OH- than baking soda solution
  2. Soap solution has only H+ and no OH-, and lemon juice has more H+ than vinegar
  3. Lemon juice has more H+ than vinegar, and baking soda solution has more OH- than soap solution
  4. Lemon juice has fewer H+ than vinegar, and soap has more OH- than baking soda solution
Correct answer: A
1 x 10^-2 is larger than 1.6 x 10^-3, so lemon juice has more H+ than vinegar. Soap (pH 10.0) has more OH- than baking soda (pH 8.3).
Use after: End of lesson — Exit ticket: 'Write one sentence defining an alkali and name one product from our lesson that contains one.'
Q8. Which sentence correctly defines an alkali?
  1. Any substance that releases H+ (aq) ions in water
  2. A base that dissolves in water producing OH- (aq) ions
  3. A substance with a pH above 7 only
  4. A base that does not dissolve in water
Correct answer: B
By the Arrhenius definition, an alkali is a base that dissolves in water producing OH- (aq) ions. Saying only 'pH above 7' misses the OH- idea, and H+ release describes acids.
