Q1. Learners are deciding how to line up the first 20 element cards. Potassium, K, has atomic number 19 and relative atomic mass 39. Argon, Ar, has atomic number 18 and relative atomic mass 40. If the cards are ordered only by increasing relative atomic mass, which card comes first?
  1. K comes first because 39 is less than 40
  2. Ar comes first because it has the smaller atomic number
  3. It is not possible to decide without knowing their properties
  4. They must sit in the same position because their masses are almost equal
Correct answer: A
Ordering by increasing mass puts the smaller A_r first, so K (39) comes before Ar (40). This is the prediction that the evidence in Part B then challenges.
Use after: Observe phase — Part B: arranging the Element Cards on the grid (groups as columns, periods as rows)
Q2. On the element-card grid, which statement correctly describes groups and periods?
  1. A group is a vertical column and a period is a horizontal row
  2. A group and a period are both vertical columns, numbered differently
  3. A group is a horizontal row and a period is a vertical column
  4. A group is a set of elements with the same mass and a period is a set with the same number of neutrons
Correct answer: A
Groups are vertical columns, numbered 1 to 18. Periods are horizontal rows, numbered 1 to 4 for the first 20 elements. Learners often confuse the two.
Use after: Observe phase — Part B: arranging the Element Cards on the grid by atomic number
Q3. Magnesium, Mg, has atomic number 12. When H to Ca are arranged by atomic number, Be, Mg and Ca sit in one column, and Na to Ar form one row. In which period and group is Mg?
  1. Period 2, group 3
  2. Period 3, group 2
  3. Period 12, group 1
  4. Period 2, group 12
Correct answer: B
Mg is in the row that runs from Na to Ar, which is period 3. It is in the column with Be and Ca, which is group 2.
Use after: Explain phase — CER paragraph: why mass ordering fails for Ar and K (also the exit ticket)
Q4. Argon (atomic number 18, A_r 40) is placed before potassium (atomic number 19, A_r 39) in the periodic table. What is the correct reason?
  1. Heavier atoms must always come before lighter atoms
  2. Argon is a gas and potassium is a solid, so gases always come first
  3. A mistake was made in the mass of potassium, so it will be corrected later
  4. Elements are ordered by atomic number, and 18 comes before 19, even though argon is heavier
Correct answer: D
The modern table is ordered by atomic number (number of protons), as shown by Moseley in 1913. Ar has Z = 18 and K has Z = 19, so Ar comes first even though its mass is slightly higher.
Use after: Explain phase — CER paragraph: evidence that Ca has the same A_r as Ar but sits in a different group
Q5. Calcium (Z = 20) and argon (Z = 18) both have a relative atomic mass of 40, but calcium sits in group 2 and argon sits in group 18. What does this show?
  1. Argon must be placed in group 2 because its mass is the same as calcium's
  2. Elements with the same mass always sit in the same period
  3. Calcium and argon have the same number of protons
  4. Mass alone cannot tell us where an element belongs, but atomic number can separate them
Correct answer: D
The same mass appears in different groups, so mass is not a reliable basis for the order. Atomic number differs (18 and 20), so it gives each element its own place.
Use after: Explain phase — Using the table to answer (c): which elements are in the same group as Cl?
Q6. Chlorine (Z = 17) is used to disinfect drinking water in Nairobi and Mombasa. Among the first 20 elements, which one sits in the same group as chlorine?
  1. Argon, Z = 18, the next element after chlorine
  2. Neon, Z = 10
  3. Sulphur, Z = 16, in the same period as chlorine
  4. Fluorine, Z = 9
Correct answer: D
Cl is in group 17 in period 3. Fluorine (Z = 9) is directly above it in group 17 in period 2. Sulphur and argon are in the same period as Cl, not the same group, and neon is in group 18.
Use after: Model Building phase — Class Model: 'Order is by atomic number (Moseley, 1913), not mass (Mendeleev, 1869)'
Q7. A learner says: 'Moseley proved that Mendeleev's work was completely wrong and replaced all of it.' Which statement is the best correction?
  1. Mendeleev ordered by atomic number and Moseley ordered by mass
  2. Moseley discovered the first 20 elements, so Mendeleev's table was not needed
  3. Mendeleev's table had no gaps, but Moseley's table has gaps for undiscovered elements
  4. Moseley showed that atomic number is the true basis of order, while Mendeleev's idea of putting similar elements in one column and leaving gaps stayed useful
Correct answer: D
Mendeleev (1869) ordered by atomic mass, grouped similar elements and left gaps for undiscovered elements. Moseley (1913) showed that atomic number is the true basis, and the two ideas fit together.
