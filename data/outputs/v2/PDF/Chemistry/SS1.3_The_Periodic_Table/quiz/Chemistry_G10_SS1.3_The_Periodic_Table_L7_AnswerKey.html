Q1. A sodium atom has the electron arrangement 2,8,1. What are its valency and its oxidation number when it forms an ion?
  1. Valency 1, oxidation number -1
  2. Valency 1, oxidation number +1
  3. Valency +1, oxidation number 1
  4. Valency 8, oxidation number +8
Correct answer: B
Sodium loses its 1 outer electron, so its valency (a plain number) is 1. Losing a negative electron makes the ion positive, so the oxidation number is +1.

Q2. Magnesium has the electron arrangement 2,8,2. Which statement correctly gives its ion and oxidation number?
  1. It loses 2 electrons, forming Mg2+ with oxidation number +2
  2. It gains 2 electrons, forming Mg2- with oxidation number -2
  3. It loses 8 electrons, forming Mg8+ with oxidation number +8
  4. It loses 2 electrons, forming Mg2+ with oxidation number -2
Correct answer: A
Magnesium has 2 outer electrons and loses them to reach the stable 2,8 arrangement. Losing 2 electrons gives a 2+ ion, so the oxidation number is +2.

Q3. Chlorine has the electron arrangement 2,8,7. A student writes its oxidation number as +7 because it has 7 outer electrons. What is the correct oxidation number and reason?
  1. +7, because chlorine loses all 7 outer electrons
  2. -7, because chlorine gains 7 electrons
  3. +1, because chlorine loses 1 electron
  4. -1, because chlorine gains 1 electron to get the stable arrangement 2,8,8
Correct answer: D
Chlorine needs only 1 more electron to reach the noble gas arrangement 2,8,8 (argon), so it gains 1 electron and forms Cl- with oxidation number -1.

Q4. Which statement correctly describes the difference between valency and oxidation number?
  1. Valency and oxidation number are exactly the same thing in every case
  2. Valency is the number of electrons lost or gained, with no sign; oxidation number is the same number with a + or - sign
  3. Valency is the number of protons; oxidation number is the number of neutrons
  4. Valency has a sign but oxidation number does not
Correct answer: B
Valency counts the electrons lost or gained and is never negative. The oxidation number adds a sign: + for loss and - for gain.

Q5. Oxygen has the electron arrangement 2,6. What are the valency and oxidation number of oxygen in the oxide ion?
  1. Valency 2, oxidation number +2
  2. Valency 2, oxidation number -2
  3. Valency 6, oxidation number +6
  4. Valency -2, oxidation number 2
Correct answer: B
Oxygen has 6 outer electrons and needs 2 more to reach 2,8. It gains 2 electrons, so its valency is 2 and its oxidation number is -2.

Q6. Nitrogen has the electron arrangement 2,5. What are its valency and oxidation number when it forms an ion?
  1. Valency 2, oxidation number -2
  2. Valency 3, oxidation number +3
  3. Valency 5, oxidation number +5
  4. Valency 3, oxidation number -3
Correct answer: D
Nitrogen has 5 outer electrons and needs 3 more to reach 2,8. It gains 3 electrons, so valency is 3 and oxidation number is -3.

Q7. Lithium, sodium and potassium have masses of 7, 23 and 39, yet they react in the same way with water. What is the best explanation?
  1. Each has the same atomic mass
  2. Each has a full outer energy level
  3. Each gains 1 electron to form an ion with oxidation number -1
  4. Each has 1 outer electron, so each forms an ion with oxidation number +1
Correct answer: D
Li, Na and K are all in group 1 and have 1 outer electron. Each loses it to form a +1 ion, so they behave alike despite different masses.
Use after: Observe phase — Part B: transition element card set (iron in FeCl2 and Fe2O3)
Q8. Rust on roofing sheets in Kisumu contains Fe3+ in Fe2O3, while FeCl2 contains Fe2+. What does this show about iron?
  1. Iron has a different valency only because oxygen is present
  2. Iron gains electrons in Fe2O3 and loses them in FeCl2
  3. Iron is a transition element and can have more than one oxidation number (+2 and +3)
  4. Iron has an oxidation number of +2 only, and Fe2O3 is a mistake
Correct answer: C
Transition elements can lose electrons from more than one energy level, so iron forms both Fe2+ and Fe3+. The outer electron count alone does not decide which one forms.

Q9. Copper forms Cu2O and CuO. Which pair of oxidation numbers does copper show in these compounds?
  1. -1 in Cu2O and -2 in CuO
  2. +2 in Cu2O and +1 in CuO
  3. +1 in Cu2O and +2 in CuO
  4. +1 in both compounds
Correct answer: C
Copper forms the Cu+ ion in Cu2O and the Cu2+ ion in CuO. Both are positive because copper is a metal that loses electrons.
