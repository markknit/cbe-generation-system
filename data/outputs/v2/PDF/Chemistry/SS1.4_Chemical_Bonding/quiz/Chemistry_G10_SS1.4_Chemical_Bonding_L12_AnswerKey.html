Use after: Predict phase — Model Blueprint Sheet: planning prompt (2) on the bond angle(s) the model must show
Q1. A group is planning a 3-D model of diamond. Each carbon atom is bonded to four other carbon atoms in a tetrahedral arrangement. Which bond angle should the group write on their blueprint?
  1. 120°
  2. 109.5°
  3. 180°
  4. 90°
Correct answer: B
The four bonds around each carbon in diamond point to the corners of a tetrahedron, giving a bond angle of 109.5°. A 90° angle is the common error the teacher checks for on blueprint sheets.
Use after: Observe phase — Build phase: NaCl group alternating two clay colours and counting that each Na⁺ is surrounded by 6 Cl⁻
Q2. A group builds a sodium chloride (NaCl) model by alternating two colours of clay in a 3-D grid. How many Cl⁻ ions should surround each Na⁺ ion in the finished model?
  1. 4
  2. 6
  3. 2
  4. 8
Correct answer: B
In the NaCl ionic lattice each Na⁺ is surrounded by 6 Cl⁻ ions and each Cl⁻ by 6 Na⁺ ions, so the coordination number is 6:6.
Use after: Observe phase — Build phase: graphite group connecting layers with loose string to represent weak Van der Waals forces
Q3. In a graphite model, carbon atoms in a layer are joined by rigid wire, but the layers are joined only by loose string. When you pull the layers apart, what do the loose strings represent breaking?
  1. Metallic bonds between the carbon atoms
  2. Strong covalent bonds between carbon atoms in the same layer
  3. Ionic bonds between the layers
  4. Weak Van der Waals forces between the layers
Correct answer: D
Only weak Van der Waals forces hold the layers together, so the layers slide over each other easily. This is why graphite is soft and leaves a mark on paper. The strong covalent bonds inside each layer stay intact.
Use after: Observe phase — Build phase: SiO₂ group connecting each central maize-kernel 'Si' to four bean 'O' atoms
Q4. A student building the SiO₂ model connects each central maize-kernel 'Si' to beans representing 'O' atoms, and then bridges the oxygens to the next Si. How should each Si atom be bonded in a correct SiO₂ giant covalent lattice?
  1. To two O atoms in a straight line
  2. To three O atoms in a flat layer
  3. To four O atoms in a tetrahedral arrangement
  4. To six O atoms, like Na⁺ in NaCl
Correct answer: C
In SiO₂ each Si is covalently bonded to four O atoms arranged tetrahedrally, and each O links to another Si. This builds a giant covalent lattice.
Use after: Explain phase — Peer review carousel: teacher listening at the diamond and graphite models for the misconception 'it has metal in it'
Q5. During the carousel, a visitor writes on a graphite model: 'Graphite conducts electricity because it has metal in it.' Which comment on the peer review card would correct this?
  1. Graphite conducts because its layers are held together by weak Van der Waals forces.
  2. Graphite conducts because it has four bonds per carbon atom, like diamond.
  3. Graphite conducts because each carbon has one delocalised electron free to move along the layers.
  4. Graphite conducts because it is an ionic lattice with free ions.
Correct answer: C
Each carbon in graphite uses three electrons in bonding, leaving one delocalised electron that can move and carry charge. Graphite contains only carbon, with no metal.
Use after: Explain phase — Whole-class question at the diamond and graphite models: 'why is one the hardest substance on Earth and the other writes on paper?'
Q6. Both diamond and graphite are 100% carbon. Why does the diamond model fit a material that is extremely hard and does not conduct electricity, while graphite is soft and conducts?
  1. Diamond is an ionic compound and graphite is a covalent compound.
  2. Diamond has four bonds per carbon in a 3-D tetrahedral network, while graphite has three bonds per carbon in layers with weak forces between them.
  3. Diamond contains a metal that holds the atoms together, while graphite does not.
  4. Diamond has more protons in its carbon atoms than graphite.
Correct answer: B
The two materials contain the same atoms, so the difference is the bonding arrangement. Diamond's 3-D network of four bonds locks every atom in place. Graphite's layers of three bonds per atom are weakly held together and leave one electron free.
Use after: DQB phase — Driving Question Board sticky note: 'I can now explain ______ about the carbon paradox because I built ______'
Q7. A student completes the sticky note: 'I can now explain why diamond does not conduct electricity because I built the tetrahedral model and saw that ______.' Which ending is correct?
  1. the layers are held together by only loose string
  2. every carbon electron is locked in a covalent bond, so there are no free electrons
  3. each carbon has one delocalised electron that is trapped between layers
  4. there are free ions that cannot move in the solid
Correct answer: B
Each carbon in diamond uses all four outer electrons in covalent bonds, so no electrons are free to carry charge. This makes diamond an electrical insulator.
