Q1. A student in Kisumu measures the sun's angle with the ground as 53°. The shadow of a vertical mango tree on level ground is 9.0 m long. Which equation connects the angle, the shadow and the tree's height h directly?
  1. tan 53° = 9.0 / h
  2. tan 53° = h / 9.0
  3. cos 53° = h / 9.0
  4. sin 53° = h / 9.0
Correct answer: B
The tree height h is opposite the 53° angle and the shadow is adjacent to it, so the ratio Opposite/Adjacent, which is tan 53°, links them. Sin would need the sun-ray length (hypotenuse), which is not given.
Use after: Observe phase — Part A: algebraic derivation of tan θ = sin θ / cos θ
Q2. In a right-angled triangle, sin θ = O/H and cos θ = A/H. What is sin θ ÷ cos θ, that is (O/H) ÷ (A/H), after simplifying?
  1. (O × A) / H²
  2. O / H
  3. O / A
  4. A / O
Correct answer: C
(O/H) ÷ (A/H) = (O/H) × (H/A). The H cancels, leaving O/A, which is tan θ. Multiplying by A/H instead of inverting gives the wrong answer (O × A)/H².
Use after: Observe phase — Part B: numerical verification table for 30°, 40°, 60° and 70°
Q3. From mathematical tables, sin 40° = 0.6428 and cos 40° = 0.7660. What is sin 40° ÷ cos 40°, to 3 decimal places, and which table value does it match?
  1. 1.41, which matches tan 40°
  2. 0.839, which matches tan 40°
  3. 1.19, which matches tan 50°
  4. 0.49, which matches tan 40°
Correct answer: B
0.6428 ÷ 0.7660 ≈ 0.839, which equals tan 40° in the tables. Dividing cos by sin gives 1.19, multiplying gives 0.49 and adding gives 1.41, and none of these are sin ÷ cos.
Use after: Explain phase — Part A: sensemaking discussion, Q1 (is tan unnecessary?)
Q4. We have proved that tan θ = sin θ / cos θ, so tan can be found from sin and cos. Why is the tangent ratio still useful?
  1. It is only useful when we know the hypotenuse
  2. It gives a direct route when we know an angle and one of the opposite or adjacent sides but not the hypotenuse
  3. It is only useful for angles of 53°
  4. It is not useful, because sin and cos can always replace it
Correct answer: B
Tan uses only the opposite and adjacent sides, so it is a convenient shortcut when the hypotenuse is unknown or cannot be measured, as with a tree and its shadow.
Use after: Explain phase — Part A: sensemaking discussion, Q2 (opposite or adjacent?)
Q5. The sun's rays make a 53° angle with level ground. A vertical tree of height h casts a 9.0 m shadow on the ground, forming a right-angled triangle. The 53° angle is at the tip of the shadow. Which side of the triangle is the 9.0 m shadow, relative to the 53° angle?
  1. The adjacent side, because it lies next to the 53° angle and is not the hypotenuse
  2. It cannot be named until the tree height is known
  3. The hypotenuse, because it is the length we measured
  4. The opposite side, because it lies on the ground
Correct answer: A
The shadow forms one arm of the 53° angle and is not the side facing the right angle, so it is adjacent. The tree height is the side opposite the 53° angle, and the sun ray is the hypotenuse.
Use after: Explain phase — Part B: mango-tree calculation, h = 9.0 × tan 53°
Q6. A mango tree casts a 9.0 m shadow when the sun's angle with the ground is 53°. Using tan 53° ≈ 1.3270 from tables, what is the height of the tree, to 2 decimal places?
  1. 0.15 m
  2. 10.33 m
  3. 6.78 m
  4. 11.94 m
Correct answer: D
tan 53° = h / 9.0, so h = 9.0 × tan 53° = 9.0 × 1.3270 = 11.943 ≈ 11.94 m. Dividing 9.0 by 1.3270 (6.78 m) is the inverted-ratio error.

Q7. The same 53° sun angle at the same time of day gives the same tangent ratio for a small pole and for a tall tree. Why does tan θ = Opposite/Adjacent work for triangles of any size?
  1. Because the ratio Opposite/Adjacent stays constant for a given angle, whatever the size of the triangle
  2. Because the ratio gets bigger as the shadow gets longer
  3. Because the opposite side is always equal to the adjacent side
  4. Because tan θ depends on the length of the hypotenuse
Correct answer: A
Triangles with the same angles are similar, so their side ratios are equal. For a given angle, Opposite/Adjacent is fixed and does not depend on the triangle's size.
