Q1. A Kericho plot has 2³ rows of tea and each row has 2⁴ plants. How many plants are there altogether, written as one power of 2?
  1. 2¹
  2. 4⁷
  3. 2⁷
  4. 2¹²
Correct answer: C
2³ × 2⁴ = (2×2×2) × (2×2×2×2), which is seven factors of 2, so 2⁷. The product rule adds the exponents: 3 + 4 = 7.
Use after: Predict phase — Predict: 2¹⁰ ÷ 2³ nursery seedlings prediction
Q2. A nursery has 2¹⁰ tea seedlings to share equally among 2³ farmers. How many seedlings does each farmer get?
  1. 8 192
  2. 1
  3. 128
  4. 7
Correct answer: C
2¹⁰ ÷ 2³ = 2¹⁰⁻³ = 2⁷ = 128. Subtract the exponents. Adding them gives 2¹³ = 8 192, and dividing the bases gives 1.
Use after: Observe phase — Observe: Table 1 (Product Rule) expanding 2² × 2³, 3² × 3³, 5¹ × 5⁴
Q3. In Table 1, a group expands 2² × 2³ into repeated multiplication. How many factors of 2 are there altogether, and what does this show?
  1. 1 factor, so 2² × 2³ = 2¹ (cancel the common base)
  2. 5 factors, so 2² × 2³ = 4⁵ (multiply the bases)
  3. 6 factors, so 2² × 2³ = 2⁶ (multiply the exponents)
  4. 5 factors, so 2² × 2³ = 2⁵ (add the exponents)
Correct answer: D
2² × 2³ = (2×2) × (2×2×2) has 2 + 3 = 5 factors of 2, so it equals 2⁵. This is the pattern behind the product rule.
Use after: Observe phase — Observe: Table 3 (Zero Index) 2³ ÷ 2³ and aⁿ ÷ aⁿ
Q4. In Table 3, a group works out 2³ ÷ 2³ by cancelling common factors and also by the quotient rule. What is the value of 2⁰?
  1. 2
  2. 3
  3. 1
  4. 0
Correct answer: C
By cancellation, (2×2×2) ÷ (2×2×2) = 1. By the quotient rule, 2³ ÷ 2³ = 2³⁻³ = 2⁰. So 2⁰ = 1, not 0.
Use after: Explain phase — Explain: pair application problem 1 (Rift Valley plot 3⁴ m by 3² m)
Q5. A Rift Valley farmer owns a rectangular plot measuring 3⁴ metres by 3² metres. What is the area of the plot?
  1. 6 561 m²
  2. 9 m²
  3. 531 441 m²
  4. 729 m²
Correct answer: D
Area = 3⁴ × 3² = 3⁴⁺² = 3⁶ = 729 m². Multiplying the exponents would give 3⁸ and multiplying the bases would give 9⁶. Subtracting exponents gives 3² = 9, which is the quotient rule and does not apply here.
Use after: Explain phase — Explain: pair application problem 2 (Kisumu fish trader 4⁶ ÷ 4³)
Q6. A Kisumu fish trader divides 4⁶ kg of dried tilapia equally among 4³ market stalls. How many kilograms does each stall get?
  1. 64 kg
  2. 16 kg
  3. 1 kg
  4. 262 144 kg
Correct answer: A
4⁶ ÷ 4³ = 4⁶⁻³ = 4³ = 64 kg. Dividing the exponents gives 4² = 16, which is wrong. Adding them gives 4⁹ = 262 144, and dividing the bases gives 1.
Use after: End of lesson — End of lesson: connecting the laws back to the Kericho tea-farm phenomenon (2³ and 2¹⁰)
Q7. A tea estate's harvest is 2ⁿ grams per cycle. If the exponent increases by 1 to n + 1, what happens to the harvest?
  1. It increases by 2 grams
  2. It is multiplied by n
  3. It increases by 1 gram
  4. It doubles
Correct answer: D
2ⁿ⁺¹ = 2ⁿ × 2¹ = 2 × 2ⁿ, so the harvest doubles. An exponent that is one larger means one more factor of 2.
Use after: Model Building phase — Model Building: adding the Laws Panel to the Index Toolbox diagram
Q8. Which statement about the laws of indices (a is not 0) is correct and belongs in a Laws Panel?
  1. aᵐ × aⁿ = aᵐ⁺ⁿ, aᵐ ÷ aⁿ = aᵐ⁻ⁿ and a⁰ = a
  2. aᵐ × aⁿ = aᵐ⁺ⁿ, aᵐ ÷ aⁿ = aᵐ⁻ⁿ and a⁰ = 1
  3. aᵐ × aⁿ = aᵐ⁺ⁿ, aᵐ ÷ aⁿ = aᵐ⁺ⁿ and a⁰ = 0
  4. aᵐ × aⁿ = aᵐⁿ, aᵐ ÷ aⁿ = aᵐ⁻ⁿ and a⁰ = 1
Correct answer: B
The product rule adds exponents, the quotient rule subtracts them, and any non-zero base raised to the power 0 equals 1. The other options multiply exponents, add them in a quotient, or give a wrong value for a⁰.
