Use after: Predict phase — Predict: M-Pesa prompt – recovering 17,000,000 from 7.2304
Q1. An analyst finds that log₁₀ x = 7.2304, where x is the number of M-Pesa transactions in a day. Which expression gives x?
  1. x = 7.2304^10
  2. x = 7.2304 × 10
  3. x = 7.2304 ÷ 10
  4. x = 10^7.2304
Correct answer: D
The definition log₁₀ x = n ⟺ 10ⁿ = x means x = 10^7.2304. The antilogarithm of 7.2304 is 10 raised to that power.
Use after: Observe phase — Observe: Worked Example 1 (log lookup) – Kariuki's characteristic question
Q2. Using four-figure tables, the characteristic of log₁₀ of a number is found from the digits before the decimal point. What is the characteristic of log₁₀(58.4)?
  1. 0
  2. 1
  3. 3
  4. 2
Correct answer: B
58.4 has 2 digits before the decimal point, so the characteristic is 2 − 1 = 1. Learners who answer 2 are using the number of digits instead of one less.
Use after: Observe phase — Observe: Practice Problem A – log₁₀(3,240)
Q3. A Kericho tea estate produces 3,240 kg of tea in a day. From the log table, the mantissa of 3240 is 0.5105. What is log₁₀(3 240)?
  1. 0.5105
  2. 3.3240
  3. 4.5105
  4. 3.5105
Correct answer: D
3240 has 4 digits before the decimal point, so the characteristic is 4 − 1 = 3. Adding the mantissa gives 3 + 0.5105 = 3.5105.
Use after: Observe phase — Observe: Practice Problem C – antilog(4.5922)
Q4. From the antilog table, the mantissa 0.5922 gives the digits 3910 (that is, 3.910). What is the antilogarithm of 4.5922?
  1. 3 910
  2. 3.910
  3. 39 100
  4. 391 000
Correct answer: C
The characteristic 4 means the number has 4 + 1 = 5 digits before the decimal point. So antilog 4.5922 = 3.910 × 10⁴ = 39 100, and a calculator's 10ˣ key gives the same.
Use after: Explain phase — Explain: Prompt 1 – why the antilogarithm table is a table of powers of 10
Q5. Why is an antilogarithm table described as a table of powers of 10?
  1. Because the table divides each logarithm by 10
  2. Because log₁₀ x = n means 10ⁿ = x, so the table gives the value of 10 raised to each logarithm
  3. Because the table lists the numbers 10, 20, 30 and so on
  4. Because the table gives the negative of each logarithm
Correct answer: B
By the index definition log₁₀ x = n ⟺ 10ⁿ = x, finding the number from its logarithm n means working out 10ⁿ. The antilog table lists these values. It does not give a negative log or a division by 10.
Use after: Explain phase — Explain: Prompt 2 – analyst writes 7.2340 instead of 7.2304
Q6. An analyst should have written log₁₀ N = 7.2304 but wrote 7.2340 by mistake. When she finds the antilogarithm of 7.2340, how will her number compare with the correct number?
  1. It will be negative, because the logarithm was written wrongly
  2. It will be exactly the same, because the characteristic is still 7
  3. It will be smaller, because the digits were swapped
  4. It will be larger, because a bigger logarithm means a bigger number
Correct answer: D
Since 10ˣ increases as x increases, 7.2340 is greater than 7.2304, so its antilogarithm is greater. Antilog table values rise as the mantissa rises.
Use after: Explain phase — Explain: Prompt 3 – tea manager multiplies 3,240 × 47.6 using Practice Problems A and B
Q7. A tea estate manager wants to multiply 3 240 × 47.6 using logarithms. He knows log₁₀ 3 240 = 3.5105 and log₁₀ 47.6 = 1.6776. Which method is correct?
  1. Add 3 240 + 47.6, then find the logarithm of the sum
  2. Multiply 3.5105 × 1.6776, then find the antilogarithm
  3. Find the antilog of 3.5105 and of 1.6776, then add the two answers
  4. Add 3.5105 + 1.6776 = 5.1881, then find the antilogarithm of 5.1881
Correct answer: D
The logarithms are added first: 3.5105 + 1.6776 = 5.1881. The antilogarithm of 5.1881 gives the product, about 154 200. Taking antilogs first and then adding reverses the steps.
