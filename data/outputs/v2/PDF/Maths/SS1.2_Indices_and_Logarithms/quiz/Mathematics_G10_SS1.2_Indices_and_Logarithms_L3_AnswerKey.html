Q1. The reciprocal of a number is the number you multiply it by to get 1. What is the reciprocal of 2³?
  1. 1/8
  2. 8
  3. −8
  4. 1/6
Correct answer: A
2³ = 8, and 8 × 1/8 = 1, so the reciprocal is 1/8. Choosing 8 repeats the number itself, and −8 confuses the reciprocal with the negative.
Use after: Observe phase — Station B: Negative Index Rule (8 g of tea shared among 32 tasting cups)
Q2. 8 g (2³ g) of tea from one plant is shared equally among 2⁵ = 32 tasting cups. Using 2³ ÷ 2⁵, how much tea goes in each cup?
  1. 2^(−2) g, which equals −4 g
  2. 2² g, which equals 4 g
  3. 2^(−2) g, which equals 1/4 g
  4. 2^(−2) g, which equals −1/4 g
Correct answer: C
The quotient rule gives 2^(3−5) = 2^(−2). Ordinary arithmetic gives 8 ÷ 32 = 1/4, so 2^(−2) = 1/2² = 1/4. A negative index gives a reciprocal, not a negative amount.
Use after: Observe phase — Station C: Fractional Index Rule (using the power rule in reverse)
Q3. Using the power rule, (2^(1/2))² = 2^(1/2 × 2) = 2¹ = 2. What does this tell us 2^(1/2) must be?
  1. Half of 2, which is 1
  2. The square of 2, which is 4
  3. The number that, multiplied by itself, gives 2 (that is, √2)
  4. 2 ÷ 2 ÷ 2 = 1/2
Correct answer: C
Since 2^(1/2) squared equals 2, 2^(1/2) is the number whose square is 2, which is √2. The index 1/2 means a square root, not 'half of 2'.
Use after: Explain phase — Tier 1 (a) and the whole-class 'rule audit' ((2^4)^3 = 2^7)
Q4. What is the value of (2⁴)³?
  1. 128
  2. 64
  3. 4 096
  4. 24
Correct answer: C
By the power rule, (2⁴)³ = 2^(4×3) = 2¹² = 4 096. The answer 128 comes from wrongly adding the indices (2⁷), which is the error in the rule audit.
Use after: Explain phase — Tier 1 (d): simplify 8^(2/3), writing the rule used
Q5. What is the value of 8^(2/3)?
  1. 2
  2. 16/3
  3. 4
  4. 8/3
Correct answer: C
The denominator 3 is the root and the numerator 2 is the power: 8^(2/3) = (∛8)² = 2² = 4. Answers such as 16/3 or 8/3 come from treating 2/3 as something to multiply or divide by.
Use after: Explain phase — Tier 2 (pairs): 2^10 tea plants arranged in 2^4 equal rows
Q6. A Kericho estate has 2¹⁰ tea plants arranged in 2⁴ equal rows. How many plants are in each row?
  1. 64
  2. 16 384
  3. 256
  4. 6
Correct answer: A
Plants per row = 2¹⁰ ÷ 2⁴ = 2^(10−4) = 2⁶ = 64. Dividing 1 024 by 4 gives 256, which wrongly divides by the index instead of by 2⁴ = 16.
Use after: Explain phase — Tier 2: explain in words what 2^(−3) container-loads of tea means physically
Q7. A farm worker says 2^(−3) container-loads of tea. What does this mean?
  1. A negative amount of tea, equal to −6 container-loads
  2. 8 container-loads, because the negative sign is ignored
  3. A negative amount of tea, equal to −8 container-loads
  4. 1/8 of a container-load, because 2^(−3) is the reciprocal of 2³
Correct answer: D
By the negative index rule, 2^(−3) = 1/2³ = 1/8, which is a small positive amount. A negative index does not mean a negative quantity.
Use after: Model Building phase — Index Laws page of the Concept Map: new row for the fractional index rule
Q8. Which statement correctly states the fractional index rule for a^(m/n)?
  1. a^(m/n) = a^m ÷ a^n
  2. a^(m/n) = a^(m−n)
  3. a^(m/n) = ⁿ√(a^m), which is the same as (ⁿ√a)^m
  4. a^(m/n) = m × ⁿ√a
Correct answer: C
Using the power rule, a^(m/n) = (a^(1/n))^m = (ⁿ√a)^m = ⁿ√(a^m). The denominator n gives the root and the numerator m gives the power.
