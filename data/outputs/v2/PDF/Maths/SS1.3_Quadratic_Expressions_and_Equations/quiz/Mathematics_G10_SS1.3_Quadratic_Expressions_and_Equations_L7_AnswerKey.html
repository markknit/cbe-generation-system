Q1. A trader at a Kisumu market stall arranges 60 mandazi in a rectangular tray with x rows. There are 4 more columns than rows, so there are (x + 4) columns. Which equation, written with zero on one side, describes this tray?
  1. x² + 4x − 60 = 0
  2. x² − 4x − 60 = 0
  3. x + (x + 4) = 60
  4. x² + 4x + 60 = 0
Correct answer: A
The number of mandazi is rows × columns, so x(x + 4) = 60. This expands to x² + 4x = 60, and subtracting 60 from both sides gives x² + 4x − 60 = 0.
Use after: Observe phase — Stage B: Path around the shamba (outer rectangle (12 + 2w) by (8 + 2w))
Q2. A shamba in the Rift Valley is 12 m long and 8 m wide. A path of uniform width w metres is built all the way around it. The shamba and the path together cover 140 m². Which equation shows this?
  1. 12w × 8w = 140
  2. (12 + w)(8 + w) = 140
  3. (12 + 2w)(8 + 2w) = 96
  4. (12 + 2w)(8 + 2w) = 140
Correct answer: D
The path lies on both sides of the length and the width, so the outer rectangle measures (12 + 2w) by (8 + 2w). Its area is the total of 140 m². Using (12 + w) is the common error of adding the path only once.
Use after: Observe phase — Stage B: Path around the shamba (expand, simplify, then divide by 4)
Q3. When (12 + 2w)(8 + 2w) = 140 is expanded and simplified, we get 4w² + 40w − 44 = 0. Dividing every term by 4, which equation do we get?
  1. w² + 10w − 44 = 0
  2. w² + 40w − 11 = 0
  3. w² + 10w − 11 = 0
  4. w² + 10w + 11 = 0
Correct answer: C
Every term must be divided by 4: 4w² ÷ 4 = w², 40w ÷ 4 = 10w and −44 ÷ 4 = −11. So the equation is w² + 10w − 11 = 0.
Use after: Explain phase — Keep or reject? table: mandazi tray, x = −10 and x = 6
Q4. The mandazi tray equation x² + 4x − 60 = 0 factorises as (x + 10)(x − 6) = 0, where x is the number of rows. Which statement about the answer is correct?
  1. x = 10, because the bracket contains +10
  2. x = −10, because it is the first root found
  3. x = 6, because the number of rows cannot be negative, so x = −10 is rejected
  4. Both x = 6 and x = −10 are answers, because both satisfy the equation
Correct answer: C
Setting each bracket to zero gives x = −10 or x = 6. A tray cannot have −10 rows, so it is rejected. Only x = 6 works, since 6 rows × 10 columns = 60 mandazi.
Use after: Explain phase — Keep or reject? table: path around the shamba, w = −11 and w = 1
Q5. For a path of width w metres around a 12 m by 8 m shamba, the equation is w² + 10w − 11 = 0. What is the width of the path?
  1. 11 m
  2. 1 m
  3. −1 m
  4. −11 m
Correct answer: B
w² + 10w − 11 = (w + 11)(w − 1) = 0, so w = −11 or w = 1. A path cannot have negative width, so w = 1 m. Check: the outer size is 14 m by 10 m = 140 m².
Use after: Explain phase — Keep or reject? table: thrown ball, t = 1 s (rising) and t = 3 s (falling)
Q6. A football is kicked at Kasarani. Its height after t seconds is h = 20t − 5t² metres. Solving 20t − 5t² = 15 gives t = 1 and t = 3. Why are BOTH answers valid?
  1. One of the answers must be negative, so it is rejected
  2. The ball is at 15 m once on the way up (t = 1 s) and once on the way down (t = 3 s)
  3. t = 3 is an error, because it is bigger than t = 1
  4. Only t = 1 is valid, because the ball reaches 15 m first
Correct answer: B
Substituting gives 20(1) − 5(1)² = 15 and 20(3) − 5(3)² = 60 − 45 = 15. The ball rises through 15 m and falls through it again, so both times fit the situation.
Use after: Explain phase — Challenge a group: when is the ball on the ground? (5t(4 − t) = 0)
Q7. A ball's height is h = 20t − 5t² metres after t seconds, and it is kicked at t = 0. To find when it lands, set h = 0 and solve 20t − 5t² = 0. At what time, in seconds, does the ball land?
  1. 5
  2. 20
  3. 2
  4. 4
Correct answer: D
20t − 5t² = 5t(4 − t) = 0, so t = 0 (the kick) or t = 4. The ball lands at t = 4 s. The value 2 s is when it reaches its highest point (20 m).
Use after: Model Building phase — Cumulative model: 'Form and solve' flowchart
Q8. Which list gives the steps for forming and solving a quadratic equation from a story in the correct order?
  1. Define the variable with units, write the equation, rearrange to ax² + bx + c = 0, factorise and use the zero-product property, check each root in the story
  2. Write the equation, check the roots in the story, define the variable, rearrange to zero, factorise
  3. Define the variable with units, write the equation, factorise, use the zero-product property, rearrange to zero, give both roots as answers
  4. Define the variable with units, write the equation, factorise, rearrange to ax² + bx + c = 0, check the roots in the story
Correct answer: A
The equation must be rearranged to zero before it can be factorised. The zero-product property then gives the roots. Each root is checked against the story last, because the context decides which roots are answers.
