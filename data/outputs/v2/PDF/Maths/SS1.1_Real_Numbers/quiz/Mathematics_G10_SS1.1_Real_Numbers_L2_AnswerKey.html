Q1. A learner says: "The decimal 0.333… (one-third of a kilogram of unga) goes on forever, so it must be irrational like π." Which response is correct?
  1. The learner is wrong, because 0.333… is a whole number.
  2. The learner is correct, because any decimal that never ends is irrational.
  3. The learner is wrong, because 0.333… is equal to 1/3, a ratio of two integers, so it is rational.
  4. The learner is correct, because only terminating decimals can be rational.
Correct answer: C
0.333… repeats the digit 3 forever and equals 1/3, which has the form p/q with integers p and q (q ≠ 0). Repeating decimals are rational. Only decimals that never end AND never repeat are irrational.
Use after: Explain phase — Explain: pairs read the justification for π aloud and the class agrees
Q2. Which statement gives the best reason why π is irrational, so that the mama mboga's daughter could never cut the string to the exact circumference of the sufuria?
  1. π is irrational because it has a decimal point.
  2. π is irrational because its decimal never terminates, even though it can be written as a fraction of two integers.
  3. π is irrational because it cannot be written as p/q with p and q integers, and its decimal 3.14159… never terminates or repeats.
  4. π is irrational because it is a very large number.
Correct answer: C
An irrational number cannot be written as p/q (q ≠ 0, p and q integers), and its decimal neither terminates nor repeats. Both parts are needed for a full justification.
Use after: Explain phase — Explain: classifying the whole numbers on the cards as odd, even, prime or composite
Q3. Which statement about the numbers 1, 7, 28 and 160 is correct?
  1. 7 is an odd prime number.
  2. 1 is a prime number because it is only divisible by itself.
  3. 160 is an odd composite number.
  4. 28 is an even prime number.
Correct answer: A
7 has exactly two factors (1 and 7), so it is odd and prime. 1 is neither prime nor composite. 28 and 160 are even and composite because they have more than two factors.
Use after: Explain phase — Explain: INTEGERS – 'Which cards are integers but not natural numbers?'
Q4. The night temperature on Mt Kenya was −7 °C. Looking at the sets ℕ ⊂ ℤ ⊂ ℚ ⊂ ℝ, which is the smallest set that contains −7?
  1. ℚ, the rational numbers
  2. The irrational numbers
  3. ℕ, the natural numbers
  4. ℤ, the integers
Correct answer: D
−7 is a negative whole number, so it is not a natural number. The smallest set containing it is the integers ℤ. It is also in ℚ and ℝ, but those sets are larger. It is not irrational because −7 = −7/1.
Use after: Explain phase — Explain: pairs re-sort their 12 cards onto a paper Venn diagram
Q5. 1 kg of unga costs Ksh 60.50. A learner says this number is irrational because it has a decimal point. Which response is correct?
  1. The learner is wrong, because 60.50 is a natural number.
  2. The learner is wrong, because 60.50 terminates and can be written as the fraction 121/2, so it is rational.
  3. The learner is correct, because 60.50 is not a whole number.
  4. The learner is correct, because every number with a decimal point is irrational.
Correct answer: B
60.50 = 6050/100 = 121/2, a ratio of two integers, so it is rational. Terminating decimals are always rational, so a decimal point alone does not make a number irrational.
Use after: Model Building phase — Model: first Real Number System Model with a nested Venn diagram of five labelled regions
Q6. In your Real Number System Model you draw the nested diagram ℕ ⊂ ℤ ⊂ ℚ ⊂ ℝ with the irrationals as a region of ℝ. Which statement about this diagram is correct?
  1. ℤ lies outside ℚ because integers cannot be written as fractions.
  2. Irrational numbers lie inside ℚ, next to the integers.
  3. Every natural number is also an integer, a rational number and a real number.
  4. Every rational number is also an integer.
Correct answer: C
Because the sets are nested, every natural number is in ℤ, ℚ and ℝ. Irrationals are in ℝ but outside ℚ. Not every rational is an integer (for example 2/3), and integers can be written as fractions (for example −7 = −7/1).
Use after: End of lesson — End of lesson: revisiting the Kenyan number cards (π and √2 versus 0.333…)
Q7. A 1 m × 1 m plot has a diagonal of length √2 m, which is 1.41421356… with digits that never end and never repeat. Which of these numbers is also irrational?
  1. 0.121212… (the block 12 repeats forever)
  2. 0.333…
  3. π = 3.14159… (the digits never end and never repeat)
  4. 0.5
Correct answer: C
π is irrational because its decimal never terminates and never repeats. 0.5 terminates, and 0.121212… and 0.333… repeat, so all three are rational.
