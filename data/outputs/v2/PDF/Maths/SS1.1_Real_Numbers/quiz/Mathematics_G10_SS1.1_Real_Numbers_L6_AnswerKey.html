Q1. A shopkeeper in Kisumu wants 1 ÷ 4.5 quickly. Without a calculator, which estimate of 1 ÷ 4.5 is sensible?
  1. About 0.45, because you just move the decimal point
  2. About 2.2, because you divide 4.5 by 2
  3. More than 0.25, because 4.5 is a small number
  4. Between 0.2 and 0.25, because 4.5 is between 4 and 5
Correct answer: D
1 ÷ 4 = 0.25 and 1 ÷ 5 = 0.2, so 1 ÷ 4.5 must lie between 0.2 and 0.25.
Use after: Observe phase — Observe: Table Reading Sheet (reading 2.5, 4.5, 8, 3.2 and 4.8)
Q2. Using a table of reciprocals, the reciprocal of 4.8 is read and stated to 4 significant figures. Which value is correct?
  1. 0.208
  2. 0.2083
  3. 2.083
  4. 0.2100
Correct answer: B
1 ÷ 4.8 = 0.20833…, which is 0.2083 to 4 significant figures. 0.208 has only 3 significant figures.
Use after: Observe phase — Observe: Table Reading Sheet (multiply back to check, noting differences between table and division)
Q3. A pair reads 0.2222 from the table as the reciprocal of 4.5. When they multiply back, 4.5 × 0.2222 = 0.9999, not exactly 1. What is the best explanation?
  1. The table of reciprocals is faulty and should not be used
  2. They read the wrong row of the table
  3. The table value is rounded to 4 significant figures, so the product is very close to 1 but not exact
  4. They should have added 4.5 and 0.2222 instead of multiplying
Correct answer: C
1 ÷ 4.5 = 0.2222… never ends, so the table value is rounded. Multiplying back therefore gives a number very near 1, not exactly 1.
Use after: Explain phase — Explain: worked example of 45 = 4.5 × 10 using standard form
Q4. From the table, the reciprocal of 4.5 is 0.2222. Using standard form (45 = 4.5 × 10), what is the reciprocal of 45?
  1. 2.222
  2. 0.002222
  3. 0.2222
  4. 0.02222
Correct answer: D
1/45 = (1/4.5) × (1/10) = 0.2222 × 0.1 = 0.02222. A larger number has a smaller reciprocal.
Use after: Explain phase — Explain: practice with 450, 0.032 and 48
Q5. From the table, the reciprocal of 3.2 is 0.3125. Using standard form, what is the reciprocal of 0.032?
  1. 312.5
  2. 0.03125
  3. 31.25
  4. 3.125
Correct answer: C
0.032 = 3.2 × 10⁻², so 1/0.032 = 0.3125 × 10² = 31.25. Since 0.032 is small, its reciprocal must be large.
Use after: DQB phase — DQB: 'Is a table value exact for 1/π?' and the 'What we now understand' notes
Q6. A learner says, "The table gives the exact reciprocal of every number, even 1/π." Which response is correct?
  1. Correct, because tables are made from exact calculations
  2. Wrong, because table values are given to 4 significant figures, so they are approximations
  3. Wrong, because tables only work for whole numbers
  4. Correct, but only for numbers between 1 and 10
Correct answer: B
Table values are rounded to 4 significant figures. The reciprocal of an irrational number like π never ends, so a table can only give an approximation.
Use after: Model Building phase — Model: adding 'Tables' to the Reciprocal Layer and comparing 1/3.14 with 1/π
Q7. From the table, 1/3.14 = 0.3185 (4 s.f.), but 1/π ≈ 0.3183. Why are the two values different?
  1. Reciprocals of numbers between 1 and 10 are always wrong in the table
  2. The table has a printing error
  3. 1/π cannot be found by division
  4. 3.14 is only an approximation of π, so its reciprocal is not the reciprocal of π
Correct answer: D
The table value is the reciprocal of 3.14, which is a rounded, nearby number and not π itself. This is like cutting the string at 88 cm instead of the exact circumference.
