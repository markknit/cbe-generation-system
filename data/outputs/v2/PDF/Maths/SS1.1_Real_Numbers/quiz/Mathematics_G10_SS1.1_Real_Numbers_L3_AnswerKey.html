Q1. Which of these Kenyan measurements can definitely be written exactly as a fraction p/q, where p and q are integers and q is not 0?
  1. √5, a length in a roof truss
  2. 34.5, the temperature in Kisumu in °C
  3. √2, the diagonal of a 1 m by 1 m tile
  4. π, the circumference of a sufuria divided by its diameter
Correct answer: B
34.5 = 69/2, so it is rational. π, √2 and √5 are irrational, so they cannot be written exactly as a fraction.
Use after: Observe phase — Decimal Detective worksheet: describing the decimal pattern of 0.142857142857… (1 ÷ 7)
Q2. A learner types 1 ÷ 7 on a calculator and sees 0.142857142857… Which description of the decimal is correct?
  1. It never ends and has no pattern, like π
  2. It never ends, so it must be irrational
  3. The same 6 digits, 142857, repeat forever, so the pattern is recurring and the number is a fraction (1/7)
  4. It stops after 6 decimal places
Correct answer: C
The block 142857 repeats forever, so this is a recurring decimal. Recurring decimals are rational, and here the number is 1/7.
Use after: Observe phase — Teacher projects 22 ÷ 7 beside π and learners record the difference in red
Q3. On a calculator, 22 ÷ 7 = 3.142857142857… (the digits 142857 repeat) and π = 3.14159265358979… (no repeating block). A carpenter says 'I use 22/7 for π.' Which statement is correct?
  1. 22/7 is exactly equal to π because both begin 3.14
  2. π is rational because the calculator shows only a limited number of digits
  3. 22/7 is only close to π: it is rational with a repeating decimal, while π is irrational and never repeats
  4. 22/7 is irrational because it is a fraction of two whole numbers that never ends
Correct answer: C
The digits of 22/7 and π differ after 3.14, and 22/7 repeats while π does not. So 22/7 is a rational approximation of π, not equal to it.
Use after: Explain phase — Block 1: definitions of rational and irrational numbers; learners reclassify the ten numbers (√4 = 2 = 2/1)
Q4. A square plot has an area of 4 m². Its side length is √4 m. Which statement is correct?
  1. √4 is irrational because it is not a natural number
  2. √4 is neither rational nor irrational
  3. √4 is irrational because it has a square root sign
  4. √4 = 2 = 2/1, so it is rational
Correct answer: D
√4 is exactly 2, and 2 = 2/1 has the form p/q with integers p and q (q ≠ 0). So √4 is rational even though it is written with a root sign.
Use after: Explain phase — Block 2: recurring decimals as fractions (0.333… = 1/3 and 0.181818… = 2/11)
Q5. Let x = 0.272727… (the digits 27 repeat forever). Multiplying by 100 gives 100x = 27.2727…, so 99x = 27. Which fraction is equal to x in its simplest form?
  1. 1/27
  2. 27/10
  3. 3/11
  4. 27/100
Correct answer: C
100x − x = 27.2727… − 0.2727… = 27, so 99x = 27 and x = 27/99 = 3/11. This shows that a recurring decimal is a fraction in disguise.
Use after: Explain phase — Block 3: back to the phenomenon, completing 'The circumference of the sufuria (28π cm) cannot be written as an exact fraction because π is irrational, which means ___'
Q6. A sufuria has a diameter of 28 cm, so its circumference is 28π cm. Which statement correctly explains why this circumference cannot be written as an exact fraction?
  1. Because calculators do not show enough digits; a better calculator would show the exact fraction
  2. Because π is irrational: its decimal never ends or repeats, so it cannot be written as p/q
  3. Because 28 is too big a number to write as a fraction
  4. Because π equals 22/7, and 22/7 is too long to measure with string
Correct answer: B
π is irrational, so its decimal neither terminates nor repeats and it cannot be written as p/q. Therefore 28π cannot be written as an exact fraction, which is why the string always has a small gap or overlap.
Use after: Model Building phase — Cumulative model: drawing rational (ℚ) and irrational subsets inside the real numbers and placing today's numbers
Q7. A learner draws two non-overlapping regions inside the real numbers, labelled 'Rational' and 'Irrational'. Which placement of numbers is correct?
  1. Rational: 1/3, 22/7. Irrational: √4, π, √2
  2. Rational: 1/3, √4, √2. Irrational: π, 22/7, √5
  3. Rational: 1/3, √4, 22/7. Irrational: π, √2, √5
  4. Rational: 1/3, √4, π. Irrational: 22/7, √2, √5
Correct answer: C
1/3, √4 = 2 and 22/7 are rational, as they are fractions of integers with terminating or recurring decimals. π, √2 and √5 are irrational, with non-terminating, non-recurring decimals.
