Q1. A learner sketches the reflection of a flag outline before using any tools. The correct image of the flag will be on the other side of mirror line m. Which statement about locating the image of vertex A is correct?
  1. Draw a line from A to m at any convenient angle and mark an equal length beyond m
  2. Place A' at the same horizontal distance as A, even if the mirror line is slanted
  3. Slide the whole flag sideways, parallel to the mirror line, to the other side
  4. Drop a perpendicular from A to m and mark A' the same distance beyond m, along that perpendicular
Correct answer: D
The image point lies on the perpendicular from the object point to the mirror line, at an equal distance on the opposite side. Sliding the shape or using other angles gives a wrong image.
Use after: Observe phase — Observe: teacher models the construction of vertex A (measuring 3.2 cm and marking A')
Q2. Vertex A of a flag outline is 3.2 cm from the mirror line m, measured along the perpendicular. After constructing the image point A', what is the distance from A to A'?
  1. 1.6 cm
  2. 9.6 cm
  3. 3.2 cm
  4. 6.4 cm
Correct answer: D
A' is also 3.2 cm from m on the other side, so AA' = 3.2 + 3.2 = 6.4 cm.
Use after: Observe phase — Observe: step (1), placing the set square against the mirror line and drawing the perpendicular from vertex A
Q3. You want to draw the perpendicular from a vertex to the mirror line using a set square. What should you do first?
  1. Place the set square at the vertex and turn it until it touches the mirror line at any angle
  2. Place one edge of the set square flush along the mirror line, then slide it until the perpendicular edge passes through the vertex
  3. Draw a freehand line from the vertex to the mirror line and check it by eye
  4. Measure the distance to the mirror line with a ruler and mark the image point before drawing any line
Correct answer: B
The set square must sit flush along the mirror line first so that the other edge is exactly perpendicular to it. Most construction errors come from a misaligned set square at this step.
Use after: Observe phase — Observe: measuring and recording corresponding sides and angles of the object and the image in the table
Q4. In your measurement table, angle ABC on the object polygon measures 112°. After reflecting the polygon carefully, what should angle A'B'C' on the image measure?
  1. 68°, because the mirror flips the angle to its supplement
  2. It depends on how far the polygon is from the mirror line
  3. 56°, because the image is half the distance from the mirror
  4. 112°, because reflection preserves angles
Correct answer: D
Reflection preserves all lengths and angles, so the image angle equals the object angle: 112°.
Use after: Explain phase — Explain: Kericho land plot PQRS, written prompt 2 (mirror line moved 2 cm to the right)
Q5. A learner reflects the quadrilateral PQRS in a mirror line and then moves the mirror line 2 cm to the right and reflects it again. What happens to the shape and size of the image?
  1. The image becomes 2 cm larger
  2. The shape and size stay the same; only the position of the image changes
  3. The shape of the image changes but its size stays the same
  4. The image becomes smaller because it is further from the object
Correct answer: B
Reflection preserves length, angle and shape wherever the mirror line is placed. Moving the mirror line only moves the position of the image.
Use after: Explain phase — Explain: written prompt 3 (the matatu mirror and the 8 m lorry) and whole-class debrief
Q6. A lorry is 8 m long. A driver looks at its image in a flat matatu rear-view mirror. What is the length of the image of the lorry?
  1. 8 m, because reflection in a flat mirror preserves length
  2. 4 m, because the image is half as far as the object
  3. It depends on how far away the lorry is
  4. 16 m, because the image is the same distance behind the mirror as the lorry is in front
Correct answer: A
Every image point is at the same perpendicular distance from the mirror as its object point, so distances between image points equal those between object points. The image is 8 m long. Far objects only look smaller to the eye.
Use after: DQB phase — Driving Question Board: two-sentence caption and consensus diagram 'Every point reflects to a unique image point — object and image are congruent'
Q7. After constructing a reflected image of a polygon on plain paper, which caption best states what the construction proves?
  1. The image is always larger than the object because it is on the other side of the mirror
  2. Every point reflects to a unique image point, and the image is congruent to the object
  3. The image is only an approximation of the object, close in size and shape
  4. The image is the same as the object, but it is moved parallel to the mirror line
Correct answer: B
Each vertex has exactly one image point at an equal perpendicular distance, and measuring shows all lengths and angles are preserved. The image is therefore congruent to the object (Object ≅ Image).
