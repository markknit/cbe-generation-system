Q1. A group pins a paper equilateral triangle at its centre and turns it clockwise. It covers its outline exactly again at some angles up to one full turn. At which angles does it fit its outline?
  1. 90°, 180°, 270° and 360°
  2. 180° and 360°
  3. 120°, 240° and 360°
  4. 60°, 120°, 180°, 240°, 300°, 360°
Correct answer: C
An equilateral triangle fits its outline every 360° ÷ 3 = 120°, so at 120°, 240° and 360°. This gives order 3.
Use after: Observe phase — Step 1: repeating the investigation for the square and the regular hexagon, group record check
Q2. One group records 'order 6' for a square cutout turned about its centre in one full 360° turn. What is the correct order of rotational symmetry of the square, and why?
  1. Order 2, because a square only fits after 180°
  2. Order 6, because a square has six edges and corners counting both
  3. Order 4, because it fits its outline at 90°, 180°, 270° and 360°
  4. Order 8, because a square has four sides and four corners
Correct answer: C
A square fits its outline every 360° ÷ 4 = 90°, giving four positions in a full turn, so the order is 4. Order 6 comes from miscounting.
Use after: Observe phase — Step 3: compiling the class table and matching the kiondo basket image to the hexagon row
Q3. A Kikuyu kiondo basket has a regular hexagon weave pattern when viewed from above. What is the angle between one position where the pattern looks identical and the next, as it is turned about its centre?
  1. 60°
  2. 120°
  3. 30°
  4. 45°
Correct answer: A
A regular hexagon has order 6, so the angle between identical positions is 360° ÷ 6 = 60°.
Use after: Observe phase — Step 2: handling the solid models (cone prompt about every position around the vertical axis)
Q4. A right circular cone stands on its base. It is turned about the vertical axis through its apex and the centre of its base. What is its order of rotational symmetry about this axis?
  1. Infinite order, because it looks the same after every turn
  2. Order 2, because it has a round base and a point
  3. Order 4, because it has a vertical axis
  4. Order 1, because it only fits after a full turn
Correct answer: A
A cone is perfectly round about its vertical axis, so it looks identical after every amount of turning. Its order is infinite.
Use after: Observe phase — Step 2: identifying axis and order for the triangular prism
Q5. A triangular prism has ends that are equilateral triangles. An axis joins the centres of the two triangular ends. What is the order of rotational symmetry of the prism about this axis?
  1. Order 3
  2. Order 6
  3. Order 2
  4. Order 1
Correct answer: A
Turning the prism about this axis, the equilateral triangle ends fit onto themselves every 120°, so the order is 3. Order 2 comes from confusing the rectangular faces with the triangle symmetry.
Use after: Explain phase — Task A: regular pentagon, predict its order using angle = 360°/n
Q6. A regular pentagon is not cut out. Using angle = 360° ÷ n, what is the smallest angle that turns it onto itself?
  1. 108°
  2. 60°
  3. 72°
  4. 90°
Correct answer: C
A regular pentagon has order 5, so the smallest angle is 360° ÷ 5 = 72°.
Use after: Observe phase — After the class table is complete: the minute hand of the Nairobi clock image
Q7. Look at just the minute hand of a clock, a single straight arm turned about the centre of the clock. What is its order of rotational symmetry, and why?
  1. Order 4, because it points at 12, 3, 6 and 9
  2. Order 2, because it looks the same after a half turn
  3. Order 1, because it only fits onto itself after a full 360° turn
  4. Order 12, because the clock has 12 numbers
Correct answer: C
The hand only returns to an identical position after 360°, so it maps onto itself once in a full turn. Its order is 1.
Use after: DQB phase — DQB update: capstone entry on the order of the 12 hour-marks of the clock face
Q8. The 12 hour-marks of a clock face are equally spaced. Ignoring the numerals, hands and minute marks, through what smallest angle can the clock face be turned so that it maps onto itself?
  1. 60°
  2. 90°
  3. 12°
  4. 30°
Correct answer: D
The 12 hour-marks give order 12, so the smallest angle is 360° ÷ 12 = 30°.
Use after: Model Building phase — Model building: adding the hexagon layer and the model limitation note
Q9. A learner draws a regular hexagon on a coordinate grid to model a 3-D kiondo basket. Which statement is a limitation of this model?
  1. It shows too many vertices to be a regular hexagon
  2. It only shows a 2-D cross-section, so it does not show the axis and depth of the 3-D basket
  3. It cannot show that the hexagon has order 6
  4. It cannot show a 60° rotation between vertices
Correct answer: B
A flat hexagon shows only one cross-section. The full symmetry of the 3-D basket must also account for its axis and depth.
