Q1. A scalene triangle is rotated 90° about a point. The object and its image are cut out of paper and kept flat and face up on a desk. What is needed to make the image fit exactly onto the object?
  1. Sliding alone, with no turning
  2. The image can never fit, because rotation changes the size
  3. Sliding and turning on the desk, with no flipping over
  4. Flipping the cutout over so it faces down
Correct answer: C
A rotated image fits its object by sliding and turning while it stays flat and face up. No flipping is needed, so rotation gives direct congruence.
Use after: Observe phase — Part: Observe - three-action test on Pair C (irregular quadrilateral and its reflection image)
Q2. An irregular quadrilateral and its reflection image are cut out of paper. Sliding and turning the image flat on the desk does not make it fit the object. What must you do to make it fit?
  1. Slide it further across the desk
  2. Turn it through a bigger angle on the desk
  3. Flip the cutout over so it faces down
  4. Make the cutout larger
Correct answer: C
A reflected image is a mirror image, so it fits only after the cutout is flipped over. This is the signature of opposite congruence.
Use after: Explain phase — Part: Explain - introducing direct and opposite congruence and completing the three-column table
Q3. Triangle ABC has its vertices in the order A→B→C going anticlockwise. The triangle is reflected in a mirror line to give A'B'C'. Which statement is correct about the order A'→B'→C'?
  1. It goes clockwise, so the image is oppositely congruent
  2. It also goes anticlockwise, so the image is directly congruent
  3. It goes clockwise, so the image is directly congruent
  4. It goes anticlockwise, so the image is oppositely congruent
Correct answer: A
A reflection reverses the order of the vertices, so anticlockwise becomes clockwise. This is opposite congruence. Direct congruence keeps the same sense.
Use after: Explain phase — Part: Explain - worked-example card, part (a) verifying congruence by measuring side lengths
Q4. Triangle PQR has vertices P(1, 2), Q(4, 2) and R(4, 6). It is rotated 90° anticlockwise about the origin to give P'(-2, 1), Q'(-2, 4) and R'(-6, 4). What is the length of P'R'?
  1. 7 units
  2. 5 units
  3. 3 units
  4. 25 units
Correct answer: B
P'R' = sqrt((-6 - (-2))² + (4 - 1)²) = sqrt(16 + 9) = sqrt(25) = 5. This equals PR = 5, so the sides are equal and the triangles are congruent.
Use after: Explain phase — Part: Explain - class discussion 'Rotation turns the shape, so why is the image still directly congruent?'
Q5. A learner says: "Rotation turns the shape, so the image must need flipping over to match the object, which makes it opposite congruence." Which reply is correct?
  1. The learner is right, because rotation reverses the order of the vertices
  2. The learner is wrong, because a rotated image is not congruent to its object
  3. The learner is wrong, because rotation keeps the vertex order going the same way round, so no flipping is needed
  4. The learner is right, because any turning is the same as flipping
Correct answer: C
Rotation keeps the order of the vertices going the same way round, for example anticlockwise stays anticlockwise. The image matches the object by sliding and turning flat, so the congruence is direct. Only reflection reverses the order.
Use after: DQB phase — Part: Driving Question Board - clock question 'Minute hand at 12:00 and at 12:15 - direct or opposite congruence?'
Q6. The minute hand of a clock is at 12:00. It then turns to its position at 12:15. What type of congruence connects the two positions of the hand, and why?
  1. Opposite congruence, because the hand has been turned
  2. Opposite congruence, because the hand points in a different direction
  3. They are not congruent, because the hand has moved
  4. Direct congruence, because the hand is turned, not flipped over, so it still fits the first position by turning
Correct answer: D
The hand is only turned about the centre of the clock. Its shape and size do not change and it is not flipped, so the two positions are directly congruent.
Use after: Model Building phase — Part: Model Building - 'Congruence Landscape' branching diagram
Q7. Which row correctly gives the type of congruence produced by each transformation?
  1. Translation: direct; Rotation: opposite; Reflection: opposite
  2. Translation: direct; Rotation: direct; Reflection: opposite
  3. Translation: opposite; Rotation: direct; Reflection: direct
  4. Translation: direct; Rotation: direct; Reflection: direct
Correct answer: B
Translation and rotation need only sliding and/or turning flat, so they give direct congruence. Reflection needs the cutout flipped over, so it gives opposite congruence.
