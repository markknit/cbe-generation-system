Q1. One matatu travels 3 blocks east and 4 blocks north from Kencom. Another matatu travels 5 blocks east and 0 blocks north from Kencom. Are these two journeys the same displacement?
  1. No, because only the second journey is a vector
  2. Yes, because both journeys go towards the east
  3. Yes, because both journeys start from the same place, Kencom
  4. No, because the horizontal and vertical parts of the two journeys are different
Correct answer: D
A displacement needs both a horizontal and a vertical part. The first journey is 3 east and 4 north, and the second is 5 east and 0 north, so their components differ and the journeys are not the same.
Use after: Observe phase — Observe: learners plot B = Uhuru Park at (-1, 2), draw OB and write its column vector
Q2. On a Cartesian grid with Kencom at the origin O, Uhuru Park is at point B (-1, 2). Column vectors are written here as (top / bottom). Which is the column vector OB?
  1. (2 / -1)
  2. (1 / 2)
  3. (-1 / 2)
  4. (-1 / -2)
Correct answer: C
The top number is the horizontal move (1 unit west is -1) and the bottom number is the vertical move (2 units north is 2). So OB = (-1 / 2).
Use after: Explain phase — Explain: pair task calculating AB = OB - OA from the position vectors of KICC and Uhuru Park
Q3. On a grid with origin O at Kencom, KICC is at A (2, 3) and Uhuru Park is at B (-1, 2). So OA = (2 / 3) and OB = (-1 / 2). Which is the column vector AB, the journey from KICC to Uhuru Park?
  1. (-3 / -1)
  2. (1 / -1)
  3. (3 / 1)
  4. (-3 / 1)
Correct answer: A
AB = OB - OA = (-1 - 2 / 2 - 3) = (-3 / -1). This means 3 units west and 1 unit south. Choosing (3 / 1) comes from subtracting in the wrong order.
Use after: Explain phase — Explain: consolidation RULE on the board, AB = OB - OA (position vector of where you are minus where you start)
Q4. P and Q are two landmarks on a grid with origin O. Which rule correctly gives the vector PQ, the journey from P to Q?
  1. PQ = OQ, because every journey starts at O
  2. PQ = OP + OQ, which is the two position vectors added
  3. PQ = OQ - OP, which is where you end minus where you start
  4. PQ = OP - OQ, which is where you start minus where you end
Correct answer: C
The vector from P to Q is the position vector of the end point minus the position vector of the start point. Reversing the order gives the vector QP, which points the opposite way.
Use after: Explain phase — Explain: extension task introducing C = Nairobi Railway Station at (-3, -2) and finding BC = OC - OB
Q5. On a grid with origin O at Kencom, Uhuru Park is at B (-1, 2) and Nairobi Railway Station is at C (-3, -2). Which is the column vector BC, the journey from Uhuru Park to the Railway Station?
  1. (-2 / -4)
  2. (-4 / -2)
  3. (2 / 4)
  4. (-4 / 0)
Correct answer: A
BC = OC - OB = (-3 - (-1) / -2 - 2) = (-2 / -4). That means 2 units west and 4 units south. (2 / 4) comes from subtracting in the wrong order.
Use after: DQB phase — Driving Question Board: green sticky note on how column vectors answer why two matatu journeys of the same distance end at different destinations
Q6. From Kencom, Driver 1 ends at (-6, 5) and Driver 2 ends at (5, -6). Both travelled about the same distance, 8 km. Which statement best explains why they arrived at different places?
  1. Their column vectors are the same, but the drivers wrote the numbers in a different order
  2. Their column vectors have different components, so they moved in different directions, even though the distance is the same
  3. Distance alone is enough to fix the destination, so one driver must have made an error
  4. One driver must have travelled further than the other
Correct answer: B
Driver 1's displacement is (-6 / 5), which is west and north. Driver 2's is (5 / -6), which is east and south. The distance is the same but the full column vectors are different, so the endpoints are different.
Use after: Model Building phase — Model Building: adding column vectors and the derived displacement vector AB to the Nairobi Vector Map
Q7. A column vector is written as (top / bottom), where the top number is the horizontal move (east is positive) and the bottom number is the vertical move (north is positive). What journey does the column vector (-3 / -1) describe?
  1. 3 units west and 1 unit south
  2. 1 unit west and 3 units south
  3. 3 units south and 1 unit west
  4. 3 units east and 1 unit north
Correct answer: A
The top number -3 means 3 units west and the bottom number -1 means 1 unit south. The horizontal part always comes first, so the components cannot be swapped.
