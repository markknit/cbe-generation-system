Q1. In a 3 V test circuit with a torch bulb, a piece of dry wood is connected in place of copper wire and the bulb stays dark. Which statement best explains this?
  1. Dry wood has a very high resistivity, so the current is too small to light the bulb, but it is not exactly zero.
  2. Dry wood has no electrons, so no current can ever flow in it.
  3. Dry wood has a very low resistivity, so the current is used up before it reaches the bulb.
  4. Dry wood is a semiconductor, so it only works when connected in the reverse direction.
Correct answer: A
Dry wood has a resistivity of about 10^8 to 10^11 ohm metre, so only a tiny current flows, far too small to light the bulb. The current is almost zero, not exactly zero, and wood still contains electrons.
Use after: Observe phase — Part B: arranging the resistivity cards on a number line of powers of ten
Q2. Resistivity values at about 20 C are: copper 1.7 x 10^-8 ohm metre, germanium 0.46 ohm metre, silicon 2.3 x 10^3 ohm metre, PVC about 10^13 ohm metre. Which list is in order from LOWEST to HIGHEST resistivity?
  1. PVC, silicon, germanium, copper
  2. Germanium, copper, silicon, PVC
  3. Copper, silicon, germanium, PVC
  4. Copper, germanium, silicon, PVC
Correct answer: D
Compare the powers of ten: 10^-8 is smaller than 0.46 (about 10^-1), which is smaller than 10^3, which is smaller than 10^13. So the order is copper, germanium, silicon, PVC.
Use after: Observe phase — Part B: calculating conductivity 1/rho for copper and silicon
Q3. Pure silicon has a resistivity of 2.3 x 10^3 ohm metre. Conductivity is 1/resistivity. What is the conductivity of silicon, to two significant figures?
  1. 2.3 x 10^-3 per ohm metre
  2. 2.3 x 10^3 per ohm metre
  3. 4.3 x 10^3 per ohm metre
  4. 4.3 x 10^-4 per ohm metre
Correct answer: D
Conductivity = 1/rho = 1 / (2.3 x 10^3) = 4.3 x 10^-4 per ohm metre. A large resistivity gives a small conductivity.
Use after: Observe phase — Part B: calculating how many times silicon is more resistive than copper
Q4. Copper has a resistivity of 1.7 x 10^-8 ohm metre and pure silicon has a resistivity of 2.3 x 10^3 ohm metre. About how many times more resistive is silicon than copper?
  1. 1.4 x 10^11 times
  2. 3.9 x 10^-5 times
  3. 1.4 x 10^-11 times
  4. 1.4 x 10^5 times
Correct answer: A
Ratio = 2.3 x 10^3 divided by 1.7 x 10^-8, which is about 1.4 x 10^11. Silicon is about 140 billion times more resistive than copper.
Use after: Observe phase — Part B: sorting materials into conductor, semiconductor and insulator columns
Q5. Germanium has a resistivity of 0.46 ohm metre at about 20 C. Copper is 1.7 x 10^-8 ohm metre and PVC is about 10^13 ohm metre. How should germanium be classified?
  1. Conductor, because it is a solid
  2. Insulator, because it is much more resistive than copper
  3. Conductor, because its resistivity is less than 1 ohm metre
  4. Semiconductor, because its resistivity lies between that of conductors and insulators
Correct answer: D
0.46 ohm metre is far above copper (a conductor) and far below PVC (an insulator), so germanium is a semiconductor, as is silicon.
Use after: Explain phase — Claim-evidence-reasoning explanation: why Mr Otieno uses copper cable covered in PVC
Q6. Mr Otieno, an electrician in Nairobi, wires a house with copper cable covered in PVC at 240 V. Which explanation best shows why a person can safely hold the insulated cable?
  1. Copper has a very low resistivity so it carries current well, while PVC has a very high resistivity so almost no current passes through it to the hand.
  2. PVC has no electrons, so no current at all can pass through it.
  3. A thicker wire matters more than the material, so the cover has no effect on safety.
  4. Copper is a poor conductor, so the PVC cover is only there to hold it together.
Correct answer: A
Copper (1.7 x 10^-8 ohm metre) carries current efficiently. PVC (about 10^13 ohm metre or more) allows almost no current, so the current stays in the wire. PVC still has electrons and is not perfectly non-conducting.
Use after: Explain phase — Claim-evidence-reasoning explanation: what silicon being in between means and why it is neither a good wire nor a good cover
Q7. Pure silicon has a resistivity of 2.3 x 10^3 ohm metre. Copper is 1.7 x 10^-8 ohm metre and PVC is about 10^13 ohm metre. Why is silicon NOT a good choice for either the wire or the cover of household cable?
  1. Silicon has the same resistivity as copper, so it cannot be told apart from it.
  2. Silicon is a better conductor than copper, so it would be wasted as a wire.
  3. Silicon is too resistive to carry current efficiently like copper, but not resistive enough to stop current like PVC.
  4. Silicon is an insulator that allows no current at all.
Correct answer: C
Silicon's resistivity lies in between: it is about 10^11 times more resistive than copper, so it makes a poor wire, and about 10^10 times less resistive than PVC, so it would not keep the current in the wire.
