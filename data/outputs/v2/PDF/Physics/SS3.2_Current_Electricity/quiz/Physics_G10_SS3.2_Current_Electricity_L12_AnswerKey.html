Use after: Predict phase — Predict: sketch a circuit and predict the current when four 36 W tubes are all on 240 V
Q1. A Kericho dormitory has four identical 36 W tubes, each connected on its own branch directly across a 240 V supply. What is the total current drawn when all four tubes are on?
  1. 0.60 A
  2. 0.15 A
  3. 1.67 A
  4. 6.67 A
Correct answer: A
Each tube draws I = P/V = 36/240 = 0.15 A. Branch currents add in parallel, so the total is 4 x 0.15 = 0.60 A.
Use after: Predict phase — Predict: how would you wire the tubes so that one failure does not darken the room, and what if they were in series
Q2. An electrician wants the other tubes in a dormitory to stay lit when one tube fails. How should the tubes be wired?
  1. In series, so the same current passes through every tube
  2. In parallel, so each tube is on its own branch across the full supply
  3. In parallel, so the first tube uses up the current before it reaches the others
  4. In series, so the tubes share the supply voltage equally
Correct answer: B
In parallel each tube has its own branch with the full supply p.d. A failed tube breaks only its own branch. The last option is wrong because current is not used up.
Use after: Observe phase — Observe: (a) connect the three bulbs in series and record the current
Q3. Three identical 30 Ω bulbs are connected in series to a 9 V battery. What current flows through the battery?
  1. 0.33 A
  2. 0.10 A
  3. 0.90 A
  4. 0.30 A
Correct answer: B
In series the total resistance is 3 x 30 = 90 Ω. The current is I = V/R = 9/90 = 0.10 A.
Use after: Explain phase — Explain: Final Explanation, why power is nine times bigger in parallel (P = IV)
Q4. Three identical bulbs are connected in series to a 9 V battery. Each has a p.d. of 3.0 V and a current of 0.10 A. When the same bulbs are connected in parallel to the same battery, each has 9.0 V and 0.30 A. Why is the power of each parallel bulb nine times greater?
  1. Because the parallel circuit has a larger total resistance
  2. Because the battery gives out more voltage in a parallel circuit
  3. Because the current is three times bigger and the p.d. is also three times bigger, and P = IV
  4. Because the current is nine times bigger and the p.d. stays the same
Correct answer: C
P = IV. Series: 0.10 x 3.0 = 0.30 W. Parallel: 0.30 x 9.0 = 2.7 W. Current is 3 times bigger and p.d. is 3 times bigger, so power is 3 x 3 = 9 times bigger.
Use after: Explain phase — Explain: failed series component opens the single loop (the Christmas-light string)
Q5. An old string of Christmas lights has its bulbs connected in series. One bulb fails and the filament breaks. Why does the whole string go dark?
  1. The p.d. across each remaining bulb drops to zero but the current continues
  2. The failed bulb uses up all the current from the battery
  3. The other bulbs each receive the full supply p.d. and burn out
  4. The broken filament opens the only loop, so the current is zero everywhere
Correct answer: D
A series circuit has only one loop. A broken filament makes a gap, so I = 0 in every bulb and all go out.
Use after: Explain phase — Explain: Nairobi classroom numbers, current drops from 0.60 A to 0.45 A when one tube blows
Q6. In a Nairobi classroom, four identical 36 W tubes are wired in parallel on a 240 V supply. One tube blows. What is the total current now, and what p.d. is across each remaining tube?
  1. 0.60 A and 240 V
  2. 0.45 A and 240 V
  3. 0.15 A and 240 V
  4. 0.45 A and 80 V
Correct answer: B
Each remaining tube still has 240 V and draws 36/240 = 0.15 A. Three tubes give 3 x 0.15 = 0.45 A in total.
Use after: DQB phase — Driving Question Board: Why are resistors used in electrical circuits?
Q7. A learner says: 'A resistor is useful in a circuit because it limits the current for a given p.d.' Which equation supports this idea?
  1. I = P/V, because resistance has no effect on current
  2. V = I + R, because resistance adds to the voltage
  3. V = IR, because for the same V a larger R gives a smaller I
  4. P = IV, because more resistance always gives more power
Correct answer: C
From V = IR, I = V/R. For a fixed p.d., a larger resistance gives a smaller current, which is why resistors limit current.
Use after: Model Building phase — Model Part 2: design a safe lighting circuit with a 13 A fuse or breaker in the live wire
Q8. In a classroom lighting circuit, where should the 13 A fuse or circuit breaker be placed?
  1. On the live wire, so the tubes are cut off from the supply when it trips
  2. In the earth wire, so it can carry the fault current
  3. In the neutral wire, so the current is stopped after the tubes
  4. Between the tubes, so each tube has its own fuse in series with the next
Correct answer: A
A fuse or breaker on the live wire disconnects the live supply when the current is too large. This protects people and cables from shock and fire.
Use after: End of lesson — Model Part 2: calculate the cost of running the tubes for 5 h
Q9. Four 36 W tubes (144 W in total) run for 5 hours. Electricity costs KSh 25 per kWh (an assumed teaching tariff). What is the cost?
  1. KSh 18
  2. KSh 3.60
  3. KSh 72
  4. KSh 3600
Correct answer: A
144 W = 0.144 kW. Energy = 0.144 x 5 = 0.72 kWh. Cost = 0.72 x 25 = KSh 18.
