Q1. A nyatiti string is fixed at both ends. A wave travelling along the string reaches one fixed end. What does the wave do there?
  1. It stops and stays at the end of the string
  2. It speeds up and leaves the string
  3. It is reflected and travels back along the string
  4. It disappears at the end and is lost
Correct answer: C
As with an echo from a cliff, a wave reaching a fixed end is reflected and travels back. This reflected wave later meets the incoming wave.
Use after: Observe phase — Observe, Station A and Station B: recording loops, nodes (including ends) and antinodes for the fundamental and second harmonic
Q2. A 0.60 m nyatiti string vibrates in its second harmonic (two loops). How many nodes (counting both fixed ends) and how many antinodes does the stationary wave have?
  1. 2 nodes and 2 antinodes
  2. 2 nodes and 3 antinodes
  3. 3 nodes and 2 antinodes
  4. 4 nodes and 3 antinodes
Correct answer: C
Two loops give 2 antinodes, one in the middle of each loop. The nodes are at the two ends and in the middle, giving 3 nodes. A node is a point of zero amplitude and an antinode is a point of maximum amplitude.

Q3. Why does a vibrating string show a stationary wave pattern that stays in place instead of a wave that travels along it?
  1. Two waves travelling in the same direction add up to give a bigger wave
  2. The string stops the wave from moving when it is plucked
  3. Plucking the string harder makes the wave stay in one place
  4. The wave and its reflection travel in opposite directions and superpose, adding at antinodes and cancelling at nodes
Correct answer: D
The incident wave and the wave reflected from the fixed end travel in opposite directions and interfere. They add (constructive) at antinodes and cancel (destructive) at nodes, so the pattern stays in place.

Q4. A nyatiti string has a vibrating length of 0.60 m. The wave speed on the string is 120 m/s. What is the frequency of the fundamental (one loop)?
  1. 100 Hz
  2. 200 Hz
  3. 50 Hz
  4. 144 Hz
Correct answer: A
For the fundamental, wavelength = 2L = 2 x 0.60 = 1.20 m. Then f = v/wavelength = 120/1.20 = 100 Hz. Using L instead of 2L as the wavelength gives the wrong value of 200 Hz.
Use after: Explain phase — Explain, Step 3: flute calculation (open tube L = 0.34 m, v = 340 m/s)
Q5. A flute is modelled as an open tube of length 0.34 m. The speed of sound in air is 340 m/s. What is the frequency of its fundamental note?
  1. 250 Hz
  2. 1000 Hz
  3. 500 Hz
  4. 116 Hz
Correct answer: C
For the fundamental in an open tube, wavelength = 2L = 2 x 0.34 = 0.68 m. Then f = v/wavelength = 340/0.68 = 500 Hz. Taking the wavelength as L gives the wrong value of 1000 Hz.
Use after: Explain phase — Explain: pitch depends on frequency, and a shorter string or tube gives a higher pitch
Q6. A nyatiti player presses a string against the neck so that the vibrating length becomes shorter. What happens to the note?
  1. The pitch stays the same but the note is louder
  2. The pitch depends only on how hard the string is plucked
  3. The frequency is lower, so the pitch is lower
  4. The frequency is higher, so the pitch is higher
Correct answer: D
A shorter string has a shorter wavelength (wavelength = 2L), so with the same wave speed the frequency f = v/2L is higher. Pitch depends on frequency, while loudness depends on amplitude.
Use after: DQB phase — DQB: 'Which of our earlier questions about the muddy Kisumu hall does resonance help with?'
Q7. In a school hall in Kisumu with hard walls, some notes sound extra loud and boom, while others do not. Which explanation fits best?
  1. The echo of those notes takes longer to come back
  2. Louder notes always have a higher frequency
  3. The frequency of those notes matches a natural frequency of the hall, so the vibration grows large (resonance)
  4. Sound waves stop completely at nodes, so the other notes are lost
Correct answer: C
Resonance happens when a driving frequency matches a natural frequency of the system. The reflections in the hall then reinforce that note and the amplitude becomes large. Loudness depends on amplitude, not on frequency.
