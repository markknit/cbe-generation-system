Q1. Carbon has atomic number 6. Which choice correctly gives its electron configuration and the number of electrons that take part in bonding (valence electrons)?
  1. Configuration 6; 6 valence electrons
  2. Configuration 2,4; 6 valence electrons
  3. Configuration 2,4; 2 valence electrons
  4. Configuration 2,4; 4 valence electrons
Correct answer: D
Six electrons fill shell 1 (2) and then shell 2 (4), giving 2,4. Only the 4 electrons in the outermost shell are valence electrons; the 2 inner electrons do not bond.
Use after: Observe phase — Part: 'Mapping Outer Electrons Across Periods 1-3' worksheet and the chlorine finger-check
Q2. A chlorine atom has atomic number 17, so its electron configuration is 2,8,7. How many valence electrons does it have?
  1. 17
  2. 1
  3. 8
  4. 7
Correct answer: D
Valence electrons are those in the outermost shell only. Working: 17 - 2 - 8 = 7, which matches the 7 in the third shell. Counting all 17 electrons is the common error of including inner-shell electrons.
Use after: Observe phase — Class discussion: 'What do you notice about where this sequence resets?'
Q3. Across Period 2 (Li to Ne) the number of valence electrons goes 1, 2, 3, 4, 5, 6, 7, 8. Why does the count go back to 1 at sodium (Na, 2,8,1)?
  1. Sodium is a noble gas, so it starts again
  2. Sodium has lost seven of its electrons
  3. Sodium starts filling a new third shell, which holds one electron
  4. Sodium has only one electron altogether
Correct answer: C
Neon's second shell is full (2,8). Sodium's 11th electron must go into a new third shell, so it has 1 valence electron. The pattern repeats in each new period.
Use after: Explain phase — Matatu analogy and the board statement 'OCTET RULE'
Q4. Which statement correctly describes the octet rule and the duplet rule?
  1. Period 1 atoms need 8 electrons, and Period 2 atoms need 2
  2. Atoms react to get 8 valence electrons, or 2 for Period 1 atoms such as hydrogen, matching the nearest noble gas
  3. All atoms need exactly 8 electrons in total, including inner shells
  4. Atoms with 8 valence electrons react very easily to lose them
Correct answer: B
The octet rule says atoms tend to gain, lose or share electrons to reach 8 valence electrons, like a noble gas. Period 1 has only one shell, which holds 2 electrons (duplet rule).
Use after: Explain phase — Mini-whiteboard practice: drawing Lewis dot diagrams for N, O, F, Ne and Period 3 elements
Q5. Which is the correct Lewis dot diagram for a nitrogen atom (atomic number 7, configuration 2,5)?
  1. Seven dots spread around the symbol, all in pairs except one
  2. Five dots: one dot on each of the four sides, then the fifth paired with one of them
  3. Five dots, all drawn on one side of the symbol
  4. Three dots, one on each of three sides
Correct answer: B
Nitrogen has 5 valence electrons. Dots go one per side first (4 dots), and the fifth is paired with one of them. This gives one pair and three unpaired dots.
Use after: Explain phase — Carbon Lewis dot diagram question: 'What does that tell us about how many bonds it can form?'
Q6. A carbon atom has 4 valence electrons shown as 4 unpaired dots. What does this tell us about the number of bonds carbon can form?
  1. 2 bonds, because only half of the dots can be shared
  2. 6 bonds, because carbon has 6 electrons altogether
  3. 8 bonds, because it wants to have an octet
  4. 4 bonds, because it needs 4 more electrons to complete its octet by sharing
Correct answer: D
Each unpaired valence electron can be shared in a bond. Carbon has 4 and needs 4 more to reach 8, so it can form four bonds. This is why carbon is so versatile.
Use after: Explain phase — Matatu analogy question: 'How many electrons does ... sodium need to gain, lose, or share?'
Q7. A sodium atom has configuration 2,8,1. What is the easiest way for it to reach a full outer shell like a noble gas?
  1. Lose all 11 electrons
  2. Gain 7 electrons to make a full third shell
  3. Share 4 electrons with another atom
  4. Lose its 1 outer electron so that its full second shell becomes the outer shell
Correct answer: D
Losing one electron leaves sodium with configuration 2,8, a full outer shell like neon. Gaining 7 electrons would take far more change than losing 1.
