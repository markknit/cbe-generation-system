Q1. A teacher dips a clean nichrome wire loop into sodium chloride (table salt) solution and holds it in a Bunsen burner flame. What colour does the flame show?
  1. Bright yellow-orange
  2. Blue-green
  3. No colour change at all
  4. Violet
Correct answer: A
Sodium chloride gives a vivid yellow-orange flame, the same colour the cook saw when salt fell into the hearth fire.
Use after: Observe phase — Observe: potassium chloride flame test
Q2. A teacher holds a nichrome loop dipped in potassium chloride solution in a Bunsen flame in a dim room. Which colour is seen?
  1. Bright red
  2. Blue-green
  3. Bright yellow-orange
  4. Faint lilac-violet
Correct answer: D
Potassium chloride gives a faint lilac-violet flame, fainter and shorter-lived than sodium's yellow. This matches the violet flash the neighbour saw from banana-peel ash.
Use after: Observe phase — Observe: two-column table comparing predictions with observations (solution colour vs flame colour)
Q3. In a flame test, colourless potassium chloride solution gives a lilac flame. Blue copper sulphate solution gives a blue-green flame. Which conclusion is best supported by these two observations?
  1. The flame colour is always exactly the same as the colour of the solution
  2. The solution colour alone does not explain the flame colour, because a colourless solution gave a coloured flame
  3. All solutions give the same flame colour if the flame is hot enough
  4. Colourless solutions can never make a coloured flame
Correct answer: B
Colourless potassium chloride still gave a lilac flame, so the colour we see in the solution cannot be the whole story. The lesson does not explain the reason yet.
Use after: Observe phase — Observe: potassium chloride test and cleaning the wire in dilute hydrochloric acid between tests
Q4. During a flame test with potassium chloride, a student sees a brief yellow flicker in the faint lilac flame. What does the lesson suggest is the most likely cause?
  1. Potassium always gives yellow at the start of every test
  2. The solution has changed into sodium chloride
  3. The Bunsen burner gas has run out
  4. Sodium contamination left on the wire
Correct answer: D
Sodium gives a strong yellow-orange colour, so even a trace of it on the wire can show as a yellow flicker. This is why the wire is cleaned in dilute hydrochloric acid between tests.
Use after: Observe phase — Observe: repeating the sodium chloride test to confirm repeatability
Q5. The teacher repeats the sodium chloride flame test a second time. What does the second test show?
  1. The flame turns violet because the wire is now hot
  2. No colour appears because the salt has been used up
  3. The same yellow-orange colour appears again, so the result is repeatable
  4. The colour is random and changes each time
Correct answer: C
The second sodium chloride test gives the same yellow-orange colour. This shows the observation is repeatable and not a one-off accident.
Use after: Explain phase — Explain: whole-class discussion and concept web ('Our ideas so far')
Q6. The class has seen that sodium always gives yellow and potassium always gives violet. At the end of the discussion, which statement best describes where the class is?
  1. The class has noticed a clear pattern but cannot yet explain why the type of atom changes the flame colour
  2. The class has already proved the colour comes from the dye in each salt
  3. The class has shown that fire is just heat, so atoms have no effect on the colour
  4. The class has shown the colour comes only from the nichrome wire
Correct answer: A
The lesson ends with the pattern noticed (different substance, different repeatable colour) and the explanation still unanswered. The teacher names this as the starting point for the unit.
Use after: DQB phase — DQB: writing a question on a sticky note for 'OUR DRIVING QUESTION BOARD'
Q7. Which of these is the best question to post on the Driving Question Board after watching the flame tests?
  1. What is the price of a Bunsen burner?
  2. Should the teacher repeat the demonstration tomorrow?
  3. Why does sodium always give the same yellow-orange colour every time?
  4. When is the next chemistry test?
Correct answer: C
A good Driving Question Board question starts with Why, How or What and asks about the phenomenon the class observed. The sodium question does this and can guide the investigation.
