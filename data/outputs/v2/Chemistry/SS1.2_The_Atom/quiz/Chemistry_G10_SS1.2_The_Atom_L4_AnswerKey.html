Q1. Sodium-23 and sodium-24 are two isotopes of sodium (atomic number 11). Sodium-24 is slightly heavier because it has one extra neutron. A pinch of each is placed in a Bunsen burner flame. What do you predict?
  1. Sodium-23 gives yellow and sodium-24 gives violet because the masses are different
  2. Sodium-24 gives no colour because it has an extra neutron
  3. Sodium-24 gives a different colour because its heavier nucleus changes the energy levels of the electrons
  4. Both give the same yellow colour because both have the same number of electrons arranged in the same energy levels
Correct answer: D
Flame colour depends on how electrons are arranged in energy levels. Both isotopes have 11 protons and so 11 electrons with the same arrangement, so they give the same yellow flame.

Q2. Normal carbon (carbon-12) has 6 protons. Carbon-14 is used to date younger remains such as charcoal and bone. It has mass number 14 and is also carbon. How many neutrons does an atom of carbon-14 have?
  1. 8
  2. 2
  3. 6
  4. 14
Correct answer: A
Number of neutrons = mass number − atomic number = 14 − 6 = 8. Carbon-14 has 2 more neutrons than carbon-12, which has 6.
Use after: Observe phase — Activity B: Spot-the-Pattern Gallery Walk (green and red dots)
Q3. A group fills in a table for protium (¹H), deuterium (²H) and tritium (³H), which are isotopes of hydrogen. Which pattern will they find in their table?
  1. The number of electrons changes, but the number of protons stays the same in a neutral atom
  2. Both the number of protons and the number of neutrons stay the same
  3. The number of protons changes, but the number of neutrons stays the same
  4. The number of protons is the same in all three, but the number of neutrons changes
Correct answer: D
All hydrogen isotopes have 1 proton (atomic number 1). The mass number changes (1, 2, 3), so the neutrons change (0, 1, 2).

Q4. Chlorine-35 and chlorine-37 both have the electron arrangement 2, 8, 7. Which statement best explains why?
  1. Neutrons are lost when the atom is placed in a flame, leaving the same electrons
  2. Both have the same mass number, so they must have the same electrons
  3. Chlorine-37 is heavier, so its extra neutrons are added to the outer shell
  4. Both have 17 protons, so a neutral atom of each has 17 electrons, and neutrons carry no charge and do not change the electron arrangement
Correct answer: D
Isotopes have the same atomic number, so the same number of protons and electrons in a neutral atom. Neutrons are neutral and sit in the nucleus, so they do not affect the electron arrangement.

Q5. Learners sort atom cards into isotope families. Which pair of atoms are isotopes of the same element?
  1. Atom with atomic number 19 and mass number 39, and atom with atomic number 11 and mass number 23
  2. Atom with atomic number 12 and mass number 24, and atom with atomic number 11 and mass number 24
  3. Atom with atomic number 11 and mass number 23, and atom with atomic number 12 and mass number 24
  4. Atom with atomic number 11 and mass number 23, and atom with atomic number 11 and mass number 24
Correct answer: D
Isotopes of the same element have the same atomic number (here 11) but different mass numbers (23 and 24). Matching mass numbers alone does not make atoms isotopes.

Q6. Olorgesailie stone tools are hundreds of thousands to over a million years old. Archaeologists date the volcanic ash around them using potassium-40, not carbon-14. Why?
  1. Carbon-14 is not an isotope of carbon
  2. Volcanic ash contains no atoms with neutrons
  3. Potassium-40 has the same mass number as carbon-14
  4. Carbon-14 can only date remains up to about 50,000 years old, which is far younger than the tools
Correct answer: D
Carbon-14 dating works only to about 50,000 years at most. Potassium-40, a radioactive isotope of potassium, can date much older volcanic layers.

Q7. Which claim is scientifically accurate for a yellow note on the Driving Question Board about the cooking hearth phenomenon?
  1. Isotopes of sodium have different electron arrangements, so they give different flame colours
  2. The heavier isotope of an element always gives a more intense flame colour because it has more neutrons
  3. Isotopes of the same element have the same electron arrangement, so they give the same flame colour
  4. Isotopes have different atomic numbers, so their flame colours depend on mass number
Correct answer: C
Isotopes share the same atomic number and so the same electron arrangement. Electron arrangement, not neutron number, determines flame colour.

Q8. A learner draws two isotopes of potassium for the model revision: potassium-39 and potassium-41. The atomic number of potassium is 19. How many neutrons should be labelled in the potassium-41 atom?
  1. 19
  2. 22
  3. 60
  4. 41
Correct answer: B
Number of neutrons = mass number − atomic number = 41 − 19 = 22. The atom also has 19 protons and 19 electrons.
