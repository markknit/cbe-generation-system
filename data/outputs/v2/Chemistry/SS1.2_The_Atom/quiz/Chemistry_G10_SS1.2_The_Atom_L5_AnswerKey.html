Q1. The periodic table gives the relative atomic mass of chlorine as about 35.5, yet chlorine atoms exist only as Cl-35 and Cl-37, which have whole-number masses. Which explanation is best?
  1. Some chlorine atoms contain half a neutron, which makes the mass 35.5
  2. Relative atomic mass is a weighted average of the masses of the isotopes, based on how much of each there is
  3. The periodic table value is a rounding error and is not a real measurement
  4. The electrons in chlorine add extra mass to every atom to make it 35.5
Correct answer: B
Chlorine is a mixture of Cl-35 and Cl-37, so its relative atomic mass is an average of the two masses, weighted by their abundances. No single atom has a mass of 35.5.
Use after: Observe phase — Observe: Kericho maize-harvest analogy (weighted average cob mass)
Q2. A maize farmer in Kericho harvests heavy cobs (3 kg each) that make up 75% of the harvest, and light cobs (1 kg each) that make up 25% of the harvest. What is the weighted average mass of a cob?
  1. 1.5 kg
  2. 2.0 kg
  3. 3.0 kg
  4. 2.5 kg
Correct answer: D
Weighted average = (3 × 0.75) + (1 × 0.25) = 2.25 + 0.25 = 2.5 kg. The simple average of 2.0 kg ignores how much of each type there is.

Q3. Chlorine has two isotopes: Cl-35 with an abundance of 75% and Cl-37 with an abundance of 25%. What is the relative atomic mass of chlorine?
  1. 36.0
  2. 35.5
  3. 35.0
  4. 36.5
Correct answer: B
RAM = (35 × 0.75) + (37 × 0.25) = 26.25 + 9.25 = 35.5. The value 36.0 comes from the simple average (35 + 37)/2, and 36.5 comes from swapping the abundances.
Use after: Observe phase — Observe: independent pair work calculating the RAM of carbon
Q4. Carbon has two isotopes: C-12 with an abundance of 98.9% and C-13 with an abundance of 1.1%. What is the relative atomic mass of carbon, to 3 decimal places?
  1. 12.989
  2. 25.000
  3. 12.011
  4. 12.500
Correct answer: C
RAM = (12 × 0.989) + (13 × 0.011) = 11.868 + 0.143 = 12.011. Carbon is almost all C-12, so its RAM is very close to 12.

Q5. A learner calculates the relative atomic mass of an element with two isotopes, X-63 and X-65, and gets an answer of 66.2. What is the best conclusion?
  1. The answer must be wrong because a weighted average must lie between 63 and 65
  2. The answer must be wrong because relative atomic mass must always be a whole number
  3. The answer is correct because heavier isotopes always raise the average above both masses
  4. The answer is correct as long as the percentages add up to 100%
Correct answer: A
The reasonableness check says a weighted average must fall between the lightest and heaviest isotope masses. 66.2 is above 65, so there is a calculation error.

Q6. Cl-35 and Cl-37 have different masses. Why do they give the same colour in a flame test?
  1. They have different numbers of neutrons, and neutrons cancel out the colour
  2. They have the same number of protons, so the same electron arrangement
  3. The flame colour depends on the mass number, and 35 and 37 are close together
  4. They have almost the same mass, so the flame cannot tell them apart
Correct answer: B
Isotopes of an element have the same atomic number (17 protons) and so the same electron arrangement. Flame colour depends on the electrons, not on the mass.
Use after: DQB phase — DQB: Na-23 and Na-24 flame colour discussion
Q7. Sodium-23 is a stable isotope of sodium and sodium-24 is a radioactive isotope. Both have 11 protons. A pinch of sodium-24 is put in a Bunsen flame. What colour is seen, and why?
  1. Violet, because the extra neutron changes the electron arrangement
  2. Yellow-orange, because both isotopes have the same atomic number and electron arrangement
  3. A deeper orange, because sodium-24 is heavier than sodium-23
  4. No colour, because radioactive atoms do not have electrons in energy levels
Correct answer: B
Both isotopes have 11 protons and the same electron arrangement, so they give the same yellow-orange flame. Mass does not change the flame colour.
Use after: Model Building phase — Model: drawing Cl-35 and Cl-37 side by side in the running atomic model
Q8. A learner draws a model of the Cl-37 isotope. Chlorine has atomic number 17. Which set of particle numbers should the model show?
  1. 17 protons, 37 neutrons, 17 electrons
  2. 17 protons, 20 neutrons, 37 electrons
  3. 17 protons, 20 neutrons, 17 electrons
  4. 20 protons, 17 neutrons, 20 electrons
Correct answer: C
The atomic number gives 17 protons, and in a neutral atom there are 17 electrons. Neutrons = mass number − atomic number = 37 − 17 = 20.
