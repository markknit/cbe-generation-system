Q1. Carbon has 6 electrons. The orbitals available are 1s, 2s and three 2p boxes. Electrons fill the lowest-energy orbitals first. Where do the first 4 electrons of carbon go?
  1. All 4 in the 1s orbital
  2. 2 in the 1s orbital and 2 in the 2s orbital
  3. 1 each in 1s, 2s and two of the 2p boxes
  4. 2 in the 1s orbital and 2 in the 2p orbitals
Correct answer: B
1s has lower energy than 2s, which has lower energy than 2p. Each orbital holds at most 2 electrons, so 1s takes 2 and 2s takes the next 2.
Use after: Observe phase — Part: 'Electron Seat' activity, Step 2 (He) and the 5-minute check of He diagrams
Q2. Helium has 2 electrons, both in the 1s orbital. Which arrow arrangement in the 1s box is correct?
  1. Both arrows pointing down (same spin)
  2. One arrow up and one arrow down (opposite spins)
  3. One arrow in the 1s box and one in the 2s box
  4. Both arrows pointing up (same spin)
Correct answer: B
Two electrons in the same orbital must have opposite spins (Pauli exclusion principle), and the lowest-energy orbital 1s is filled first.
Use after: Observe phase — Part: 'Electron Seat' activity, spotlight on Group 3's nitrogen (Rule C)
Q3. Nitrogen has 7 electrons: 1s² and 2s² are already full. How are the remaining 3 electrons placed in the three 2p boxes?
  1. All three in a single 2p box
  2. Two paired in one 2p box, one in a second 2p box, the third box empty
  3. One electron in each of the three 2p boxes
  4. Two paired in one 2p box and the third electron in the 3s orbital
Correct answer: C
Hund's rule: orbitals of equal energy are filled singly before any pairing, so each of the three 2p boxes gets one electron.
Use after: Explain phase — 'Spot the Mistake' challenge (diagrams for B, C, O and F)
Q4. A learner draws oxygen (8 electrons) like this: 1s: ↑↓, 2s: ↑↓, and the three 2p boxes: ↑↓, ↑↓, empty. Which rule has been broken?
  1. Hund's rule, because electrons paired up before each 2p box had one electron
  2. Aufbau principle, because 2p was filled before 1s
  3. Pauli exclusion principle, because two electrons share a box with the same spin
  4. No rule has been broken
Correct answer: A
The four 2p electrons should go one in each of the three 2p boxes first, and only the fourth pairs up (↑↓, ↑, ↑). Pairing in two boxes while the third is empty breaks Hund's rule.
Use after: Explain phase — Sodium pivot: extending the three rules to write Na's configuration
Q5. Sodium (Na) has 11 electrons. Which electron configuration follows the order of filling correctly?
  1. 1s²2s²2p⁶3s¹
  2. 1s²2s²2p⁷
  3. 1s²2s²2p⁶3p¹
  4. 1s²2s²2p⁵3s²
Correct answer: A
1s, 2s and 2p fill completely (2 + 2 + 6 = 10 electrons), and the 11th electron goes into the next lowest orbital, 3s, giving 1s²2s²2p⁶3s¹.
Use after: Explain phase — Sodium pivot: teacher explanation of the 3s¹ electron as the source of the yellow flame colour
Q6. At a Rift Valley homestead, salt (sodium chloride) thrown into a cooking fire always gives a yellow-orange flame. What is the best explanation?
  1. Every element gives yellow light because all electrons follow the same filling rules
  2. The sodium atoms always have the same electron arrangement, so the lone 3s electron always releases the same amount of energy as light when it falls back
  3. Salt burns to make a yellow substance that colours the flame
  4. The flame heat changes the number of electrons in sodium each time, so the colour is always yellow
Correct answer: B
Sodium's 3s¹ electron absorbs energy, jumps up, and releases a fixed amount of energy as light when it falls back. The same arrangement always gives the same energy, so the same yellow colour.
Use after: Model Building phase — Cumulative 'Atomic Model' revision: model statement naming the orbital of the outermost electron
Q7. Lithium has 3 electrons. Using the three filling rules, which orbital does its outermost electron occupy?
  1. 2p
  2. 3s
  3. 2s
  4. 1s
Correct answer: C
Lithium is 1s²2s¹. The 1s orbital holds only 2 electrons, so the third electron goes into the next lowest orbital, 2s.
