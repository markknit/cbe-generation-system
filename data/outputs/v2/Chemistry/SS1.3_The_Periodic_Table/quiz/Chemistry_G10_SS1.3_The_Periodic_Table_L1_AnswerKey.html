Q1. In class, Li (A_r 7), Na (A_r 23) and K (A_r 39) were all seen reacting vigorously with water. What do these three elements show about relative atomic mass (A_r) and behaviour?
  1. Mass alone tells us exactly how an element will behave
  2. Only the lightest of the three reacts with water
  3. Elements with very different masses can still behave alike
  4. Elements only behave alike when their masses are almost equal
Correct answer: C
Li, Na and K differ greatly in mass (7, 23, 39) yet all react vigorously with water. So mass alone does not decide behaviour.
Use after: Observe phase — Part B: data cards showing that Ne and Ar do not react at all
Q2. Neon (A_r 20) and argon (A_r 40) were tested with water. What did the data cards show?
  1. Neither neon nor argon reacts at all
  2. Argon reacts because it is heavier than neon
  3. Both react vigorously, like sodium and potassium
  4. Neon reacts slowly but argon reacts vigorously
Correct answer: A
The data cards showed that neon and argon do not react at all, even though their masses are different.
Use after: Observe phase — Part A: sorting the 20 Element Cards by increasing A_r and looking for elements that behave alike
Q3. Fluorine (A_r 19) and neon (A_r 20) have almost the same mass. Neon does not react at all. What does comparing them suggest?
  1. Neon is unreactive because it is lighter than sodium
  2. Elements with almost the same mass can behave very differently
  3. Fluorine and neon must be in the same column of the table
  4. Elements with almost the same mass always behave alike
Correct answer: B
F and Ne are neighbours with nearly equal mass, yet they behave very differently. This is a second puzzle that mass alone does not solve.
Use after: Observe phase — Part B: 'If we line up by mass alone, where should Ar and K go?'
Q4. Argon has A_r 40 and atomic number Z 18. Potassium has A_r 39 and Z 19. Argon comes before potassium in the order of the elements. Why is this a puzzle for a line-up by mass alone?
  1. Argon is lighter than potassium, so it should come first by mass
  2. Argon and potassium have exactly the same mass
  3. Argon reacts with water but potassium does not
  4. Argon is heavier than potassium, so a mass-only line-up would put potassium first
Correct answer: D
Ar (40) is heavier than K (39), so ordering by mass alone would place K before Ar. This does not match the accepted order, and the class holds the puzzle without resolving it yet.
Use after: Explain phase — Explain: 'What do you think makes elements behave alike?' and the class discussion on patterns and puzzles
Q5. After the class sorted cards and watched the reactions, a learner asks: 'Why do Li, Na and K react alike when their masses are so different?' Which statement is the most honest scientific position at the end of this lesson?
  1. They react alike because they all have exactly the same mass
  2. They react alike because they are all unreactive gases
  3. They react alike because they all have the same atomic number
  4. The class has not explained this yet; it is a puzzle to investigate and test with ideas
Correct answer: D
The lesson creates the need to know and does not give the explanation. The learners hold their ideas as hypotheses to test. The other choices contradict the data (the masses differ, the elements are reactive metals and not gases, and their atomic numbers differ).
Use after: DQB phase — DQB: each learner writes 2 questions on sticky notes and groups sort them into categories
Q6. Which of these is the best question to post on the Driving Question Board after today's observations?
  1. What is the A_r of calcium?
  2. Why do Li, Na and K react alike even though their masses are so different?
  3. Is sodium a metal?
  4. What is the name of the element with symbol H?
Correct answer: B
A good DQB question starts with how or why and links to a puzzle seen in the evidence. The other questions have short factual or yes/no answers.
Use after: Model Building phase — Model: drawing the first version of the Class Model with arrows for patterns and question marks for puzzles
Q7. A group is drawing its first 'Electron Arrangement Model'. Which item belongs with a question mark?
  1. Li, Na and K all react vigorously with water
  2. Argon (A_r 40) comes before potassium (A_r 39) even though it is heavier
  3. The A_r of H is 1
  4. Chlorine is used to disinfect drinking water in Nairobi and Mombasa
Correct answer: B
Question marks mark puzzles that are not yet explained, such as the Ar and K order. Patterns that worked and facts from the data go in as evidence, not as puzzles.
