Q1. A water purification officer in Kisumu drops sodium into Lake Victoria water and it reacts violently. A strip of magnesium, which is the next element in Period 3, barely fizzes in cold water. Which statement best explains why sodium is so much more reactive?
  1. Sodium has one outer electron, which is lost easily because sodium has a lower ionisation energy than magnesium
  2. Sodium has two outer electrons, which makes it lose them more easily than magnesium
  3. Sodium has more protons than magnesium, so it holds its outer electron more strongly
  4. Sodium has a full outer shell, so it reacts more easily
Correct answer: A
Sodium (2,8,1) has one valence electron and a lower ionisation energy than magnesium (2,8,2). It loses that electron easily, so it reacts violently with water. Magnesium has more protons, not fewer, which holds its electrons more strongly.
Use after: Observe phase — Group D presentation: Group VIII elements (argon as inert shielding gas in welding)
Q2. Welders on construction sites such as the SGR use argon gas to shield hot metal from the air. Why is argon suitable for this use?
  1. Argon has one outer electron that it gives away easily
  2. Argon has a full outer shell of electrons, so it does not react with anything
  3. Argon is a very reactive gas that quickly reacts with oxygen before the metal can
  4. Argon needs one more electron to complete its outer shell, so it attracts electrons strongly
Correct answer: B
Argon (2,8,8) has a full outer shell, so it neither loses, gains nor shares electrons. It is inert and cannot react with the hot metal.
Use after: Observe phase — Group C presentation: Group VII elements (chlorine in water treatment at a plant such as the one in Kisumu)
Q3. Chlorine is added to Lake Victoria water at a treatment plant in Kisumu to kill bacteria. Which property of chlorine, linked to its electron configuration, makes it effective?
  1. It has one outer electron that it loses easily, so it is a strong reducing agent
  2. It has a full outer shell, so it is completely inert
  3. It has a very large atomic size, so it is easily pulled apart by bacteria
  4. It has 7 outer electrons and a high electronegativity, so it strongly pulls electrons from other substances (it is a strong oxidising agent)
Correct answer: D
Chlorine (2,8,7) needs only one more electron to fill its outer shell. This gives it high electronegativity and strong oxidising power, so it damages bacterial cells.
Use after: Observe phase — Group B presentation: Group II elements (calcium in cement production and teacher prompt on the form of calcium in cement)
Q4. Cement used in Kenyan construction is made from calcium compounds such as limestone (CaCO₃). Calcium atoms form Ca²⁺ ions in these compounds. What does the 2+ charge tell us about calcium?
  1. Calcium gains two electrons, so it has two outer electrons missing
  2. Calcium has a full outer shell, so it forms ions without any change
  3. Calcium has two outer electrons, which it loses to form the 2+ ion in its compounds
  4. Calcium is present in cement as the pure metal, which is stable in air
Correct answer: C
Calcium is in Group II and has two valence electrons. It loses both to form Ca²⁺, so it is found in cement as compounds, not as the reactive metal.
Use after: Explain phase — Whole-class synthesis: 'Why does potassium explode more violently than sodium, which explodes more violently than lithium?'
Q5. Potassium explodes more violently in water than sodium, and sodium reacts more violently than lithium. Which explanation is correct?
  1. Going down Group I, the nuclear charge increases, so the outer electron is held more strongly and lost more easily
  2. Going down Group I, the outer electron is farther from the nucleus and more shielded, so it is lost more easily
  3. Going down Group I, the outer shell becomes full, so the metals become more reactive
  4. Going down Group I, the number of outer electrons increases, so more electrons are available to react
Correct answer: B
Down Group I there are more electron shells, so the single outer electron is farther from the nucleus and more shielded. Its ionisation energy is lower, so it is lost more easily and reactivity increases.
Use after: DQB phase — DQB closure: pairs answer Lesson 1 questions citing evidence (e.g. Lesson 5 ionisation energies across Period 3)
Q6. Going from left to right across Period 3 (Na to Ar), how does first ionisation energy change, and why?
  1. It decreases, because more electrons repel each other and are lost more easily
  2. It generally increases, because the nuclear charge increases while the electrons are added to the same shell, so they are held more strongly
  3. It increases, because more shells are added across the period
  4. It stays the same, because all the elements are in the same period
Correct answer: B
Across a period the number of protons increases but the electrons go into the same shell, so shielding stays about the same. The outer electrons are pulled more strongly and ionisation energy generally increases. No new shells are added across a period.
Use after: Model Building phase — Final Cumulative Annotated Periodic Table Model: annotating electron configurations for Li, Na, K, Mg, Ca, Cl, Br, I, Ar
Q7. Sodium is in Period 3 and Group I. Which shows the number of electrons in each shell of a sodium atom?
  1. 2, 1, 8
  2. 2, 8, 8, 1
  3. 2, 8, 2
  4. 2, 8, 1
Correct answer: D
Sodium has atomic number 11, so it has 11 electrons. They fill the shells as 2, 8, 1, giving 3 shells (Period 3) and 1 outer electron (Group I).
Use after: End of lesson — Individual Final Explanation answering the driving question and the class consensus answer
Q8. Which statement is the best overall explanation for why elements such as sodium, magnesium, chlorine and argon behave so differently?
  1. Their reactivity depends only on how many protons each atom has
  2. Elements in the same period react in the same way because they have the same number of shells
  3. The position of an element in the periodic table shows its electron configuration, and the number of outer electrons, shielding and ionisation energy determine how it behaves
  4. Their reactivity depends on the colour and state of the element
Correct answer: C
The unit's main idea is that position in the periodic table shows electron configuration. Together with shielding and ionisation energy, this determines how easily an element loses or gains electrons. Atomic number alone, or the number of shells alone, cannot explain the differences.
