Use after: Predict phase — Think-Pair and cold-call poll of the pre-lab prediction table
Q1. Two partners disagree about what colour methyl orange will turn in baking soda solution. Before testing, what is the best way to settle the disagreement?
  1. Carry out the test and record the colour actually seen
  2. Ask the teacher to say which prediction is right
  3. Vote and go with the answer most students choose
  4. Let the student who is more confident decide
Correct answer: A
In science, disagreements between predictions are settled by evidence from the experiment, not by confidence, authority or votes.
Use after: Observe phase — Experiment 1 procedure, Step 1: litmus strips with Test Solution 1 (lemon juice)
Q2. In Experiment 1, a student puts 2-3 drops of freshly squeezed lemon juice on a strip of blue litmus paper. What colour does the paper turn?
  1. Red
  2. Blue (no change)
  3. Pink
  4. Colourless
Correct answer: A
Lemon juice is an acid, and acids turn blue litmus paper red.
Use after: Observe phase — Experiment 1: circulation and 'check for honest recording' while groups fill the results table
Q3. A group predicted that cow's milk would be strongly basic. Their litmus and indicator results do not match this prediction. What should the recorders do?
  1. Write down the colours exactly as seen, even if they differ from the prediction
  2. Leave the milk row blank because the result was unexpected
  3. Copy the results from another group's table
  4. Change the results in the table to match the prediction
Correct answer: A
Honest, accurate recording is essential. An unexpected result is useful data and must never be altered to fit a prediction.
Use after: Explain phase — Consensus Results Table and pattern rules for each indicator (Explain phase)
Q4. Liquid soap solution turns red litmus paper blue and turns phenolphthalein pink. How should it be classified, and why?
  1. Acid, because it changes the colour of litmus paper
  2. Base, because red litmus turns blue and phenolphthalein turns pink
  3. Neutral, because it does not make methyl orange red
  4. Acid, because phenolphthalein changes colour
Correct answer: B
Bases turn red litmus blue and phenolphthalein pink or magenta. Both results point to a base.
Use after: Explain phase — Pattern Statement: writing rules for acids, bases and neutral substances from the consensus table
Q5. A student tests tap water. Litmus paper shows no colour change, phenolphthalein stays colourless and methyl orange is orange-yellow. What is the best conclusion?
  1. It is neutral, because none of the indicators show an acid or base colour
  2. It cannot be classified because no indicator turned red
  3. It is a base, because methyl orange is yellowish
  4. It is an acid, because phenolphthalein is colourless
Correct answer: A
Neutral substances do not change litmus, leave phenolphthalein colourless and make methyl orange orange-yellow. Colourless phenolphthalein alone cannot separate acids from neutral liquids, so the other indicators must be used as well.
Use after: DQB phase — DQB: sticky-note questions, clustering, and the SOLVED zone
Q6. After Experiment 1, students can tell whether a liquid is an acid, a base or neutral using indicators. Which question is still NOT answered by this experiment?
  1. How do acids react, for example do they corrode or react with other substances?
  2. Is baking soda solution a base?
  3. What colour does phenolphthalein turn in a base?
  4. Is vinegar (siki) an acid?
Correct answer: A
Indicators only classify a liquid by colour change. They do not show what an acid will do chemically, and this question leads into the next lesson. The other three questions were answered by today's results.
Use after: Model Building phase — Anchor model revision: labelling each cup as ACID, BASE or NEUTRAL
Q7. A student revises a model by labelling the liquids tested in Experiment 1 using the evidence. Which set of labels is correct?
  1. Lemon juice: base; baking soda solution: acid; tap water: neutral
  2. Lemon juice: neutral; baking soda solution: base; tap water: acid
  3. Lemon juice: acid; baking soda solution: neutral; tap water: base
  4. Lemon juice: acid; baking soda solution: base; tap water: neutral
Correct answer: D
Lemon juice is an acid (blue litmus turns red). Baking soda solution is a base (red litmus turns blue, phenolphthalein turns pink). Tap water is neutral (no change).
