Q1. Mama Wanjiru wants to remove grease from a sufuria. She has soap solution (pH 10.0), vinegar (pH 2.8), lemon juice (pH 2.0) and plain water (pH 7.0). Which is the best choice, and why?
  1. Lemon juice, because the sour taste shows it is the strongest cleaner
  2. Vinegar, because all acids dissolve grease better than bases
  3. Soap solution, because it is basic and OH- (aq) ions help to lift the grease
  4. Water, because pH 7.0 is the only safe value for cleaning
Correct answer: C
Soap solution (pH 10.0) is basic and contains OH- (aq) ions, and in the cleaning station it lifted grease better than water or vinegar. Taste or being an acid does not make a product a good cleaner.
Use after: Observe phase — Observe: Station 1 Pickling (acid)
Q2. Mama mboga stores onions for kachumbari in vinegar (5% ethanoic acid, pH 2.8). Which statement best explains why vinegar is used for pickling?
  1. Vinegar has a low pH with H+ (aq) ions, which makes the conditions unsuitable for many spoilage microbes
  2. Vinegar is a base, so it neutralises the microbes
  3. Vinegar is clear, so the onions stay white
  4. Vinegar has pH 2.8, which is higher than water, so it keeps the onions fresh
Correct answer: A
A pH of 2.8 is lower than water (7.0), so vinegar is acidic and contains H+ (aq) ions. This acidic environment is unsuitable for many spoilage microbes, so the onions keep longer.
Use after: Observe phase — Observe: Station 2 Cleaning and baking (bases), recipe card for mandazi
Q3. Mama Wanjiru adds baking soda solution (pH 8.3) to her mandazi dough. Which property explains why baking soda helps the dough rise and soften?
  1. It has pH 7.0, so it does not react with anything in the dough
  2. It is a strong alkali that dissolves the flour
  3. It is a base that reacts with acids to release carbon dioxide gas (CO2), which makes the dough rise
  4. It is an acid that makes the dough sour and soft
Correct answer: C
Baking soda is basic (pH 8.3) and releases CO2 when it reacts with an acid, as seen with vinegar earlier. The gas bubbles make the dough rise.
Use after: Observe phase — Observe: Station 3 Farming, Mr Kamau's maize farm in Kericho
Q4. On Mr Kamau's farm in Kericho the soil is acidic (pH about 4.5). He adds lime. What happens in the soil?
  1. Lime has no effect on the ions in the soil; it only adds colour
  2. Lime dissolves the soil, so the pH falls below 4.5
  3. OH- (aq) or carbonate from lime reacts with H+ (aq) in the soil, so the pH rises
  4. Lime adds more H+ (aq) ions, so the soil becomes sweeter
Correct answer: C
Lime is basic. Its OH- (aq) or carbonate ions neutralise H+ (aq) in the acidic soil, forming water or carbon dioxide and water, so the pH rises.
Use after: Observe phase — Observe: Station 3 Farming, soil pH card (4.5 before lime and about 6.0 after liming)
Q5. Before liming, Mr Kamau's soil had a pH of about 4.5. After liming it was about 6.0. By how many pH units did the pH rise?
  1. 2.5
  2. 1.5
  3. 10.5
  4. 0.5
Correct answer: B
Rise in pH = final pH - starting pH = 6.0 - 4.5 = 1.5 pH units.
Use after: Explain phase — Explain: strong and weak comparison, why magnesium hydroxide is used for antacids instead of sodium hydroxide
Q6. A patient in Nairobi has hyperacidity after eating nyama choma. Stomach acid is hydrochloric acid (pH about 1.5-2). Why is magnesium hydroxide chosen as an antacid instead of sodium hydroxide (pH 13)?
  1. Sodium hydroxide is weaker than magnesium hydroxide
  2. Magnesium hydroxide is a mild, only slightly soluble base that raises the stomach pH to about 3.5-5, while sodium hydroxide is a strong base that would be harmful
  3. All bases are safe to swallow, so either would work equally well
  4. Magnesium hydroxide is an acid, so it is gentler on the stomach
Correct answer: B
Magnesium hydroxide is a mild base that is only slightly soluble. It neutralises some of the excess acid and raises the pH to about 3.5-5. Sodium hydroxide is a strong, corrosive base and is not safe to swallow.
Use after: Explain phase — Explain: Safety Courtroom on soap
Q7. Soap solution (pH 10.0) removes grease very well but is harmful if swallowed. Which safety precaution matches this?
  1. Soap is a base, and bases are safe to swallow because antacids are bases, so no precaution is needed
  2. Soap is only dangerous when it is a solid bar, so solutions need no care
  3. Use soap for washing only, and store it away from children and food
  4. Mix soap with vinegar before use so that it becomes safe to swallow
Correct answer: C
Soap is useful for washing but harmful if swallowed, so the precaution is to use it for washing only and keep it away from children. Not all bases are safe to swallow, and antacids are only safe in the correct dose.
Use after: Explain phase — Explain: compare strong and weak, vinegar (pH 3 at 0.1 M) and HCl (pH 1)
Q8. Vinegar (ethanoic acid, 0.1 mol/L) has pH 3, but hydrochloric acid of the same concentration (0.1 mol/L) has pH 1. Which statement is correct?
  1. Vinegar is a weak acid, so it is dilute, and HCl is a strong acid, so it is concentrated
  2. Both acids have the same strength because they have the same concentration
  3. Vinegar is safer because it is a base
  4. HCl is a strong acid that ionises fully to give many more H+ (aq) ions, so it is more hazardous than vinegar of the same concentration
Correct answer: D
Strength is about how much an acid ionises, and concentration is about how much acid is dissolved. At the same concentration, strong HCl gives many more H+ (aq) ions (pH 1) than weak ethanoic acid (pH 3). A weak acid is not the same as a dilute acid.
Use after: Model Building phase — Model: mini-model (4) the stomach with H+ (aq) from hydrochloric acid and OH- (aq) from magnesium hydroxide
Q9. A learner draws a model of the stomach after a patient takes a magnesium hydroxide antacid. Which drawing and caption best show what happens?
  1. All H+ (aq) ions disappear completely and the stomach reaches pH 14
  2. H+ (aq) ions change into OH- (aq) ions on their own, with no reaction
  3. OH- (aq) ions from the antacid combine with H+ (aq) ions to form H2O, so fewer H+ (aq) remain, but some are still present (pH about 3.5-5)
  4. The antacid adds more H+ (aq) ions, so the pH rises
Correct answer: C
Neutralisation: H+ (aq) + OH- (aq) gives H2O. Only some H+ (aq) ions are removed, so the pH rises to about 3.5-5 and the stomach is still acidic.
