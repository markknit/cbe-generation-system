Use after: Predict phase — Predict: individual written prediction and Think-Pair-Share on whether the farmer, fisher and student will make the same groups
Q1. A farmer in Kericho, a fisher at Lake Victoria and a student in Nairobi each sort the same eight organisms: goat, chicken, maize plant, mushroom, algae, bacteria, bean plant and mosquito. Which prediction is most reasonable?
  1. Only the student in Nairobi can make correct groups
  2. They may make different groups, because each person may choose a different rule such as habitat, use or size
  3. They must make the same groups, because the organisms are the same
  4. They cannot make any groups, because the organisms are too different
Correct answer: B
People can sort using different rules (habitat, food use, colour, movement), so different groupings are possible. Predictions are not marked wrong at this stage, but this one fits the idea of different criteria.
Use after: Observe phase — Observe: card sorting, Step 1, where the group agrees one rule and sorts the eight cards
Q2. A group sorts the organisms with the rule: 'Can move from place to place on its own.' Which set contains only organisms that clearly fit this rule?
  1. Goat, maize plant, mushroom
  2. Mushroom, algae, bean plant
  3. Goat, chicken, mosquito
  4. Chicken, bean plant, mosquito
Correct answer: C
A goat, a chicken and a mosquito all clearly move from place to place on their own. Maize, bean plants and mushrooms stay fixed in one place.
Use after: Observe phase — Observe: Gallery Walk, finding an organism placed in a different group from your own
Q3. In a card-sorting activity, Group A put the mushroom with the plants and Group C put the mushroom in a different group. Both groups wrote a clear rule. What does this show?
  1. The mushroom cannot be classified at all
  2. The same organism can be placed in different groups when groups use different rules
  3. Group C cheated, because the mushroom can only go with plants
  4. Both groups must have misread the cards
Correct answer: B
Each group used its own criterion, so the same organism ended up in different groups. This was the key observation from the Gallery Walk.
Use after: Observe phase — Observe: Step 4, listing Kikuyu, Luo, Kiswahili and English names for the same organism in a table
Q4. Maize is called 'mahindi' in Kiswahili, and it has different names in Kikuyu, Luo and English. What problem can this cause?
  1. People using different names may not be sure they are talking about the same organism
  2. Only the Kiswahili name is allowed in science
  3. Names do not matter because everyone already uses the same groups
  4. Maize will grow differently in each community
Correct answer: A
Different local names for one organism make it hard for people in different places to be sure they mean the same living thing.
Use after: Explain phase — Explain: debate on 'Is the group that sorted by usefulness (food, pests, disease) wrong?'
Q5. One group sorted the eight organisms by usefulness: food, pests and disease-causing. Another learner says, 'That group is wrong.' Which response fits what the class found?
  1. The group is wrong, because organisms cannot be both useful and harmful
  2. The learner is right, because only habitat can be used to sort organisms
  3. The group is not wrong, because it followed a clear rule, but its rule is only one of many possible rules
  4. The learner is right, because usefulness is not a real feature
Correct answer: C
Every group was correct by its own criterion. The puzzle is that many correct groupings exist, so no single one works for everyone.
Use after: Explain phase — Explain: Jigsaw/peer teaching question 'What is classification?'
Q6. Which statement best describes what 'classification' means, as used in this lesson?
  1. Finding the most useful organism
  2. Grouping organisms using chosen criteria (rules)
  3. Collecting organisms from the environment
  4. Giving every organism a new name
Correct answer: B
In this lesson, classification means grouping organisms using chosen criteria. Different criteria give different groupings.
Use after: Model Building phase — Model: drawing the initial model with the 'problem' arrow and the 'what we need' box
Q7. At the end of Lesson 1, learners draw an initial model with a 'what we need' box. Which idea best fits what a shared system for classifying organisms should provide?
  1. Only people in Nairobi decide the groups
  2. Only organisms that are useful for food are included
  3. Each community keeps its own names and rules, and nobody changes them
  4. The same names and rules that people everywhere can use to identify and study organisms
Correct answer: D
The puzzle was that different groupings and names stop people communicating, so a shared system needs common names and rules usable by everyone. The lesson does not yet say what that system is.
