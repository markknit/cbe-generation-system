LM1 — Distance and displacement on one line
A fictional walker travels4m east then3m west in7s. Take east positive. Draw the path and find distance,total displacement,average speed and average velocity. Explain why a nonzero distance can accompany zero displacement on a return trip. No actual walk is recorded.
Teacher key and preparation
Distance7m,displacement+1m;average speed1m/s,average velocity+1/7≈+0.143m/s. Distance totals path length;displacement final minus initial position. Average velocity has direction/sign;average speed does not. Return to start yields zero displacement but positive distance if movement occurred.
LM2 — Position and velocity records
Supplied straight-line position record:time/s0,2,4,6;position/m0,6,12,18. Plot labelled position-time axes and calculate interval velocities. Compare a second record at the same times:positions18,12,6,0m. Explain negative velocity without calling speed negative. Explain the position-time slope and whether these tables alone resolve every motion between observations.
Teacher key and preparation
First intervals+3m/s,second−3m/s;speed3m/s for the stated uniform model. Straight interpolation represents constant velocity,not proof of all unobserved between-sample behaviour. Position-time slope gives velocity over a segment,not acceleration. Axes/units/coordinates explicit;no actual movement measured.
LM3 — Acceleration is change of velocity
Supplied constant-acceleration record:initial velocity+5m/s,final−1m/s,elapsed3s. Calculate acceleration,find time at which velocity is zero,and explain how speed can first decrease then increase while acceleration keeps the same negative sign. If needed use v=u+at;do not confuse acceleration with speed. Draw a labelled velocity-time line through the endpoints.
Teacher key and preparation
a=(−1−5)/3=−2m/s²;v0 at2.5s. Speed decreases to0 then increases in the negative direction to1m/s. Negative acceleration is not always slowing;it depends on velocity direction. Given constant-acceleration assumption justifies the straight line;not actual measured motion.
LM4 — Use v=u+at with stated assumptions
For straight motion with constant acceleration find:A final velocity fromu3m/s,a2m/s²,t4s;B time fromu3,v15,a2;C acceleration fromu3,v11,t4. Show substitution,units and direction convention. Audit a claim that this equation with one constant a automatically describes a vehicle whose acceleration changes halfway. No derivation is required.
Teacher key and preparation

Givenu2m/s,a1.5m/s²,t4s,calculate displacement with s=ut+½at² and final velocity with v=u+at. Check displacement using average velocity (u+v)/2 times time. Explain when displacement equals distance in this example. Then audit the incorrect calculation2×4+½×1.5×4,which omits the time square.

Teacher key and preparation

LM6 — Equations without time and stopping models
Use v²=u²+2as for a forward-moving object withu4m/s,a3m/s²,s8m. Find final speed and explain why squared velocity alone does not determine direction without the context. Separately,a fictional object slows uniformly from12m/s witha−3m/s² until first rest:find time and stopping displacement. No actual vehicle/braking test or road stopping-distance recommendation.
Teacher key and preparation
v²16+48=64,v+8m/s because forward motion specified. Other contexts can require the negative root. First-rest time4s;displacement24m. Equations do not justify extrapolating a braking model past rest or assuming real reaction/braking distances are this ideal value.
LM7 — Piecewise motion and graph area
A fictional object moves at+4m/s for3s,then accelerates uniformly from+4 to+10m/s during the next3s. Draw its velocity-time graph using these intervals. Calculate displacement of each interval,total displacement,total average velocity and acceleration in each interval. Explain why one constant acceleration does not describe all6s. All velocities remain positive.
Teacher key and preparation
First displacement12m;second mean7×3=21m;total33m;average5.5m/s. Acceleration0 then2m/s². Graph points(0,4),(3,4),(6,10);area rectangle+trapezium. Distance also33m because no reversal. Do not use (4+10)/2 over the whole6s;that would incorrectly assume one linear velocity ramp.
LM8 — Approved low-drop investigation
Actual observation only after teacher approves a light soft ball,stable floor-level catch tray,clear exclusion zone and maximum drop height0.50m;no climbing,stairs,windows,roads,hard/heavy objects or people below. Teacher marks a visible scale,supervises a release from rest without throwing,and retrieves only after rest. Repeat3times,recordactualheight,object,release condition,observer/date/role and downward motion. If approved video/frame capture is available,record actual frame times and positions against scale to examine increasing spacing for equal intervals;ordinary human stopwatch timing over this low height cannot establish precise g. Do not claim that looking alone measures acceleration or that ordinary air-resisted motion is exact free fall. If approval/provision missing,use LM9 supplied frame data and mark actual investigation not performed. Compare an ideal gravity-only model with real air resistance;no actual values are prefilled.

Teacher key and preparation
Observe actual safe release/records before crediting practical evidence. Downward motion is consistent with gravity;quantitative increasing speed needs suitable timed position evidence,not eye impressions alone. Real ball experiences air resistance and release/scale/frame uncertainty. Ideal gravity-only near Earth uses a stated g;do not infer mass dependence or exact equality from a few ordinary drops. Source investigation remains unperformed under supplied-data alternative.

LM11 — An upward object still accelerates downward
Paper model,upward positive,u+10m/s,a−10m/s²,no drag,return to same launch height. Find time to highest point,maximum displacement,total return time and return velocity. At the highest point state both velocity and acceleration. Find displacement and velocity at0.50s and1.50s;explain why same position does not mean same velocity. No launch is performed.
Teacher key and preparation
