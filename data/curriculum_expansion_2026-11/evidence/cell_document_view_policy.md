# Cell source-image implementation

Original downloaded image bytes are copied unchanged into materials/microscopy,hashes verified against independent suitability evidence. Word crop frames select a source panel for readability without raster editing,retouching or image synthesis. Each declared image is a fingerprint-bound asset;pixel crop bounds are validated and converted to DrawingML source rectangles. Captions declare panel selection,credit/licence,organism,tissue,mode and visibility limits;scale bars stay inside the selected view. Final artifact review must inspect actual exported panels,bars and aspect ratios. Compiler fits visible frames within6.3in width/6.5in height. Twenty-two pipeline tests pass,including source-byte preservation,crop coordinates/geometry and portrait bounds. Old reviewed deliveries are not rebuilt solely for this code change;their hashes/audits/policies remain frozen evidence.
