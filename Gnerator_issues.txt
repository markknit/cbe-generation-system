*1. safetyNotes key corrupted as safetyNotes with lesson number inserted*

Pattern found:

safety1otes

safety3otes

safetyNotes

general_science__grade_10__ss_3_3__waves.json
general_science__grade_10__ss_3_4__magnetism_and_electromagnetic_induction.json


Likely cause: the generator is replacing a placeholder like N with the lesson number too broadly, and it is touching the key name safetyNotes, turning the N into 1, 2, etc.

Recommended generator fix:
- Never use a raw placeholder like N for global string replacement.
- Use explicit placeholders like {lessonNumber} or {{LESSON_NUMBER}}.
- Do not run placeholder replacement over object keys.
- Add schema validation that rejects unexpected slo keys before writing JSON.

*2. Missing summaryTablePrompt.explained*

Two General Science lessons were missing the required explained field:

text
general_science__grade_10__ss_3_2__linear_motion.json
LESSONS[6].summaryTablePrompt.explained missing


text
general_science__grade_10__ss_2_2__chemical_families.json
LESSONS[4].summaryTablePrompt.explained missing


Both had:

json
{
  "observed": "...",
  "learned": "..."
}


but lacked:

json
"explained": "..."


Recommended generator fix:
- Make summaryTablePrompt always emit exactly:
  - observed
  - learned
  - explained
- Add a pre-export contract check for every lesson.
- If explained is absent, fail generation or synthesize a fallback from the lesson’s existing final explanation / driving-question synthesis.
