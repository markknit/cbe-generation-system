## Known Issues / Lessons Learned

- **(2026-11-21) The branch's control documents were 50 commits stale.** CLAUDE.md, WORKFLOW.md and `ares-contract.schema.json` (contract R1, 1.1.0) had not been merged since 2026-10-26. Caught by `/restart`; fixed by `git merge main`. Structural fix: already the Branch Policy rule (merge `main` at every session start); `/restart` reports the count and proposes it.
- **(2026-11-21) Resource DB not verified in this worktree.** `data/ares_index/ares_content.db` reported missing by `ls`, and the symlink check was blocked by the sandbox. Check before any step that rebuilds resource links.

- **(2026-10-22) `UNIT.totalDuration` is not a usable lesson-length source.** It assumes 40 minutes per lesson and disagrees with the lessons in 11 of 28 Bio/Chem/Phys modules (e.g. `bio_1_1`: lessons sum 840 min, field says 480). **Structural fix:** the build reads per-lesson `duration` only, and the Phase 2 validator should also check that the slide timings equal that figure.

- **(2026-11-22) A status line went stale in the same file that was meant to catch it.** The 2026-11-21 row said 'NOT pushed (51 ahead)' while `origin/presentations` already equalled `HEAD`. **Structural fix:** `/update` must run `git fetch` and `git rev-list --count origin/presentations..HEAD` before recording any push state.
- **(2026-11-22) The picture step failed in the real batch driver (it had only been tested with a stub).** `scripts/make_art.py` fell back to `cand_0.png` when the vision ranker recorded no choice, but candidates are numbered from 1; 3 of 5 `figtest2` lessons failed at art. Fixed (first existing candidate, with a warning that a human must look). The vision-ranker server (`/home/markk/vlm-qa/start_server.sh`, port 8090) was not running, so those pictures are unranked. **Structural fix:** a stub test does not prove an integration; run one real lesson through each new stage before a batch.
- **(2026-11-22) `pgrep -f '<pattern>'` inside a `bash -c` wait loop matches its own shell**, so a 'wait until the run ends' monitor never ended (two 30-minute watches expired). Use the PID, or `ps -eo cmd | grep -v grep`.
- **(2026-11-22) Teacher notes leaked builder language** ('source review as recorded in the build log', 'Retain the lesson-plan criterion', 'Keep the prescribed sine pathway unchanged') in `figtest2` decks; reviewers rated it minor. **Fix:** authoring rule 14 now forbids it and the validator has error N1 (`BUILDER_RE` in `scripts/validate_deck.js`); tested on the 4 real leaks and 3 clean sentences. Not yet seen to work in a fresh model run (`sub1` will show it).
