AUTHORING CHECKLIST (apply while you write; an independent reviewer will check every item afterwards, and each defect it finds is a failure of this pass):
1. NUMBERS: recompute every calculation, total, average, percentage and unit conversion before writing it. If a lesson gives minutes per phase, they must add up to the lesson's stated duration (40 minutes unless the unit says otherwise). The same person, object or situation has ONE value for each quantity everywhere (all lessons and the Final Explanation); take values from the fact sheet verbatim.
2. CROSS-REFERENCES: refer to another lesson, card, table, dataset or material only if the fact sheet's lesson map says it exists there. Say "in Lesson N" only for the lesson that really teaches it. Card, item and group counts in the text must match the arithmetic (e.g. 5 groups x 5 categories = 25 cards).
3. REAL-WORLD FACTS: use only places, records, measurements and figures you are certain are correct, or label the data "illustrative" / "a made-up example". Never present an invented figure as a real measurement, and never put numbers in the mouth of a real named person or athlete unless the figure is well known and accurate. Realistic figures only (no impossible speeds, masses, temperatures, times).
4. SCIENCE AND MATHEMATICS: textbook-level correct for Grade 10. Where a simplification is needed, say it is a simplification. Check direction-of-change statements, causes (why, not just what), units, and the names of apparatus, particles, organs and processes. If you are not sure a statement is correct, leave it out.
5. KICD: copy learning outcomes, key inquiry questions, competencies, values and PCIs verbatim. Cover every specific learning outcome across the lessons, and stay inside this sub-strand's content.
6. PRACTICALS: only apparatus and materials a Kenyan secondary school can obtain; list real hazards in safetyNotes.
7. FINAL EXPLANATION: assesses only what the lessons taught, using the lessons' own data and characters; every exemplar must be derivable from what learners met; prompts never contain their own answers; the rubric has four levels (Exceeds 4, Meets 3, Approaches 2, Below 1).
